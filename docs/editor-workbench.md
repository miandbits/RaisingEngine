# 검증·UI 계층·자동 플레이 작업실

## 실행과 검증 결과

`Edit-Editor-Workbench-Lab.cmd`는 별도 샘플 `tests/fixtures/projects/editor-workbench-lab`과 자동 플레이 분석 패널을 연다. 기존 프로젝트와 이전 편집기 출력은 보존한다.

상단 **검증**을 누르면 하단 검증 패널이 열리고 오류·경고 수, 검사한 초안 버전, 검사 시간이 표시된다. 오류가 없어도 성공 결과를 표시한다. 오류 행을 누르면 해당 화면·요소로 이동한다. 검사 후 수정하면 다시 검증해야 한다는 표시가 나온다. 이 검사는 데이터 구조·참조·규칙 검사이며 자동 플레이는 별도 작업이다.

## UI 부모·자식 계층

계층 패널의 **그룹 추가**로 컨테이너를 만든다. 요소의 부모를 속성 패널에서 고르거나 트리에서 그룹으로 끌어 넣는다. 부모는 같은 화면/부품 안의 그룹이며 자기 자신이나 자손을 부모로 삼을 수 없다.

- 좌표와 앵커는 부모 영역 기준이다. 부모를 이동하면 자식도 함께 이동한다.
- 숨김·투명도·배치 잠금·표시/활성 조건은 자식에게 상속된다.
- 그룹의 자식 클리핑을 켜면 영역 밖 렌더링과 클릭을 막는다. 끄면 자식의 영역 밖 배치를 허용한다.
- 그룹 복제는 하위 요소와 내부 부모 참조를 함께 복제하고, 그룹 삭제는 하위 트리를 삭제한다.
- 기존 부모 없는 요소는 기존 화면 기준 배치를 유지한다.
- 같은 계약을 화면, 재사용 부품, 반복 목록의 템플릿에 사용한다. 네이티브·웹 플레이어에 적용된다.

## 자동 플레이와 경로 지도

기본 보기는 **분기 트리**이다. 기존 5,000회 기록을 그대로 사용하며 다시 시뮬레이션하지 않는다. 같은 관측 경로를 공유한 회차는 묶되, 갈라진 뒤 같은 사건에 도달해도 가지를 다시 합치지 않는다. 예를 들어 `A → X → C`와 `B → X → D`는 서로 다른 X 노드를 가진다. 반복 행동도 순서를 보존한다.

- **더블클릭 또는 Enter/Space:** 선택한 가지 펼치기·접기.
- **한 번 클릭:** 그 노드만 방문한 회차가 아니라, 시작부터 해당 가지까지의 전체 경로를 실제로 지난 회차를 조회한다. 기존 엔딩·결과·능력치 필터와 함께 적용된다.
- **추가 갈래 보기:** 한 번에 표시되지 않은 형제 가지를 차례로 펼친다. 원본 회차를 생략하지 않는다.
- **트리 접기 / 지도 맞춤 / Ctrl+휠:** 펼친 범위와 배율을 조절한다. 펼침·접기 뒤에도 선택한 부모를 화면에 유지한다.
- 공통 단일 경로는 카드 하나에 최대 32개 관측 단계를 묶고, 툴팁·하단 설명에서 구간을 확인한다. 성공·실패는 분리해 표시한다.
- 카드의 **부모 대비 비율**은 그 경로에서 관측된 회차 비율이다. 상태에 따라 계산되는 게임의 고정 성공 확률을 뜻하지 않는다. 같은 관측 경로를 묶는 것이며 능력치까지 동일한 상태라는 의미도 아니다.

예전 지도는 보기 선택의 **집계 그래프**로 유지한다. 기간·종류 필터는 집계 그래프에서 사용한다. 트리는 연결을 읽고 개별 경로를 확인할 때, 집계 그래프는 사건 전체의 방문량을 비교할 때 사용한다.

상단 **자동 플레이 · 경로 지도**에서 회차 수, seed, 전략, 명령 한도, 시간 한도를 정하고 시작한다. 저장하지 않은 현재 초안도 불변 스냅샷으로 분석한다. 진행 중에는 완료 수와 종료 분포를 표시하고, 완료 후 집계 지도를 그린다. 중단한 분석도 완료된 회차 기록을 보존한다.

**병렬 작업**은 1–32개로 지정한다. 편집기는 CPU 논리 코어 수 안에서 최대 4개를 기본값으로 잡는다. 무작위·자원 보존·능력 집중 전략은 독립 회차를 여러 작업 스레드에서 실행하고, 원래 회차 번호 순서로 결과를 모은다. seed와 회차 번호가 같으면 작업 수가 달라도 결과가 같아야 한다. 미방문 탐색과 목표 탐색은 이전 탐색 결과를 사용하므로 현재는 실제 작업 1개로 실행하며, 요청 수와 실제 사용 수를 결과에 따로 표시한다. 병렬 수가 많다고 항상 빨라지는 것은 아니므로 다른 프로그램을 함께 쓸 때는 줄일 수 있다.

지도 노드는 기간·종류·판정 결과를 구분한다. 방문 횟수와 도달 회차 수를 별도로 표시하며 성공 판정 노드에서는 실제 계산된 확률의 범위·평균을 볼 수 있다. 큰 지도는 방문 수 상위 600개 노드와 2,000개 연결까지만 그리며 표시 수/전체 수를 알린다. 기간·종류를 좁히면 세부 항목을 볼 수 있다. 원본 회차 기록은 생략하지 않는다.

노드나 연결을 선택하면 **그 지점을 실제로 지난 회차**만 목록에 나온다. 목록은 100개씩 넘기고 엔딩·종료 결과·종료 시 능력치 범위로 추가 필터할 수 있다. 능력치 필터는 판정 순간이 아닌 **종료 상태** 기준이다.

회차 필터는 엔딩·결과·능력치를 변경하면 자동 적용된다. 숫자 입력은 200ms 뒤 적용하며 **회차 필터 적용**으로 즉시 조회할 수도 있다. 목록 위 **적용 필터 (모두 충족)**에 경로와 종료 조건의 교집합을 표시한다. **경로 필터 해제**는 경로만 해제하고, **전체 필터 해제**는 엔딩·결과·능력치까지 초기화한다. 능력치 제한이 없으면 숫자 입력은 비활성화된다. 조회 중에는 이전 결과와 페이지 버튼을 비워 오래된 회차를 선택하지 않게 한다. 조회 실패, 잘못된 수치 범위, 0개 결과를 목록 상태에 표시한다.

필터 해제 후 같은 가지를 클릭해도 전체 회차에 머물던 오류를 Qt에서 재현하고 수정했다. 트리·그래프 전환 때 선택 표시도 초기화하며, 추가 갈래를 불러올 때 현재 경로 선택을 유지한다. `qt-studio-tree-filter` 빌드의 회귀 검사는 기존 5,000회 원본 경로에서 회차 번호를 직접 계산해 첫 페이지·다음 페이지와 대조한다. 경로 재선택, 보기 전환, 빠른 연속 선택, 엔딩·능력치 교집합, 결과 조건 유지, 잘못된 범위, 빈 결과, 전체 초기화와 재생도 확인한다. 새 시뮬레이션은 실행하지 않는다. [필터 검증 결과](evidence/route-tree/filter-regression.json)와 [실제 필터 화면](evidence/route-tree/branch-filter-verified.png)을 보존한다.

## 회차 재생

회차를 선택해 열면 실제 명령 순서, 기간, 결과, 계산 확률, 추첨값을 확인한다. 이전/다음·자동 재생·단계 이동은 원본 스냅샷과 실제 명령으로 상태를 재현하며 변경 전/후 값을 비교한다. 이후 프로젝트를 수정해도 원본 분석은 유지된다. 이 패널은 시뮬레이션 상태 재생기이며 게임 화면 애니메이션을 재생하는 창은 아니다.

`.studio/analysis` 아래에 분석 메타데이터, 스냅샷, 회차 기록이 저장된다. 분석 기록 목록으로 다시 열 수 있다. 원본/기록의 무결성이 맞지 않으면 재생을 거부한다.

## 결과 해석

5,000회 플레이는 선택한 전략과 seed로 관측한 결과이다. 미관측 이벤트·엔딩을 도달 불가능하다고 판정하지 않는다. 집계 지도에서 연결을 이어 만든 임의의 경로가 실제 한 회차에 존재한다고 보장하지 않으므로, 회차 원본을 열어 확인한다. 성공 확률은 상태에 따라 달라지며 집계 빈도를 고정 성공률로 해석하지 않는다.

## 검증 기록

완료 증거는 `.cache/qt-workbench-evidence`의 Qt 화면 및 결과 JSON, `.cache/native-hierarchy`의 실제 네이티브 입력 검사, `output/playwright/hierarchy-web-wide.png`와 관련 테스트 로그에 보존한다.

실제 Qt 편집기에서 seed 4242, 4개 작업, 5,000회, 회차당 명령 한도 1,000으로 실행했다. 분석 시간은 약 150.8초이며, 지도·재생 UI까지 포함한 인수 검사는 약 157.6초에 통과했다.

| 결과 | 관측값 |
| --- | --- |
| 처리한 회차 | 5,000 |
| 엔딩 도달 | 4,999 |
| 명령 한도 | 1 (회차 번호 4183, seed 8425) |
| 전체 기록 명령 | 2,036,668 |
| 집계 노드 / 연결 | 1,667 / 34,178 |
| 이웃 / 방랑 / 학자 / 기사 엔딩 | 2,619 / 867 / 1,357 / 156 |

한도 회차는 1,000번째 명령까지 정확히 재생되고 일정 준비 상태에서 멈췄다. 엔진 오류나 도달 불가능 판정으로 취급하지 않는다. 장인 엔딩은 이번 무작위 표본에서 관측되지 않았다.

독립 검사에서 모든 회차의 SHA-256과 그래프의 방문 횟수·서로 다른 도달 회차 수를 원본 기록으로 재계산했다. 마지막 회차와 한도 회차의 저장 상태를 코어에서 정확히 재현했다. 같은 스냅샷으로 앞서 실행한 단일 작업 기록의 회차 0, 1, 99, 1000, 2824도 병렬 실행 결과와 일치했다.

검사 묶음: 기존 Qt GUI 16개, 새 잠금·부품 계층 GUI, 실제 5,000회 및 저장 결과 재열기·필터·재생, 계약·편집·기존 분석 회귀 36개, 병렬/분석 서비스 검사 22개, 네이티브 32워커 동시 실행 3,200회, 네이티브·웹 실제 계층 플레이. 회귀 묶음 사이에는 중복 검사가 있으므로 합산하지 않는다.

분석 ID: `840424df-b211-4107-99c5-5c199620f783`. 독립 감사 결과: `.cache/qt-workbench-evidence/analysis-audit.json`.
