# Binary preview sample media

The release package uses original geometric PNG demonstration art generated solely by `scripts/release-sample-media.mjs`. The generator and its original drawing definitions are distributed under this repository's MIT license; generated outputs may be used, modified and redistributed under the same license. Retain the MIT copyright and permission notice. These are simple demonstration assets, not illustrations from a commercial game.

Seven image designs replace 18 copies in the selected visual, journey and adventure templates. The replacement policy pins each original file's hash and target path; unknown media stops packaging. The resulting `licenses/sample-media.json` records every image's hash, size, generator and license. The audit regenerates each design and rejects missing, modified or additional media in packaged examples.

Generated image-tool artwork and commercial-game reference images are **not shipped in this binary preview**. All 47 affected public-source image copies also use these geometric designs, so automatic GitHub source ZIPs do not reintroduce the old illustrations. Original source images, generated fixture copies and generation records were archived in an owner backup outside the repository before replacement; existing user games and animation projects are unchanged. Generation prompts alone do not establish a redistribution license or third-party rights clearance, so this package does not depend on them. `config/source-sample-media.json` records the current-source image boundary. The source checker rejects the former illustration hashes in tracked raster files. This does not rewrite earlier Git history or claim to remove old clones/releases.

The other 13 tracked PNGs belong to the optional animation plugin's procedural demo, defined by its MIT source `plugins/cutout-animation/demo/make-parts.mjs`. They are unchanged and are not bundled with the editor installer. The public test fixture's geometric SD images exercise frame selection rather than represent final character artwork.

No music, voice or video is bundled in these templates. Noto Sans KR and Noto Sans JP are separately licensed under SIL OFL 1.1; their original notices accompany the fonts. Do not apply the engine's MIT license to those fonts or to third-party libraries. The full dependency notices and corresponding Qt sources remain in `licenses/`.

Source-only audio fixtures are also sample-free: the winter motif is synthesized by its adjacent Python generator, and the four native-player tone formats are freshly generated from a mathematical 440 Hz sine wave (`tests/native-player/fixtures/generate-tone.mjs`, MIT). The earlier tone files are preserved in the external backup. FFmpeg was used only to encode these original test signals and is not distributed in the application.
