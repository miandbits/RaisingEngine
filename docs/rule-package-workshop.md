# 시각적 규칙 패키지 제작실

진입: **디자인 → 규칙 확장 패키지 · 진행 방식 → 새 패키지 제작**.
기존 패키지는 목록에서 선택하고 **선택 패키지 편집**으로 연다.

## 제작 순서

1. 패키지 이름과 버전을 정한다. 내부 식별자는 자동으로 생성된다.
2. **조건 추가 / 효과 추가** 후 **본문 편집**으로 기존 조건·효과 편집기를 연다. 참조와 대상은 프로젝트의 이름 목록에서 선택한다.
3. **조절 값 연결**에서 본문의 능력·자원·인물·아이템·사건·상태나 수치를 선택하고 이름 있는 입력으로 만든다. 다른 위치를 같은 입력에 연결하거나 고정값으로 돌릴 수 있다.
4. **입력 이름 · 기본값 편집**에서 기본값을 수정한다. 정수 입력은 최소·최대 범위를 지정한다. 범위를 벗어난 기본값은 저장되지 않는다.
5. **진행 방식 추가**에서 상태를 만들고 시작 상태를 정한다. 전이마다 출발 상태, 도착 상태, 조건, 비용, 효과, 후속 사건을 연결한다. 여러 출발 상태와 반복 전이도 지원한다.
6. **패키지 파일로 내보내기**로 `.raiserules`를 저장한다. `QSaveFile`로 기록하여 실패한 쓰기로 기존 파일을 깨뜨리지 않는다.
7. 패키지 제작실과 부모 대화상자의 저장을 차례로 적용한다. 진행 인스턴스를 추가하고 입력과 공유/캐릭터 범위를 정한 뒤 행동 목록을 화면에 배치한다.
8. 프로젝트 공통 검증을 실행하고 플레이한다. 기존 Undo, 디스크 충돌 검사와 프로젝트 저장 경로를 사용한다.

## 수정과 버전

- 제작실은 분리된 초안을 편집한다. 취소는 프로젝트를 바꾸지 않는다. 내보내기는 별도 명시적 파일 쓰기이므로 이후 취소해도 내보낸 파일은 남는다.
- 본문을 그대로 다시 저장하거나 효과 순서를 바꾸면 조절 값 연결을 유지한다. 연결된 값을 직접 다른 숫자로 바꾸면 그 위치는 고정값이 된다. 다른 독립 연결은 유지한다. 구조를 대체한 경우 연결을 다시 확인한다.
- 사용 중인 상태는 먼저 시작 상태·전이 연결을 바꿔야 삭제할 수 있다.
- 버전을 바꾸면 동일 패키지 내부 호출만 새 버전을 따른다. 프로젝트·다른 패키지의 호출은 고정된 이전 버전을 유지하므로 공통 검증에서 버전 오류가 난다.
- 기존 진행은 **선택 진행을 위 정의·버전에 다시 연결**로 명시적으로 갱신한다. 입력은 새 정의의 기본값으로 초기화하므로 다시 확인해야 한다. 조건·효과 호출은 규칙 선택기에서 새 버전을 고른다.
- **의존 패키지 · 버전 변경 안내**에서 필요한 외부 규칙의 ID와 고정 버전을 확인한다. 외부 패키지를 자동 다운로드하거나 몰래 교체하지 않는다.
- 내용 지문이 바뀐 저장은 기존 저장 계약에 따라 거절된다. 이 제작실은 저장 상태를 자동 마이그레이션하지 않는다.

## 검증 범위와 한계

패키지 대화상자는 이름·버전·상태 연결·입력 범위 같은 제작 오류를 먼저 보여준다. 프로젝트의 실제 참조, 재귀 호출, 확장 예산, 생성 ID 충돌과 런타임 AST는 **공통 검증기**가 최종 판단한다. 파일 내보내기 성공이 모든 프로젝트에 대한 유효성 보증은 아니다.

이 도구는 [규칙 확장 API 1](rule-extensions.md)의 시각적 작성기다. 임의 JavaScript/C++ 실행, 새 런타임 원시 연산, 새로운 그래픽 백엔드를 제공하지 않는다. 참조 기본값은 가져올 프로젝트에도 존재하거나 다시 선택해야 한다.

비용 양식이 표현하지 못하는 외부 확장 형식·중복·없는 참조는 원본을 보존하고 수정을 중단한다. 패키지 전체 업그레이드 마법사, 외부 호출 일괄 재연결, 저장 마이그레이션 계획 편집은 후속 작업이다.

## 재현 가능한 자동 시험

`npm run test:rule-workshop`은 실제 Qt 위젯에서 빈 패키지부터 조건·효과·입력·진행 방식을 제작하고 파일 대화상자로 내보낸다. 이를 다시 가져와 공통 프로젝트 서비스로 저장한 뒤 숨김 Windows 플레이어와 헤드리스 Chrome의 Wasm 플레이어에서 같은 경로를 실행한다.

수련 준비·취소·실행·돌파, 중간 저장·복원, 엔딩과 새 프로세스/브라우저 복원, 경로 회귀와 성장량 변경에 따른 실패를 확인한다. 정수 범위 오류, 사용 중인 상태 삭제, 버전 고정·명시적 재연결, 취소와 템플릿 연결 보존도 검사한다.

장면 배경·기본 일정·서사와 검증용 버튼 일부는 테스트 기반 데이터다. **패키지 규칙은 위젯으로 제작**하지만 샘플 전체를 사람이 처음부터 GUI만으로 만든 시험은 아니다. 독립 제작성·실제 사람 시험의 완료 증거로 바꾸어 서술하지 않는다.

빌드 출력: `dist/qt-studio-rule-extensions/RaisingStudioQt.exe`.
최신 로컬 증거 위치: `.cache/rule-extension-verification/latest.json`.
현재 게임 창을 유지하기 위해 이 빌드는 대화형으로 실행하지 않는다.
