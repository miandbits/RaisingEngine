# Schedule authoring feedback

The properties dock keeps the selected element name, widget configuration, and
connection-following buttons visible while the property fields scroll. Tools are
disabled for an empty or multiple selection; widget configuration is available
for supported widget types.

Multi-character schedules now show initial names, assigned activities, optional
costs/descriptions, and the action area on the canvas. This preview uses the
project's authored starting assignments and updates when that data changes.
It is clipped to the widget bounds and indicates additional scrollable members.

This is an authoring preview, not a second simulation or an exact native/web
renderer. Runtime rule results, eligibility, effects, and interactive scrolling
must still be checked in Play. Preview metadata never enters project or save
files. Projects without a roster retain their existing canvas presentation.
