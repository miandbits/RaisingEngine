# 회상·엔딩 도감 1단계

이 문서는 1단계 구현 기록이다. 이후 구현된 CG·음악·조건 해금 및 원본 연출 회상은 [2단계 문서](gallery-media-and-recollection.md)를 따른다. 아래의 당시 미구현 목록은 현재 지원표가 아니다.

## 제작

Qt의 **프로젝트 설정 → 회상 · 엔딩 도감**에서 사용을 켜고 항목을 추가한다. 사건/엔딩 선택, 고정 ID, 제목, 분류, 잠금 힌트, 이미지 썸네일, 표시 순서를 편집할 수 있다. 설정은 기존 프로젝트 저장·되돌리기·공통 검증 서비스를 사용한다. 중복 ID, 없는 대본 참조, 이미지가 아닌 썸네일을 오류 위치와 함께 검사한다.

`project.gallery`는 선택형이다. 설정 없는 프로젝트와 기존 실행 저장 형식은 그대로 동작한다. 단, 다른 콘텐츠 변경과 마찬가지로 갤러리 설정 추가는 콘텐츠 지문을 바꾼다. 변경 전 콘텐츠의 실행 저장을 자동 마이그레이션하는 기능은 이번 범위가 아니다.

## 실제 플레이

- 제목·본편 화면의 도감 버튼에서 연다. 분류, 6개씩 페이지 이동, 해금 개수/전체 개수, 잠금 힌트를 제공한다. 미해금 항목의 제목과 이미지는 표시하지 않는다.
- 설정에 등록한 사건 또는 엔딩의 대본을 **끝까지** 감상하면 해금한다. 진입하거나 선택지 직전에 저장한 것만으로는 해금하지 않는다.
- 기록 보기에서 당시 본 대사, 선택한 답변, 완료 시 능력치와 최초 기록 시간을 확인한다. 다른 대사/선택 경로는 별도 기록으로 추가한다. 같은 경로를 다시 보면 최초 기록을 유지한다. 항목당 최대 32개 기록, 기록당 최대 10,000 프레임, 프로필 최대 64 MiB다.
- 회상 중 본편 명령·일정 자동 진행·연출·SD 시계를 차단한다. 닫으면 원래 본편 상태와 재생 위치로 돌아온다. 회상은 코어 명령을 실행하지 않으므로 보상·효과·난수를 다시 적용하지 않는다.

## 데이터와 저장

제작 계약은 `packages/schema/gallery.schema.json`, 프로필 계약은 `packages/schema/gallery-profile.schema.json`이다. 도감의 고정 ID는 출시 후 유지하고 다른 대본에 재사용하지 않는 것이 원칙이다. 소스 종류·ID도 기록에 저장하여 ID를 다른 대본에 재사용하더라도 기존 기록으로 잘못 해금하지 않는다.

플레이어의 저장 슬롯 폴더에 `collection-<gameId>.json`을 별도로 저장한다. 기본 위치는 SDL 사용자 설정 경로의 `RaisingEngine/<gameId>`이며, 테스트의 `--save`를 지정하면 그 파일의 부모 폴더를 사용한다. 콘텐츠 지문별로 프로필을 나누지 않는다. 새 게임·과거 실행 저장·재실행이 기존 해금을 지우지 않는다. 대본/항목 삭제 시 기록 자체는 보존하고 도감에서 숨긴다. 같은 ID로 복구하면 다시 표시한다.

저장은 프로세스 간 잠금을 획득하고 디스크 최신 기록과 합친 뒤 임시 파일·백업·이름 변경으로 수행한다. 본 파일이 사라진 중단 상태에서는 `.bak`을 읽는다. 손상 파일은 초기화하거나 덮어쓰지 않고 오류를 표시한다. 저장 실패 시 현재 프로세스의 미저장 해금은 유지하며 도감을 다시 열면 재시도한다. 파일 접근 문제를 해결하기 전에 프로그램을 닫으면 미저장 해금은 유지되지 않는다. 강제 종료 뒤 `.lock` 디렉터리가 남았다면 해당 게임 프로세스가 없는지 확인한 후 복구해야 한다. 클라우드 동기화/다중 기기 병합은 지원하지 않는다.

이벤트 도중 실행 저장을 불러오면 검증된 명령 이력으로 진행 중인 대사 기록을 재구성한다. 이 검증 재실행 자체로 과거 완료 사건을 새로 해금하지 않는다. 정상 플레이에서 이후 대본을 마쳤을 때 전체 대사를 기록한다.

## 지원 범위와 다음 확장

현재 **Qt 제작 + Windows 네이티브 플레이어**에서 지원한다. `narrative-gallery-v1` 능력 검사로 미지원 웹/구형 런타임 내보내기를 거부한다. 조용히 갤러리를 빠뜨리는 내보내기를 허용하지 않는다.

회상은 텍스트·선택·수치 스냅샷 뷰어다. 원래 애니메이션·음악·효과를 그대로 재실행하거나 자유롭게 선택을 바꾸는 모드가 아니다. 이미지 파일 자체는 프로필에 복사하지 않고 당시 배경 참조 또는 현재 도감 썸네일을 사용하므로 에셋을 교체/삭제하면 당시 그림을 보장하지 않는다. 언어를 바꾸어 회상을 다시 번역하지 않는다. 대본 도중 저장을 복원할 때 재구성되는 이전 대사는 프로젝트 기본 언어 기준이다.

다음 확장은 CG·음악 및 사용자 정의 수집품, 임의 조건 해금, 디자이너가 배치하는 도감 위젯, 애니메이션 포함 격리 회상, 웹 플레이어 프로필 저장이다. 현재 이를 완료한 것으로 보지 않는다.

## 검증

- Qt 실제 위젯: 샘플 복제, 3항목 제작, 중복 ID 방지, 추가·삭제·순서 이동, undo/redo, 저장·재열기·공통 검증.
- 실제 Windows 플레이어: 두 엔딩, 서로 다른 사건 선택 2개 기록, 미완료 사건 잠금, 중간 저장·복원 후 전체 대사, 과거 저장/새 게임/프로세스 재실행 보존, 회상 중 상태·RNG·타임라인·SD 불변, 같은 경로 중복 방지.
- 데이터 계약: 레거시 프로젝트, 참조·썸네일 타입·중복 ID, 실제 프로필 JSON Schema 검증, 미지원 웹 내보내기 거부.
- 파일 복구: 본 파일 유실 후 백업 읽기, 손상 파일 오류 표시와 원본 보존.

증거는 `.cache/gallery`와 `.cache/gallery-*.log`에 남긴다. `examples/last-grandson-polished/project.json`의 도감 설정은 Qt 위젯 제작 결과에서 가져왔다. 기존 사용자 프로젝트/저장 파일은 수정하지 않았다.

최종 결과: Qt 제작 시나리오 2개와 초기화/정리 통과, 네이티브·데이터 회귀 5건 통과. 마지막 저장 재시도 수정 후 도감 전체 시험을 다시 실행했고, 실제 파일 잠금을 해제한 같은 플레이어 프로세스에서 대기 중인 두 기록을 저장하는 것도 통과했다. 헤드리스·플레이어·편집기 TypeScript 검사와 공개 콘텐츠 경계 검사도 통과했다. 웹 GUI 지원을 검증했다는 뜻은 아니다.

검토 빌드:

- `Edit-Gallery-Lab.cmd`: 최신 Qt와 갤러리 런타임을 연결해 공개 샘플을 연다. 개인 편집용은 새 프로젝트에서 복제한다.
- `release/last-grandson-gallery-review/Play-Gallery-Review.cmd`: 검증에서 얻은 사건 두 선택·두 엔딩이 해금된 별도 검토 프로필.
- `release/last-grandson-gallery-review/Play-Fresh-Review.cmd`: 별도 빈 프로필로 시작하여 직접 해금. 이후 실행은 이 프로필을 유지한다.
- `dist/qt-studio-gallery/RaisingStudioQt.exe`, `dist/native-player-gallery/RaisingPlayer.exe`: 빌드 산출물. 기존 검토 폴더와 일반 사용자 프로필은 보존했다.
