# 목표 경로 그래프와 단계 비교

목표 경로 검사 창의 **경로 그래프 · 재생 / 비교**, 또는 자동 탐색 결과의 **발견 경로 그래프 · 재생 / 비교**에서 연다. 자동 탐색 결과는 회귀 테스트에 등록하기 전에도 볼 수 있다.

## 사용 순서

1. 기존 경로와 대체 경로를 선택하고 **현재 초안으로 불러오기**를 누른다. 기존 경로를 비우면 단일 경로 재생이다. 자동 탐색 결과에서 열면 참고한 원본 경로가 자동 선택된다.
2. 그래프는 동일한 명령과 상태가 유지되는 구간을 하나로 보여주고, 처음 달라지는 지점부터 좌우로 나뉜다. **첫 분기로**는 이 지점으로 이동한다. 최초 명령 차이와 최초 상태 차이를 따로 표시한다.
3. 노드를 선택하거나 이전·다음·단계 재생 버튼을 사용한다. **번호 동기화**를 끄면 좌우 단계 번호를 따로 선택할 수 있다. 번호 동기화는 날짜 정렬이 아니다. 서로 다른 시점이면 상세 영역에 표시한다.
4. **능력 · 자원 · 상태**에서 각 명령 전후 값, 각 경로의 증감, 두 경로의 실행 후 차이를 비교한다. **조건 차이**는 목표 조건의 전후 판정과 비교 값을 보여준다. **실제 행동 검사**는 해당 명령에 대한 런타임의 조건·비용·효과 추적이다.
5. 실패한 명령에서는 경로가 멈춘다. 실패 이후 명령을 실행한 것처럼 표시하지 않으며 미실행 수를 표시한다. 마지막 명령까지 실행했어도 목표를 달성하지 못했다면 마지막 노드를 실패로 표시한다. 실패 원문은 **명령 · 실패 원인**에서 확인한다.

## 비교의 의미

일반 경로 비교에서는 두 경로 모두 같은 **현재 콘텐츠 초안의 스냅샷**에서 각자 기록한 seed와 시작 조건으로 다시 실행한다. 수정 전 결과와 비교하려면 [기준 기록 저장과 과거 비교](goal-route-history.md)를 사용한다. 원본 경로 파일과 플레이 저장 파일은 변경하지 않는다.

목표 조건의 참/거짓은 조건식 평가 결과다. 사건 발동 시점, 엔딩 우선순위 등 전체 도달 판정과는 구분되며, 실제 목표 도달 여부는 실행 결과로 판정한다. 초기 조건이 다르면 처음부터 분리해서 표시한다.

비교 도중 초안을 수정하면 이전 스냅샷이라는 안내가 뜬다. 현재 초안으로 다시 불러와야 새 콘텐츠가 반영된다. 자동 탐색 후 콘텐츠가 변경되면 해당 탐색 결과는 다시 탐색해야 한다.

## 범위와 제한

- 단계 재생은 실제 런타임으로 계산한 상태와 명령 기록을 탐색하는 기능이다. 플레이어 화면이나 애니메이션을 동영상처럼 재생하지 않는다.
- 한 비교의 상태 데이터는 64 MiB, 재실행 시간은 60초로 제한한다. 한도를 넘으면 부분 결과를 성공으로 표시하지 않고 오류를 반환한다.
- 지도는 한 번에 60단계씩 표시한다. 지도 시작 단계와 단계 번호로 나머지 구간에 접근한다. Ctrl+휠로 확대·축소하고 지도를 드래그할 수 있다.
- 상태 표는 최대 2,000개 경로를 표시하며 초과 시 안내한다. 원시 상태 차이와 실패 정보도 상세 탭에 제공한다.
- 최근 비교 하나를 캐시한다. 새 비교를 불러오면 이전 창의 캐시는 만료되므로 다시 불러와야 한다.

## 검증

- `tests/analysis/goal-compare.test.mjs`: 명령 분기, 능력치 차이, 목표 조건, 비용·효과 추적, 실패 후 미실행, seed 차이, 앞뒤 재생, 초안 변경, 미등록 자동 탐색 결과 검증.
- `native/studio/goal-compare-test.inc`: 실제 Qt 위젯의 경로 선택, 그래프 노드 선택, 첫 분기 이동, 단계 재생, 좌우 독립 이동, 종료 실패 표시, 미등록 탐색 결과 열기.
- 증거 위치: `docs/evidence/route-compare/`. 별도 시험 프로젝트에서 수행하며 사용자 원본 파일은 보존한다.
