# 편집 캔버스 내장 재생 검증

2026-10-22. Windows / Qt 6.10.1 / SDL3·RmlUi 플레이어.

## 변경과 보호 범위

- 편집기의 현재 초안과 검사 상태를 임시 번들로 내보내고, 별도 플레이어 프로세스를 캔버스에 연결한다.
- 재생·일시정지·계속·초기화·편집 복귀를 제공한다. 일시정지는 게임 입력, 연출·대화·확장 시간과 오디오 엔진을 함께 멈춘다.
- 저장·자동 저장·도감·환경설정은 임시 세션 경로만 사용한다. 검사 저장은 같은 프로세스가 기억한 기준 상태에서 명령 재현을 통과해야 하며 일반 저장 로더에서는 거부한다.
- 초기화는 새 프로세스와 새 저장 폴더를 사용한다. 콘텐츠·검사 문맥 변경은 실행을 끝내며, 오래된 결과를 새 편집 문맥에 적용하지 않는다.
- 기존 정지 화면 검사, 저장 재현 규칙과 프로젝트 데이터 계약을 유지한다.

## 확인한 결과

- `tests/native-player/editor-live.test.mjs`: 실제 Windows 플레이어의 연출 시간 진행, 일시정지 중 시간·입력 차단, 재개, 임시 저장·불러오기, 일반 로더의 검사 저장 거부, 프로젝트·원본 저장 보존.
- `tests/native-player/authoring-preview.test.mjs`, `tests/qt-studio/authoring-preview.test.mjs`: 기존 정지 화면 검사와 캐릭터별 데이터·표현·저장 재현 회귀. 위 신규 테스트와 합계 11개 통과.
- `qt-canvas-live-test`: 공방 사본의 실제 Qt 창과 내장 Windows 플레이어에서 저장 상태 일치, 버튼으로 사건 실행, 음악·효과음 로드, 캐릭터 연출, 정지 중 음악 커서 불변, 재개 후 증가, 임시 저장·복원, 초기화, 편집 배치 저장과 프로젝트 재열기, 재열기 후 다시 재생을 검증했다. 원본 저장 바이트 일치. 정상 종료까지 통과.
- `qt-canvas-state-test runtimeGeometryKeepsAuthoredCoordinates`: 실제 렌더링 좌표와 설계 좌표가 다를 때 배치 편집 좌표 보존.
- 실제 편집기 창에서도 재생 버튼 → 사건·소리 버튼 → 두 캐릭터 연출 → 일시정지 → 정지 중 입력 차단 → 초기화를 직접 조작했다. 창 안의 게임 화면과 편집기의 정지·임시 상태 안내를 확인했다.
- 한국어·영어·일본어 편집기 번역 검사 통과.

공방의 원본에는 검증에 필요한 연속 동작·소리가 없어 별도 사본에 진단용 연출·짧은 소리와 버튼을 준비했다. 이 데이터 준비를 GUI 제작 시험으로 주장하지 않는다. 사본, 저장과 화면 증거는 비공개 작업 폴더에만 보관한다.

## 범위와 재현

`RAISING_NATIVE_PLAYER_RUNTIME`에 최신 Windows 플레이어 경로를 설정하고 위 Node 테스트를 실행한다. Qt 통합 시험은 `RAISING_CANVAS_LIVE_PROOF`의 JSON 설정(`root`, `output`, `save`)과 별도 `RAISING_EDITOR_SETTINGS`를 받는다. 시험 사본에는 `home/heading`, `proof-motion`, `proof-event`, 저장·불러오기 버튼이 필요하다. 실제 프로젝트에 직접 실행하면 배치 저장 시험으로 제목 요소가 한 칸 이동하므로 반드시 폐기 가능한 사본을 사용한다.

기존 `direction.test.mjs`는 외부에서 생성한 `.cache/direction-proof.json`이 없어 이번 호출에서 준비 단계 오류가 났다. 해당 별도 시험은 통과로 계산하지 않았다. 이번 기능의 연출·저장 재생은 위 신규 플레이어/Qt 통합 시험으로 검증했다.

Windows 내장 재생만 검증했다. 웹·모바일 내장 재생, 장시간 오디오 스트레스, 모든 애니메이션 플러그인 조합은 이번 범위에 포함하지 않는다. 임시 세션 저장은 편집기 종료 후 이어하는 용도가 아니며 초기화 후에는 사용할 수 없다.
