# RaisingEngine 0.1.0-preview.3

Windows x64 preview. The Qt editor is named **Raising Studio**; exported Windows games use **RaisingPlayer.exe**.

This is an unsigned preview, not a stable release. Keep your projects and saved games outside the installation folder and retain backups before upgrading. The editor language setting is independent of your game's languages. English/Japanese include advanced tools and catalogued service diagnostics. Unknown external errors keep their source text. Sample content is not automatically translated. Binary templates use MIT geometric sample images; see `licenses/SAMPLE-ASSETS.md`.

The package contains MIT engine code, separate third-party notices in `licenses/`, and the corresponding Qt sources in `licenses/qt/sources/`. See the installed `THIRD_PARTY_NOTICES.md` and `licenses/README.md`. Optional animation plugins are installed separately.
