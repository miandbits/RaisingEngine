# RaisingEngine 0.1.0-preview.1

Windows x64 preview. The Qt editor is named **Raising Studio**; exported Windows games use **RaisingPlayer.exe**.

- [한국어: 설치 → 첫 게임 → 내보내기](ko.md)
- [English: install → first game → export](en.md)
- [日本語：インストール → 初めてのゲーム → 書き出し](ja.md)

This is an unsigned preview, not a stable release. Keep your projects and saved games outside the installation folder and retain backups before upgrading. The editor language setting is independent of your game's languages. English/Japanese cover the preview's main workflow; advanced authoring tools and service diagnostics can still show Korean. Sample content is not automatically translated.

The package contains MIT engine code, separate third-party notices in `licenses/`, and the corresponding Qt sources in `licenses/qt/sources/`. See the installed `THIRD_PARTY_NOTICES.md` and `licenses/README.md`. Optional animation plugins are installed separately.
