# インストールして初めてのゲームを作る

## インストール

1. 検証済み配布元の Windows x64 インストーラーを使用し、付属の `.exe.json` または `SHA256SUMS.txt` と SHA-256 を照合してください。
2. インストール言語を選び、**新しいフォルダー**を指定します。既存のフォルダーは上書きしません。更新版も別のフォルダーにインストールします。
3. インストール先の `RaisingStudioQt.exe` を実行します。Node.js や Qt の開発環境は不要です。このプレビューは未署名で、クリーンな Windows VM での検証はまだ完了していません。
4. プロジェクト管理画面の **エディター言語 → 日本語** を選び、エディターを再起動します。編集中は **表示 → 언어 / Language / 言語…** からも設定できます。ゲームのテキストやセーブデータには影響しません。高度なツールと登録済みのエラーにも英語・日本語で対応します。サンプルの名前や物語、未知の外部エラーの原文は保持します。

## 制作とプレイ

1. **新規プロジェクト**で **探索・戦闘** を選択します。インストール先とは別の空フォルダーを指定し、**プロジェクトを作成**を押します。元のサンプルは保持されます。
2. **ファイル → プロジェクト設定…**でゲームのタイトルを変更し、適用・保存します。最初のテストではカレンダーと能力の範囲はそのままにします。
3. コンテンツ検索で活動 `휴식`（休息）を探します。**選択したコンテンツを編集…**から名前と数値効果を1つ変更します。接続用のIDは変更しないでください。
4. **プロジェクトを保存 → 検証**を押します。エラーをダブルクリックすると修正箇所に移動します。構造の検証だけではすべてのエンディングへの到達を保証しません。
5. 画面を開き、テキストやボタンを追加します。**インスペクター**で文字・位置・サイズを設定し、ボタンの **行動・クリック時** に行動と有効な対象を接続します。保存して再検証します。
6. **▶ 最初からプレイ**を押します。スケジュール選択、街・ショップ、会話を進めます。途中でゲームの保存ボタンまたは Windows プレイヤーの **F5** で保存し、別の行動後に読み込みボタンまたは **F9** で復元します。プロジェクト保存とプレイ進行の保存は別の操作です。

## ゲームの翻訳

**デザイン → 翻訳ワークスペース…**で `en`、`ja` などを追加してテキストを翻訳します。初期言語、代替言語、言語別フォントを設定できます。空の翻訳には代替言語または原文を表示します。原文を変更した場合は古い翻訳を確認してください。`%1` や `{value}` などの置換表記は意味を維持します。再配布可能なフォントをインポートし、文字が正しく表示されることを確認してください。キャンバスのゲーム言語はエディター言語とは独立しています。物語やサンプルの名前は自動翻訳されません。

## 書き出し

1. **ファイル → ゲームを書き出す…**から Windows または Web を選び、既存の親フォルダーと**新しい出力フォルダー名**を指定します。未保存の変更も書き出されますが、プロジェクト自体は自動保存されません。
2. Windows は出力先の `RaisingPlayer.exe` を実行します。Web は `wasm/`、フォント、アセットを含む**フォルダー全体**を HTTP(S) 静的ホストに公開します。`file://` で直接開く方法には対応していません。Python がある開発PCなら `python -m http.server 8080 --directory "Web出力先"` を実行し、`http://localhost:8080` を開けます。
3. 書き出したゲームでもプレイ・保存・読み込みを確認します。Web のセーブはファイルとしてダウンロードし、読み込み入力で復元します。ブラウザーの外にもコピーを保管してください。
4. 書き出しに失敗したら原因を修正して再試行します。コンテンツを変更した場合は書き出し画面を開き直してください。既存の出力先は保持されます。

更新前にはプロジェクトとセーブをバックアップします。古いセーブは **ファイル → コンテンツ更新・セーブ移行／復旧…** で差分を確認してください。アンインストールには `Uninstall.exe` を使います。インストール先とは別のユーザープロジェクトは保持されます。モバイル・コンソールはこのプレビューの検証対象ではありません。

## ダウンロードと更新

[GitHub Releases](https://github.com/miandbits/RaisingEngine/releases) のバージョン別ファイルを使用します。`.exe` はインストール用、`-portable.zip` は全体を展開して実行するポータブル版です。どちらもランタイムと第三者ライセンスを含みます。`SHA256SUMS.txt` を照合してください。インストーラーはスタートメニューと Windows のインストール済みアプリに登録します。更新版は別フォルダーへインストールし、プロジェクトはその外に保存します。ポータブル版は `RaisingStudioQt.exe` を実行します。デスクトップアプリのインストールに GitHub Packages は不要です。ドラフトの配布物は公開前の管理者レビュー用です。
