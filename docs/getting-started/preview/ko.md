# 설치하고 첫 게임 만들기

## 설치

1. 검토된 Windows x64 프리뷰 설치 파일을 사용합니다. 함께 제공된 `.exe.json` 또는 `SHA256SUMS.txt`의 SHA-256과 비교합니다.
2. 설치 언어를 선택하고 **새 설치 폴더**를 지정합니다. 기존 폴더는 덮어쓰지 않습니다. 업데이트도 다른 폴더에 설치합니다.
3. 설치 폴더의 `RaisingStudioQt.exe`를 실행합니다. Node·Qt 개발 도구는 별도로 필요하지 않습니다. 이번 프리뷰는 코드 서명이 없으며 깨끗한 Windows VM에서의 검증은 아직 완료되지 않았습니다.
4. 프로젝트 선택기의 **편집기 언어**에서 한국어·English·日本語를 선택하고 편집기를 다시 실행합니다. 편집 중에는 **보기 → 언어 / Language / 言語…**에서도 설정할 수 있습니다. 게임의 언어와 저장 데이터는 바꾸지 않습니다. 고급 도구와 등록된 편집기 오류도 영어·일본어로 표시합니다. 샘플 이름과 이야기, 알 수 없는 외부 오류의 원문은 유지합니다.

## 첫 제작과 플레이

1. 새 프로젝트에서 **탐험·전투**를 선택하고 설치 폴더 밖의 빈 폴더를 지정한 뒤 **프로젝트 만들기**를 누릅니다. 원본 샘플은 그대로 유지됩니다.
2. **파일 → 프로젝트 설정…**에서 게임 제목을 바꾸고 적용·저장합니다. 첫 시험에서는 달력과 능력 범위는 유지합니다.
3. 콘텐츠 검색에서 활동 **휴식**을 찾습니다. **선택한 콘텐츠 편집…**에서 이름과 수치 효과 하나를 바꿉니다. 첫 시험에서는 연결용 ID를 유지합니다.
4. **프로젝트 저장 → 검증**을 누릅니다. 오류를 더블클릭하면 수정할 위치로 이동합니다. 구조 검증을 통과해도 모든 엔딩의 도달성을 보장하지는 않습니다.
5. 화면을 열고 텍스트나 버튼을 추가합니다. **속성**에서 문구·위치·크기를 바꾸고, 버튼에는 **행동 · 클릭했을 때**에서 행동과 유효한 대상을 연결합니다. 저장하고 다시 검증합니다.
6. **▶ 처음부터 플레이**를 누릅니다. 일정 선택, 도시·상점, 대화를 진행합니다. 중간에 저장 버튼 또는 Windows 플레이어의 **F5**로 저장하고, 다른 행동 뒤 불러오기 버튼 또는 **F9**로 복원합니다. 프로젝트 저장과 플레이 진행 저장은 별도입니다.

## 게임 번역

**디자인 → 다국어 작업실…**에서 `en`, `ja` 등을 추가하고 문구를 번역합니다. 시작 언어·대체 언어와 언어별 폰트를 지정할 수 있습니다. 빈 번역은 대체 언어와 원문으로 표시합니다. 원문이 바뀌면 기존 번역을 재검토합니다. `%1`, `{value}` 같은 치환 표시는 의미를 유지해야 합니다. 재배포 가능한 폰트를 가져오고 실제 글자 표시를 확인하세요. 캔버스의 게임 언어 선택은 편집기 언어와 별개입니다. 샘플의 이야기나 이름이 자동으로 번역되지는 않습니다.

## 내보내기

1. **파일 → 게임 내보내기…**에서 Windows 또는 Web, 기존 상위 폴더와 **새 출력 폴더 이름**을 정합니다. 미저장 초안도 내보내기에 포함되지만 프로젝트가 자동 저장되지는 않습니다.
2. Windows는 출력 폴더의 `RaisingPlayer.exe`를 실행합니다. Web은 `wasm/`·폰트·에셋을 포함한 **전체 폴더**를 HTTP(S) 정적 호스팅에 올립니다. `file://`로 직접 열 수 없습니다. Python이 설치된 개발 PC에서는 `python -m http.server 8080 --directory "웹 출력 폴더"`로 실행한 뒤 `http://localhost:8080`을 엽니다.
3. 내보낸 게임에서 플레이·저장·불러오기를 다시 확인합니다. Web 저장은 파일로 내려받고 불러오기 입력에서 복원하여 브라우저 밖에도 보관합니다.
4. 실패하면 오류를 수정하고 재시도합니다. 콘텐츠를 바꿨다면 내보내기 창을 다시 엽니다. 기존 출력 폴더는 보존됩니다.

콘텐츠 수정 전에는 프로젝트와 저장을 백업하세요. 오래된 저장은 **파일 → 콘텐츠 업데이트 · 저장 이전 / 복구…**에서 차이를 검토합니다. 제거는 설치 폴더의 `Uninstall.exe`를 사용합니다. 설치 폴더 밖의 사용자 프로젝트는 유지합니다. 모바일·콘솔은 이 프리뷰의 검증 대상이 아닙니다.

## 다운로드와 업데이트

[GitHub Releases](https://github.com/miandbits/RaisingEngine/releases)의 버전별 파일을 사용합니다. `.exe`는 설치용, `-portable.zip`은 전체 압축을 풀어 실행하는 무설치용입니다. 두 파일 모두 런타임과 제3자 고지를 포함합니다. `SHA256SUMS.txt`로 확인하세요. 설치판은 시작 메뉴 바로가기와 Windows 설치된 앱 항목을 등록합니다. 새 버전은 별도 폴더에 설치하고 프로젝트는 설치 폴더 밖에 보관합니다. 무설치판은 `RaisingStudioQt.exe`를 실행합니다. 데스크톱 앱 설치에 GitHub Packages는 필요하지 않습니다. 초안 릴리스의 파일은 공개 점검이 끝나기 전 관리자 검토용입니다.
