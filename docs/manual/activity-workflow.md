# Edit an activity and its presentation together

Open **Tasks → Create content → Edit activity, conditions and presentation together…**, or the same command in Design. Choose an activity by its displayed name. The editor keeps that activity selected when returning from presentation editing.

Edit the activity's description, costs, requirements and effects in the activity form. Its presentation controls show the linked default, success and failure timelines. Open a linked timeline to edit its clips with the normal timeline editor, then return to the activity form. The activity edits remain in the draft while the timeline is open. Check shared uses before changing a timeline: a shared timeline also affects the other activities linked to it.

Saving the inner timeline only updates this activity-editing draft. Save the outer activity form to apply the activity and presentation changes together. Cancel the outer form to discard both. The applied change is one Undo step; project Save writes it to disk. If another editor operation has changed the project or revision, reopen the form instead of applying a stale draft.

Presentation changes do not change the rules of success or failure. Costs and effects remain gameplay edits. Play the actual activity to inspect its execution and growth result, and compare recorded routes after changing its rules. Export and save-compatibility review retain their existing validation gates.

To reuse the surrounding interface, see [shared screen sections](shared-screen-sections.md). Schedule, stats and growth-result widgets can be component children, so the same settings can be maintained from their component source.
