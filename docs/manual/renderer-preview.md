# 실제 렌더러 검사

Qt 캔버스의 빠른 배치 도구와 별도로, 배포용 Windows SDL/RmlUi 플레이어가 그린 이미지를 도킹 패널에서 검사한다. 이번 단계는 Windows 실제 렌더링을 기준으로 한 정지 화면 검사이며, Qt 캔버스 자체가 배포 렌더러로 교체된 것은 아니다.

## 사용 순서

1. `Edit-PM2-Renderer.cmd`를 실행한다. 기존 `projects/pm2-components-lab` 테스트 프로젝트가 열린다.
2. 프로젝트 목록에서 **부품 상품 진열 A/B**, 또는 검사할 화면을 연다.
3. 위 도구 모음의 **실제 렌더러 검사**를 누른다. 패널은 도킹하거나 떼어 내어 크게 볼 수 있다. 보기 메뉴에서 다시 표시할 수 있다.
4. 해상도와 언어를 고른 뒤 **현재 화면 렌더링**을 누른다. 직접 너비·높이를 입력할 수도 있다. 반응형 화면은 앵커를 재계산하고 비율 유지 화면은 여백을 포함해 표시한다.
5. 검사 대상에서 버튼 또는 `배치본ID__자식ID`를 고른다. 기본·마우스 올림·누르는 중·키보드 초점·비활성 모양을 비교한다. 이것은 모양 검사이며 버튼의 게임 행동을 실행하지 않는다.
6. **비교 기준으로 보관**을 누르고 언어·해상도·상태를 바꿔 다시 렌더링하면 두 결과를 나란히 볼 수 있다.
7. 파란 테두리는 렌더러의 버튼 영역, 노란 테두리는 선택 요소의 영역이다. 이미지나 아래 검사 표를 누르면 해당 요소를 편집기에서 선택한다. 부품 자식은 화면의 배치본을 선택한다.
8. 원본을 수정하면 이전 결과라는 표시가 나타난다. 다시 렌더링해 수정 결과를 확인한다. 게임 흐름·실제 구매 등은 기존 **처음부터 플레이**로 검증한다.

렌더링 중 취소할 수 있다. 취소한 프로세스가 종료되기 전에는 재실행하지 않아 이전 결과가 새 요청과 섞이지 않는다.

## 검사 정보

- 요소의 실제 논리 좌표·크기, 버튼 영역과 화면에 남아 있는 영역.
- 장소 목록·일정 등 복합 위젯의 내부 버튼도 개별 항목으로 검사한다. 내부 버튼을 선택하면 편집기의 원래 위젯을 선택하고, 검사 대상에는 내부 버튼을 유지한다. 매우 큰 화면은 내부 버튼 진단을 1,024개로 제한하고 생략 여부를 표시한다.
- 렌더러의 텍스트 배치·스크롤 크기에 따른 가로/세로 넘침, 잘림, 화면 밖 영역.
- 실제 중심점 hit test에 따른 버튼 중앙 가림. 이는 버튼 사각형 전체의 모든 점을 검사한다는 뜻은 아니다.
- 현재 상태에서 숨겨진 요소, 사용 불가 버튼.
- 검사 표의 툴팁에 실제 적용 폰트·크기·색과 텍스트 측정 여부.

‘영역 내’는 현재 검사에서 해당 문제가 발견되지 않았다는 뜻이다. 글리프의 모든 픽셀, 모든 중첩 클리핑·입력 상태를 보증하는 결과는 아니다. 키보드 초점 모양은 확인하지만 전체 탭 이동·게임패드 탐색 순서는 이 패널에서 자동 검증하지 않는다.

## 저장과 게임 상태의 격리

`preview` 서비스는 공용 편집 서비스의 메모리 초안을 검증하고 임시 번들로 만든다. 프로젝트를 자동 저장하지 않으며 dirty, revision, undo/redo 및 디스크 파일을 유지한다. 미리보기 준비 전후 버전과 디스크를 검사하고 충돌하면 실행을 거절한다.

임시 파일은 `.cache/qt-render-preview/run-*`에 놓는다. 사용자 세이브를 로드하지 않고, 미리보기 모드의 게임 명령·수동 저장·자동 저장을 막는다. 일반 플레이 모드는 기존대로 동작한다. 구형 런타임에는 `renderer-preview-v1` 기능 표식이 없어 미리보기를 실행하지 않는다.

화면은 **초기 게임 상태**로 표시한다. 화면 이동을 강제로 수행하지 않고 표시 화면만 선택하므로, 상점·전투·대화처럼 특정 진행 상태가 필요한 위젯은 빈 내용이나 사용 불가 버튼을 표시할 수 있다. 실제 세이브에서 진행 상태를 가져오기, 사건/전투 상태 프리셋, 렌더러를 캔버스에 실시간 삽입하기, 웹·모바일·콘솔 렌더러 비교는 후속 작업이다.

## 관련 구현과 재현

- Qt 패널: `native/studio/renderer-preview.cpp`, `.hpp`.
- 공용 초안 내보내기: `apps/qt-studio/service.mjs`의 `preview`.
- 실제 배치 진단과 격리 모드: `native/player/preview.hpp`, `main.cpp`, `screen.hpp`.
- 서비스 검사: `node --test tests/qt-studio/renderer-preview.test.mjs`.
- 실제 렌더러 검사: `node scripts/verify-renderer-preview.mjs` (기존 부품 검증 샘플 필요).
- GUI 통합 검사: `QT_STUDIO_OUT=dist/qt-studio-render-preview`로 `node scripts/test-qt-studio.mjs`.

2026-10-12 검증: 전체 Qt 테스트 **11/11**, 미리보기·부품·다국어 서비스 계약 테스트 **9/9** 통과. 실제 네이티브 실행에서 한/영, 5가지 버튼 상태, 긴 문구 넘침, 버튼 중앙 가림, 복합 위젯 내부 버튼, 선택 화면 표시, 게임 명령·저장·자동 저장 격리를 통과했다. 일반 플레이의 기존 Qt 회귀도 통과했다. 결과 이미지와 보고서는 `docs/evidence/renderer-preview`에 보존했다.
