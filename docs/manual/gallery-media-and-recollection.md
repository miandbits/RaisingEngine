# CG·음악 도감과 원본 연출 회상

## 제작

Qt **프로젝트 설정 → 회상 · CG · 음악 도감**에서 사건, 엔딩, CG 이미지, 음악 에셋을 선택한다. 고정 ID, 제목, 분류, 잠금 힌트, 썸네일, 표시 순서를 설정한다. `해금 조건`은 기존 조건 편집기를 연다. 능력·자원·관계·소지품·플래그·사건 완료와 AND/OR를 같은 계약으로 작성한다.

- 사건·엔딩: 대본 완료 상태에서 조건이 참이면 해금한다. 조건 생략은 완료만 요구한다.
- CG·음악: 새 게임, 성공한 행동, 정상 실행 저장 불러오기 후 조건을 검사한다. 조건 생략은 새 게임부터 해금한다. 회상이나 저장 검증용 명령 재실행에서는 검사하지 않는다.
- 잠금 표시: 제목·그림을 가리고 힌트만 표시하거나 항목 자체를 숨긴다.
- CG 맞춤: 이미지 전체 보기/영역 채우기. 음악: 재생/일시정지/처음으로 정지.

프로젝트 저장·undo/redo·공통 검증을 사용한다. 중복 ID, 없는 대본/에셋, 잘못된 이미지·오디오 유형, 해금 조건 참조 오류를 위치와 함께 검사한다. `project.gallery`는 선택형이며 기존 도감 설정과 텍스트 기록을 계속 읽는다. 콘텐츠 변경은 지문을 바꾸므로 이전 실행 저장의 자동 마이그레이션과는 별개다.

## 원본 연출 회상

사건·엔딩 상세의 **원본 연출 회상**은 당시 방문한 대본 상태, 화면 구성, 배경, 초상화 변환, UI 모션, 애니메이션 플러그인 상태, BGM·장면 효과음을 별도의 읽기 전용 세션으로 재생한다. 기록된 선택만 허용하며 다른 분기·구매·화면 이동 등 본편 행동은 비활성화한다. 마지막 대사 뒤의 장면 변경도 보존한다. 기존 대사 기록과 완료 당시 능력치 보기 역시 남아 있다.

회상은 진행 명령을 실행하지 않으므로 효과·보상·난수·사건 완료·해금을 다시 적용하지 않는다. 본편 세션, 명령 이력, 일정/SD 시계를 보존하고 본편 음악 장치의 시계를 정지한다. 별도 오디오 장치와 ABI v1 플러그인의 별도 모듈 사본을 사용하여 플러그인 전역 상태도 격리한다. 닫으면 본편을 이어간다.

회상 상단 저장/불러오기 또는 F5/F9는 `recollection-<gameId>.json`에 위치·선택 경로 식별·애니메이션 상태·음악 위치를 기록한다. 일반 슬롯은 쓰지 않는다. 앱 재실행 후 같은 도감 기록에서 불러올 수 있다. 다른 선택 경로의 저장은 거부한다.

원본 콘텐츠 스냅샷과 방문한 상태를 보존하며 에셋 파일·플러그인 바이너리는 복사하지 않는다. 현재 번들의 에셋 해시 또는 플러그인 구성과 다르면 원본 연출 재생을 거부하고 대사 기록은 남긴다. 이전 텍스트 전용 기록에는 회상 버튼이 없으며 같은 경로를 본편에서 다시 보면 연출 기록을 보충한다. 이전 버전의 사건 중간 저장은 대사/상태를 재구성할 수 있지만 당시 기록하지 않은 플러그인 재생 시점은 복원할 수 없다.

범위는 대본 장면 명령과 당시 UI/플러그인 연출이다. 별도 UI 행동으로 실행한 임의 연출 시퀀스, 마우스 이동, 실제 대기 시간까지 녹화한 영상은 아니다. 대사는 기록 당시 언어를 보존한다.

## 데이터·지원 범위

계약은 `gallery.schema.json`, `gallery-profile.schema.json`이다. 회차 공통 프로필·파일 잠금·백업·손상 복구 정책은 [1단계 문서](gallery-and-recollection.md)를 따른다. 최대 항목 2,000개, 항목당 기록 32개, 기록당 대사/회상 프레임 각 10,000개, 프로필 64 MiB다. 콘텐츠·상태 스냅샷이 용량을 사용하므로 장편에는 별도 보관 파일과 중복 제거가 후속 과제다.

현재 검증 범위는 **Qt 제작 + Windows 네이티브 플레이어**다. 기존 도감은 `narrative-gallery-v1`, CG/음악/해금 조건·잠금 표시 설정은 `media-gallery-v2` 능력을 요구한다. 웹과 미지원 구형 런타임은 내보내기를 거부한다. 도감 전체를 자유 배치하는 위젯, 임의 수집품, 클라우드 동기화는 후속 범위다.

## 검증 증거

- Qt 실제 위젯: 샘플 복제, 사건·엔딩 3개와 CG·음악 2개 제작, 기예/신뢰 조건, 표시 설정, 중복 ID 오류, 순서 이동, undo/redo, 저장·재열기·공통 검증.
- Windows 플레이: 두 달 일정, 사건·엔딩 해금, 조건 전 CG 잠금/음악 숨김, CG 표시, 음악 재생/일시정지/정지, 원본 화면 회상, 중간 회상 저장·복원, 앱 재실행.
- 격리: 회상 전후 본편 상태/RNG·명령 이력·프로필·플러그인 상태·음악 시계, 본편 슬롯 불변, 일반 저장 재개.
- 추가 엔진 시험 데이터: 대사 전 배경/BGM/SFX/초상화 변환, 마지막 선택 뒤 장면/BGM 정지. 이 추가 데이터는 GUI 제작 증거와 구분한다.
- 호환: 이전 텍스트 프로필, 변경 원본 에셋 거부, 실제 프로필 JSON Schema, 조건 참조/에셋 유형, 기존 두 엔딩·파일 잠금/손상 복구 회귀.
