# 편집 가능한 사건·엔딩 선택 분기 도감

## 제작과 사용

프로젝트 설정 → 회상·CG·음악 도감 → **편집 가능한 선택 분기 화면 만들기** → 설정 적용.
생성된 `도감 · 선택 분기` 화면과 `도감 · 선택 분기 카드` 부품은 일반 화면/부품입니다.
데이터·UI 연결에서 열 수·스크롤·행 높이·필터·정렬·표시 조건·버튼 연결을 편집합니다.
기존 고정 도감에서도 분기 화면만 추가할 수 있습니다.

기본 도감의 사건 상세에서 **선택 분기 보기**를 누릅니다. 작성된 상세 화면이 이미 연결되어
있으면 생성기가 진입 버튼을 추가합니다. 상세 화면을 나중에 만들었거나 직접 제작한 경우
일반 버튼에 `galleryBranches` 행동을 연결하세요. 대상은 현재 선택한 도감 항목 또는
편집기에서 지정한 항목입니다.

사건/엔딩의 시작 노드에서 연결된 선택 지점마다 선택지 카드를 자동으로 만듭니다.
선택지가 없는 이야기는 빈 목록입니다. 조건 분기는 실행하지 않고 양쪽 연결을 조사하며,
이야기에 연결되지 않은 노드는 제외합니다. 모든 선택 조합을 가상으로 플레이하거나
해금하지 않습니다.

- 경험한 선택: 선택 내용, 선택 질문, 저장된 기록 수, 회상 버튼을 표시합니다.
- 미경험 선택: 선택 내용은 `미경험 선택지`, 상태는 잠금입니다. 방문하지 않은 선택 지점의
  질문도 숨깁니다. 이후 대사·결과는 표시하거나 실행하지 않습니다.
- 회상은 해당 선택을 실제로 한 원본 기록을 처음부터 재생합니다. 동일 선택을 포함하는
  기록이 여러 개면 저장 순서상 첫 원본 연출 기록을 사용합니다. 카드 단위는 전체 조합이
  아니라 **선택 지점 + 선택지**입니다. 이후 선택도 그 기록에 남은 경로를 따릅니다.
- 대사만 남은 구형 기록은 경험 여부를 표시하되 원본 연출 회상 버튼은 비활성화합니다.

## 데이터 계약

선택 설정 `project.gallery.branchScreenId`: 기존 도감·회상 화면과 다른 유효한 화면 ID.
새 데이터 원본 `galleryBranches`: 현재 선택한 사건/엔딩의 분기 행.

| 필드 | 용도 |
| --- | --- |
| `name`, `prompt`, `statusText` | 선택 내용·질문·잠금/경험 상태 |
| `entryId`, `branchId` | 도감 항목과 선택 분기의 안정적인 대상 ID |
| `unlocked`, `locked`, `canReplay` | 잠금 표시 조건과 버튼 활성화 |
| `recordCount`, `recordIndex`, `selected` | 기록 수·첫 재생 가능 기록 번호·현재 기록 포함 여부 |
| `action` | `galleryBranch` (그 분기를 포함하는 원본 기록 회상) |

카드 버튼의 `entryId`·`branchId`에는 같은 이름의 필드를 연결하고 `enabled`에는
`canReplay`를 연결합니다. 잠금 판정은 UI 표시와 별개로 실행 시 다시 확인합니다.
클릭으로 본편 명령이나 해금 효과를 실행하지 않습니다.

기존 `collection-<gameId>.json`의 방문 노드/선택 기록을 조회하므로 프로필 형식 변경은
없습니다. 본편 저장·불러오기·새 게임·프로세스 재시작과 독립적으로 경험 기록이 유지됩니다.
회상 저장은 이전과 같이 같은 기록에만 적용되며, 다른 선택 경로의 저장은 적용 전에
거부합니다. 기존 32개 기록/항목 및 프로필 용량 한도, 원본 콘텐츠/플러그인 호환 정책은
유지됩니다. 현재 콘텐츠에서 삭제된 선택지는 현재 분기 목록에 표시하지 않습니다.

Windows 네이티브 실행 지원입니다. `gallery-branches-v1` 없는 런타임으로는 내보내기를
거부하며, 부품 덮어쓰기에만 행동이 있는 경우도 검사합니다.

## 검증과 결과물

- Qt `galleryBranchesAuthoring`: 새 프로젝트 복사 → 설정 창에서 분기 화면 생성 → 실행 취소/
  다시 실행 → 데이터 연결 확인 → 카드 버튼 문구 변경 → 저장/재열기 → 의미 검증 오류 0.
  공개 샘플에는 이 GUI가 저장한 화면·카드·연결만 복사했습니다.
- `tests/native-player/gallery-branches.test.mjs`: GUI 제작 프로젝트를 실제 Windows 플레이어로
  두 회차 플레이합니다. 첫 회차의 한 분기 잠금, 두 번째 회차 후 두 분기 해금, 각 기록의
  회상·중간 저장/불러오기·새 프로세스 복원, 다른 분기 저장 거부를 검사합니다.
  본편 상태/RNG·명령·본편 슬롯·도감 프로필의 불변도 확인합니다.
- 분기 투영 검사: 중첩 선택, 연결되지 않은 노드, 잘못된 사건 ID, 구형 대사 기록,
  미경험 문구 보호, 입력 불변, 구형 렌더러 차단.
- 증거: `.cache/gallery-branches/`의 편집기 스크린샷, `one-branch.png`, `both-branches.png`,
  플레이별 `*-report.json`. 프로젝트·게임·저장은 각각 `editor-project.txt`, `game-path.txt`,
  `save-path.txt`에 경로를 기록합니다.

`Edit-Gallery-Branches-Lab.cmd`는 별도 리뷰 프로젝트와 새 Qt/네이티브 플레이어 빌드를
연결합니다. 기존 사용자 프로젝트와 이전 빌드는 수정하지 않습니다.
