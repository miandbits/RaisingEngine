# UI 다중 선택과 재사용 부품 편집

화면의 캔버스·계층, 부품 원본의 캔버스·요소 목록에서 같은 **선택 요소 일괄 편집 · 정렬…** 도구를 사용한다. 프로젝트와 저장 파일 형식은 바뀌지 않는다.

## 선택하고 배치하기

1. 캔버스에서 Ctrl/Shift를 누른 채 요소를 눌러 선택을 추가하거나 해제한다. 빈 공간에서 드래그하면 사각형에 완전히 들어온 요소를 선택한다. 계층에서는 Ctrl/Shift로 여러 행을 선택한다.
2. 선택한 요소를 드래그하면 함께 이동한다. 방향키는 1px, Shift+방향키는 10px 이동한다. 부모와 자식을 함께 선택해도 자식이 두 번 이동하지 않는다.
3. 캔버스 도구 막대, 계층 우클릭, 속성 패널에서 **일괄 편집 · 정렬…**을 연다.
4. 함께 이동, 좌우·위아래·중앙 정렬, 가로·세로 간격 맞춤을 선택한다. 정렬은 독립 요소 2개, 간격 맞춤은 3개 이상이 필요하다. 선택 영역의 바깥 경계를 기준으로 정렬하고, 간격 맞춤은 요소 크기를 제외한 여백을 같게 만든다.

위치 변경은 잠긴 요소·잠긴 부모, 자동 배치 그룹의 자식, 화면 밖으로 나가는 결과를 검사한다. 실패하면 전체 변경을 거부하고 이유를 표시한다. 일부 요소만 움직이지 않는다. 자동 배치 자식의 위치는 그룹의 배치 설정에서 조정한다.

## 서로 다른 값을 보존하는 일괄 속성

너비·높이·글자 크기·불투명도·숨김·잠금·공통 스타일 중 **체크한 속성만** 변경한다. 체크하지 않은 값, 표시 데이터, 행동, 조건, 효과 연결은 그대로 유지한다. 서로 다른 값을 가진 선택에는 안내가 표시된다. 공통 스타일의 `프로젝트 기본`은 개별 `styleId`를 제거한다.

여러 요소를 선택하면 단일 속성 입력은 비활성화된다. 첫 요소만 실수로 수정하지 않도록 일괄 편집을 사용한다. **적용** 전체는 Ctrl+Z 한 번으로 복원하며 Ctrl+Y로 다시 실행한다. **취소**는 변경하지 않는다.

선택한 여러 요소와 그 자식은 Ctrl+C/Ctrl+V로 같은 프로젝트의 다른 화면에도 복사할 수 있다. 요소 ID와 내부 참조를 새로 만들고 상대 간격을 유지한다. Ctrl+D도 여러 선택을 복제한다. 레이어 순서와 부모 변경은 한 요소 또는 부모 그룹을 선택해 조작한다.

## 부품 원본과 배치본

1. 화면에서 부품 또는 목록 배치본을 선택한다.
2. **부품 원본 편집 · 모든 배치에 반영…**을 누른다. 여러 배치본이라면 같은 원본을 사용해야 한다.
3. 해당 원본이 바로 열린다. 화면·중첩 부품의 직접 사용처와 **배치본 덮어쓰기 유지** 안내를 확인한다.
4. 원본 캔버스/목록에서 자식을 여러 개 선택하고 동일한 일괄 편집 도구로 수정한다.
5. 원본 작업실에서 **Save**를 누르면 모든 배치본에 반영한다. 배치본이 직접 덮어쓴 값은 유지한다. 원본 작업실을 취소하면 원본 변경을 버린다.

원본 안의 여러 요소 삭제·복제, 조건·대상 연결은 아직 한 요소 또는 그룹 단위다. 다중 선택 중 해당 단일 편집 버튼은 비활성화한다. 원본 작업실의 Save를 확정한 뒤에는 전체 원본 변경을 편집기의 Undo/Redo로 되돌린다. 작업실을 열어 둔 동안의 세부 조작별 Undo 이력은 제공하지 않는다.

## 기존 프로젝트와 게임 저장

기존 프로젝트를 변환 없이 연다. 수정한 게임에서도 저장·불러오기는 기존 형식을 사용한다. 다만 UI만 수정해도 콘텐츠 지문이 달라지므로 **수정 전 빌드의 저장을 새 빌드에서 바로 열 수 있다는 뜻은 아니다**. 기존의 [콘텐츠 업데이트·저장 이전 절차](../development/release-durability.md#콘텐츠-업데이트-후-저장-이전)를 사용한다. 원본 프로젝트와 저장은 보존하고 명령 재생 결과를 비교한 뒤 새 파일을 만든다. 연출·플러그인 재생 위치는 별도 초기화 검토가 필요하다.

## 재현 가능한 Qt 검증

```powershell
node tests/qt-studio/multi-edit-fixture.mjs .cache/multi-edit-fixture
$env:RAISING_ENGINE_ROOT = (Get-Location).Path
$env:RAISING_MULTI_PLAN = (Resolve-Path .cache/multi-edit-fixture-plan.json).Path
$env:RAISING_QT_TEST = '1'
$env:QT_QPA_PLATFORM = 'offscreen'
# Qt DLL과 platforms 플러그인을 현재 빌드와 일치하도록 설정한다.
dist/qt-studio-multi-edit/qt-selection-test.exe
```

생성기는 이미 존재하는 폴더를 덮어쓰지 않는다. 공개 테스트 자료로 다중 선택, 이동·정렬, 잠금·부모·자동 배치 보호, 일괄 변경·취소, 복사·붙여넣기, Undo/Redo, 부품 원본 반영·배치본 덮어쓰기 보존, 프로젝트 저장·다시 열기·검증을 검사한다. 실제 Qt 위젯을 오프스크린에서 조작하는 시험이다.
