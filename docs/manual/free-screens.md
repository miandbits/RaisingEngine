# 자유 화면과 데이터 연결

## 제작 방법

1. Qt 편집기에서 **새 화면**으로 빈 화면을 만든다.
2. **화면 전환 연결…**에서 기본 화면을 선택한다. 상태별 항목을 `기본 화면`으로 두면 일정, 대화, 선택, 엔딩을 같은 화면에서 표시할 수 있다.
3. 일정·결과·대화·선택지 요소를 원하는 위치에 배치한다. 표시 조건으로 필요한 순간에만 보이도록 설정한다.
4. 텍스트의 **표시할 데이터 찾기 · 연결…**에서 이름으로 능력치, 관계, 소지품, 대사 등을 선택한다. 수치 표시 형식은 `{label}: {value}`를 사용할 수 있다.
5. 버튼의 화면 이동 행동으로 일반 화면을 연결한다. 실행 중 이동한 화면은 저장·불러오기에도 유지된다.

수치를 막대로 보여주려면 **게이지 · 수치 데이터**를 배치한 뒤 **표시할 데이터 찾기 · 연결…**에서 능력치·자원·관계·소지품을 선택한다. 공용 값과 캐릭터별 값을 구분하며, 최대값과 선 두께를 같은 창에서 설정한다. 게이지는 화면이나 재사용 부품 안에 배치할 수 있고, 플레이·불러오기 후의 현재 값을 따라간다. 연결하지 않은 기존 게이지는 저장된 고정 값을 그대로 표시한다. 새 데이터 게이지나 선 두께를 쓰는 내보내기는 `data-meters-v1` 지원을 확인한다.

화면 이름은 역할을 강제하지 않는다. 예를 들어 명시적 화면 연결을 사용하는 프로젝트에서는 `title` 화면도 실행 중 메뉴로 사용할 수 있다. 모달 화면은 일반 화면 이동 대신 모달 행동으로 연다.

저장·불러오기 창도 모달 화면으로 제작할 수 있다. 저장한 값과 현재 값을 나란히 표시하는 방법은 [저장 패널](save-panels.md)을 참고한다.

음량·전체화면·대사 속도와 자동 진행을 조절하는 모달은 [플레이어 설정](player-settings.md)의 `playerSettings` 부품으로 제작한다. 설정은 게임 진행과 분리해 저장된다.

## 계약과 호환성

- `visual.routing.defaultScreenId`: 기본 화면.
- `visual.routing.phases`: 엔진 진행 상태별 선택적 화면 연결.
- `visual.routing.useLocationScreens`: 장소에 지정한 화면을 사용할지 여부.
- 텍스트 `binding: "data-value"`와 `dataBinding`: 공용 또는 특정 캐릭터의 수치 대상을 참조하는 구조화된 연결. 자유 수식 실행은 하지 않는다.
- 실행 상태의 선택적 `uiScreenId`: 사용자가 명시적으로 이동한 화면. 진행 상태 변경 등 다음 자동 전환 시 해제된다.
- `routing`이 없는 기존 프로젝트는 기존 화면 역할과 전환 규칙을 유지한다. 기존 저장 파일에 새 필드가 없어도 불러올 수 있다.
- 명시적 화면 연결 또는 새 데이터 연결을 쓰는 프로젝트를 내보낼 때는 `free-screens-v1` 렌더러 기능을 확인한다.

**범위:** 현재 자동 연결의 상태 목록은 엔진이 정의한 시작·일정·활동 결과·대화·선택·탐험·전투·엔딩 등의 진행 상태다. 디자이너가 새 상태를 정의하거나 임의 조건의 우선순위로 화면을 자동 선택하는 기능은 아직 구현하지 않았다. 자유 화면 생성과 사용자 정의 게임 상태는 별개의 기능이다.

## 검증

- `tests/runtime/free-screens.test.mjs`: 단일 자유 화면, 대상 참조 검증, 개별 캐릭터 데이터, 화면 이동 저장 재생, 기존 자동 전환.
- `tests/runtime/free-screen-export.test.mjs`: 구형 렌더러 내보내기 거부.
- Qt `freeScreenAuthoring`: 실제 제작 UI로 빈 화면과 요소·데이터·화면 연결을 작성하고 저장 및 플레이 내보내기.
- `tests/native-player/free-screens.test.mjs`: 실제 플레이어에서 두 선택 분기를 각각 엔딩까지 실행. 대화 도중 화면 이동·저장·복원, 엔딩 후 저장·새 실행·복원, 새 프로세스에서 복원까지 상태 일치 확인.
- `tests/native/free-screen-web.test.mjs`: 빌드된 WASM과 웹 컨트롤러에서 새 화면 이동 기록 및 기존 저장 파일 복원.
- 기존 시각 요소·관계 표시·데이터 UI·화면 이동·저장 관련 회귀 테스트 통과.

로컬 제작 결과: `.cache/free-screens/authored-game`. 두 분기는 소하의 신뢰가 각각 +3 / -1이며 같은 기본 엔딩으로 이어진다. 서로 다른 엔딩 제작 시험은 아니다.

로컬 실행 증거: `.cache/free-screens/play-evidence.txt`가 실제 플레이 보고서·스크린샷 폴더를 가리킨다. 로그와 테스트 프로젝트는 공개 샘플이 아닌 로컬 검증 산출물이다.
