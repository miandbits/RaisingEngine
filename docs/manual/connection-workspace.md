# 인물부터 후속 사건까지 연결하기

상단 **연결 작업실**을 연다. 기존 프로젝트 형식을 그대로 사용하며 적용, 되돌리기, 저장, 검증, 플레이를 같은 작업실에서 실행한다.

## 기본 순서

1. **인물**을 추가한다. 복수 육성 대상 프로젝트에서는 인물을 육성 대상으로 함께 등록하고 기본 활동을 고른다. 기존 인물에서도 육성 대상과 배정 활동으로 이동할 수 있다.
2. **활동**에서 조건·비용·효과를 편집한다. 규칙 편집은 가운데에 열리며, 확인하거나 취소하면 선택한 항목으로 돌아온다.
3. 활동에서 **만남 만들기**를 선택한다. 말하는 인물, 대사, 두 선택을 작성하고 캐릭터별 기록 여부를 정한다. 생성 후 발생 활동·장소·날짜·조건을 조정한다.
4. 사건의 **대사·선택 목록**을 두 번 누른다. 선택의 조건·효과와 다음 대사를 편집한다.
5. **이 사건·선택에서 후속 사건 연결**로 다음 만남을 만든다. 선행 사건 완료와 선택 기록 조건은 자동으로 연결한다. 캐릭터별 사건에서 시작하면 그 인물의 기록을 사용한다.
6. 변경 적용 → 프로젝트 저장 → 검증 → 플레이로 확인한다. 선택을 바꾸어 플레이하고 중간 저장·불러오기도 확인한다.

## 대상과 저장을 확인하기

- **공용**은 모든 인물이 함께 쓰는 상태다. **행동 실행자**는 지금 활동하거나 사건을 경험하는 인물이다. 특정 인물에게만 영향을 주려면 **지정 캐릭터**를 고른다.
- 기존 공용 사건의 기록 범위만 바꾸어도 기존 조건·효과의 대상까지 바뀌지는 않는다. 이미 연결된 선택 플래그와 후속 조건의 소유자를 함께 확인한다. 새 후속 연결은 시작 사건의 범위를 따른다.
- 규칙 편집의 확인은 작업실 입력에 반영한다. **변경 적용**은 프로젝트 초안을 변경하며, **프로젝트 저장**이 디스크에 저장한다.
- 미적용 입력이 있는 상태에서 종료·프로젝트 전환을 하면 돌아가기 또는 입력 버리기를 선택한다. 버린 입력은 폼에서도 원래 값으로 복원된다. 이미 적용한 미저장 변경은 기존 저장 확인에서 별도로 처리한다.
- 다른 도구가 초안 버전을 변경하면 오래된 입력의 적용을 거절한다. 입력을 확인한 뒤 새로 고침으로 최신 내용을 읽는다.

## 범위

기본 인물·활동·사건·선택·규칙·후속 연결을 한 작업실에서 편집한다. 복잡한 대본 배치, 화면 캔버스, 일부 고급 행동 흐름에는 기존 전용 도구도 사용한다. 캐릭터별 상태를 사용하지 않는 기존 프로젝트에 복수 육성 대상을 자동 도입하지 않는다.

검증은 `authoring-workspace.test.mjs`의 참조·초안 서비스 시험과 Qt의 `unifiedConnectionAuthoring`, `authoringWorkspaceRoundtrip`, `logicAstEditor`에서 실행한다. Qt 시험은 실제 위젯을 조작하며 생성·취소·후속 조건·저장 재열기·미적용 입력 보호를 확인한다. Owner 드롭다운은 클릭 처리 중 위젯을 삭제하지 않는 수명 회귀 검사를 포함한다.
