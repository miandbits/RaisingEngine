# UI 요소에서 연결 따라가기

캔버스나 계층에서 요소를 선택하고 속성 맨 위의 **데이터 · 행동 · 후속 사건 따라가기…**를 누릅니다. **디자인 → 선택 요소 연결 따라가기…**에서도 열 수 있습니다.

제작 작업실이 선택 요소를 출발점으로 엽니다. 오른쪽 **선택 항목 연결**에서 대상을 두 번 누르면 가운데 편집기가 해당 항목으로 이동합니다.

- 표시 수치 → 능력·자원 또는 인물별 관계 정의 → 해당 값을 사용하거나 변경하는 행동.
- 버튼 → 공통 행동 또는 교류 행동 → 실행 조건·비용·효과·완료 후 사건.
- 사건 → 대본 노드 → 선택지 → 선택 조건·효과·결과 안내와 다음 대사.
- 선택의 플래그·약속 기록 또는 사건 완료 조건 → 후속 사건 후보.
- **이 사건의 대본·선택지·후속 연결 지도…**로 기존 대본 작업실과 사건 연결 지도도 엽니다.

**← 이전 연결 / 다음 연결 →**는 탐색 이력만 이동합니다. 프로젝트 되돌리기와 다릅니다. **출발 UI 요소**는 처음 선택한 요소로 돌아갑니다. **화면에서 위치·크기 편집…**는 해당 화면과 요소를 캔버스에서 선택합니다.

가운데 내용을 바꾼 뒤 **변경 적용**을 누르면 저장 전 초안과 연결 목록이 갱신됩니다. 적용 전 다른 연결로 이동하면 입력을 보존하고 안내합니다. 다른 편집에서 프로젝트 버전이 바뀌면 오래된 입력을 덮어쓰지 않고 적용을 거부합니다. **새로 고침 / 입력 취소**는 현재 작업실 입력을 취소합니다. 적용한 내용은 기존 Undo/Redo와 프로젝트 저장을 사용합니다.

연결 목록은 현재 대상 주변 두 단계, 최대 300개를 표시합니다. 대상을 열면 그곳부터 이어집니다. 더 넓은 범위는 기존 참조·간접 영향 탭에서 최대 네 단계·500개까지 확인합니다. 없는 대상이나 중복 참조는 경고로 남고 임의의 문서로 이동하지 않습니다. 대본·선택지 ID는 사건별로 구분합니다.

이 목록은 **정적 참조**입니다. 후속 사건 후보가 반드시 발생한다는 뜻은 아닙니다. 부정 조건, 선택 경로, 실행자, 기간, 활동, 장소와 현재 약속 값은 실제 실행에서 함께 검사됩니다. 런타임에만 정해지는 동적 대상이나 외부 플러그인 내부 연결까지 추측하지 않습니다. 현재 대상 기준의 실제 조건과 결과는 규칙 디버거·플레이로 확인하세요.

공개 회귀 검사는 `tests/qt-studio/workspace-links.test.mjs`와 `linkedAuthoringRoundtrip` Qt 위젯 테스트에 있습니다. `node tests/qt-studio/linked-authoring-fixture.mjs <새 폴더>`로 독립 검증본과 `-plan.json`을 만듭니다. `RAISING_LINKED_PLAN`에 계획 파일을 설정하고 Qt 테스트를 실행합니다. 테스트는 실제 편집 위젯과 공유 서비스로 내용을 적용·저장하며 원본 샘플을 수정하지 않습니다.
