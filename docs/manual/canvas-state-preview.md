# 실제 저장 상태로 화면 편집

화면 캔버스 위의 **플레이 상태 → 상태 선택…**에서 플레이 저장 파일을 선택합니다. 초기 상태도 사용할 수 있습니다. 적용하면 배포용 Windows 플레이어가 계산한 표시 값, 조건별 문구·이미지, 표시·활성 조건을 편집 캔버스에서 확인할 수 있습니다.

- **캐릭터**: 기본 대상을 전환합니다. 특정 캐릭터로 고정한 카드·부품의 연결은 유지됩니다. 가상 개인 능력치·기록 변경은 선택한 캐릭터에만 적용됩니다.
- **상태 선택…**: 활동, 개인/공용 기록, 사용자 정의 상태, 능력치 검사값과 사건을 고릅니다. 사건 선택은 조건 검사이며 강제 발생 기능이 아닙니다.
- **값·조건**: 현재 값과 기준 값, 조건 충족 여부와 적용된 표현 규칙을 확인합니다.
- **갱신**: 외부에서 플레이 저장 파일이 변경됐을 때 다시 불러옵니다.
- **플레이 상태 해제**: 기존 설계 화면으로 돌아갑니다.

요소 선택, 드래그, 크기 조절과 키보드 배치는 계속 편집할 수 있습니다. 실제 렌더링 위치가 조건이나 앵커로 달라도 편집 결과는 원본 설계 좌표에 변화량으로 반영됩니다. 조건으로 숨겨진 요소는 계층에서 선택하면 점선으로 위치를 확인할 수 있습니다. 부품 내부 요소와 반응형 비율 미리보기의 기존 편집 제한은 유지됩니다.

편집·검사 설정 변경은 짧게 모아서 다시 렌더링합니다. 생성 중에는 상태 표시줄에 갱신 중임을 표시하며, 이전 요청의 결과가 새 설정을 덮어쓰지 않습니다. 실패하면 설계 화면으로 돌아가며 상태 표시줄 도움말과 **값·조건**에 원인을 표시합니다.

검사 설정은 이 PC의 프로젝트별 편집기 환경설정에 저장되어 재열기 후 복원됩니다. 게임 프로젝트, Undo 이력, 원본 플레이 저장 파일에는 가상 검사값을 쓰지 않습니다.

## 저장 호환성과 검증 범위

저장 파일은 스키마 검사 및 C++ 명령 재현 검사를 통과해야 합니다. 콘텐츠 변경 후에는 검사 전용 복사본의 콘텐츠 식별자를 갱신한 뒤 모든 명령을 다시 실행합니다. 식별자 외의 실행 상태가 정확히 일치할 때만 캔버스에서 사용합니다. 규칙 변경으로 결과가 달라지거나 저장이 손상되면 거부합니다. 이 절차는 실제 플레이어의 저장 호환성 규칙을 바꾸거나 저장 파일을 마이그레이션하지 않습니다.

배치 편집 중에는 선택한 화면의 고정 시점 렌더링을 표시합니다. Windows 플레이어의 `authoring-preview-v1` 지원이 필요합니다.

## 캔버스에서 재생하기

캔버스 위의 **재생**을 누르면 배포용 Windows 플레이어가 캔버스 안에서 실행됩니다. 현재 편집 내용과 선택한 검사 상태의 복사본을 사용합니다. 캐릭터 애니메이션, 연출, 대화 진행, 효과음, 버튼의 조건·행동을 실제 플레이어로 확인할 수 있습니다. 첫 화면은 편집 중인 화면이며, 버튼을 누른 뒤에는 게임의 일반 화면 전환 규칙을 따릅니다.

- **일시정지 / 계속 재생**: 연출·애니메이션·대화 시간, 음향과 게임 입력을 함께 멈추거나 이어갑니다.
- **초기화**: 재생을 시작했을 때의 검사 상태로 돌아갑니다. 방금 실행한 행동과 임시 저장은 이어받지 않습니다.
- **편집으로**: 재생을 끝내고 요소 배치 편집으로 돌아갑니다.
- 화면·캐릭터·검사 상태 또는 콘텐츠를 바꾸면 재생을 끝냅니다. 새 설정으로 다시 **재생**하세요.

재생 중 게임의 저장·불러오기 버튼은 해당 재생 세션의 임시 저장만 사용합니다. 본편 저장, 도감, 사용자 설정, 원본 프로젝트 및 Undo 이력은 변경하지 않습니다. 임시 저장에는 검사 세션 표시가 붙으며 일반 플레이어에서는 불러올 수 없습니다. 재생 종료·초기화·편집기 재실행 이후에도 이어갈 본편 저장을 만드는 기능은 아닙니다.

편집기에서 콘텐츠를 저장하고 프로젝트를 다시 열면 콘텐츠와 검사 설정을 복원합니다. 실행 중이던 임시 플레이는 복원하지 않고 검사 시작 상태에서 다시 재생합니다. 저장 상태 검사는 위의 엄격한 재현 검사를 그대로 사용합니다.

현재 내장 재생은 Windows 전용이며 `editor-live-preview-v1`을 제공하는 최신 플레이어가 필요합니다. 구형 런타임이면 갱신 안내 오류를 표시합니다. 내장 재생 중 전체화면 전환은 편집기 창 배치를 유지합니다. 웹·모바일 내장 재생은 지원하지 않습니다.

검증: 서비스의 캐릭터 격리·조건·저장 재현 검사, Qt 캔버스와 실제 렌더러의 픽셀 일치, 원본 배치 좌표 유지, 별도 공방 프로젝트에서 조건별 표현·편집·저장·재열기, Windows 플레이 진행 및 저장·불러오기. 비공개 게임과 증거 파일은 공개 저장소에 포함하지 않습니다.
