# 조건 판정형 라운드 작성

Qt 편집기의 **디자인 → 대본 · 선택지 작업실 → 라운드 흐름 추가…**에서 기존 사건·엔딩에 라운드 흐름을 삽입한다.

- 참가 조건과 참가 시 효과를 직접 설정한다. 참가가 불가능해도 중단 선택이 남는다.
- 라운드마다 질문, 도전 문구·효과, 통과 조건·보상, 통과 결과 문구를 설정한다. 조건은 도전 효과 적용 후 평가된다.
- 최종 통과 보상과 실패 효과, 통과·실패·중단 문구를 설정한다.
- 기본값은 조건 항상 참, 효과 없음이다. 특정 게임의 판정식이나 보상 수치를 제공하지 않는다.
- 최대 32개 라운드이며, 생성 후 작업실에서 추가 선택지나 연결을 편집할 수 있다.

삽입 위치는 대본 시작 앞 또는 다음 연결이 있는 장면·대사·효과 노드 뒤이다. 모든 완료·실패·중단 경로가 기존 연결로 돌아간다. 기존 노드와 메타데이터를 유지하며, 새 ID는 충돌하지 않는 `rounds-N-` 접두사를 사용한다.

라운드 통과 보상은 통과 결과 대사 전에 적용한다. 최종 보상도 최종 결과 대사 전에 적용한다. 기존 대본 커서와 명령 기록을 사용하므로 결과 화면에서 저장·불러오기를 해도 보상을 다시 적용하지 않는다.

도구의 적용은 작업실 초안만 변경한다. 작업실 저장은 기존 단일 batch 편집을 사용하며 한 번의 실행 취소로 되돌린다. 취소는 원본을 변경하지 않는다. 작업실을 연 뒤 다른 요청이 프로젝트 revision을 바꾸면 저장을 거절하고 초안을 유지한다.

이 도구는 기존 choice/branch/effect/dialogue 노드를 생성하는 작성 보조 기능이다. 전투 토너먼트, 대전표, 전투 후 같은 대본 라운드로 복귀하는 기능 또는 실시간 미니게임을 추가하지 않는다.

## 검증

- Qt `scriptRoundsBuildAndPreserve`: 기존 노드·필드 보존, 삽입 연결, ID 충돌 방지, 잘못된 삽입 위치 거절, 실제 생성 fixture 비교.
- Qt `scriptRoundsDialogAndTransaction`: 취소, 조건 편집 연결, 문구 검증, 단일 batch·undo/redo, 저장·재열기, 실제 서비스 revision 충돌 시 초안 보존.
- `node --test tests/runtime/script-rounds.test.mjs`: 동일 생성 fixture의 성공, 둘째 라운드 실패, 첫 보상 후 중단, 참가 불가 네 경로. 유효 초기 설정과 정상 명령만 사용하며 모든 명령의 TS/C++ 결과 및 모든 커서의 저장·재생을 비교한다.
- `tests/fixtures/script-rounds.json`의 수치는 합성 테스트 값이다. Qt fixture를 갱신하려면 `RAISING_EXPORT_ROUNDS_FIXTURE=1`로 해당 Qt 테스트를 실행한다. 일반 테스트에서는 fixture를 읽고 비교만 한다.

제작 프로젝트와 기존 저장 파일은 검증에 사용하거나 변경하지 않는다. Qt 검증은 임시 예제 복사본과 offscreen 플랫폼에서 실행한다.
