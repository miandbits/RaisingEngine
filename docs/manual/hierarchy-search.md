# 계층에서 전체 화면 검색

계층 패널의 **전체 화면에서 찾기 · 이름 / ID**에 입력하면 화면·요소 이름, ID, 요소 종류와 텍스트를 대소문자 구분 없이 찾는다. 다른 화면의 결과도 화면별로 표시하며, 일치하는 요소의 부모 그룹을 함께 남긴다. 화면이나 그룹 자체가 일치하면 그 아래 내용도 표시한다.

- 입력만으로 열린 문서·선택·프로젝트 데이터가 바뀌지 않는다.
- 결과를 클릭하면 해당 화면을 열고 요소를 선택한다. 서로 다른 화면에 같은 요소 ID가 있어도 화면 ID로 구분한다.
- 검색을 지우면 현재 화면의 계층으로 돌아간다. 찾은 요소의 선택은 유지된다.
- 저장·이름 변경 등으로 계층을 새로 그려도 검색을 다시 적용한다.
- 검색 중에는 끌어놓기를 잠가 다른 화면에 잘못 옮기지 않도록 한다. 검색을 지우면 원래 배치 잠금에 따른 끌어놓기 동작이 복원된다.

검증용 프로젝트는 `.cache/hierarchy-search-ppJt8I`이며 생산 콘텐츠는 변경하지 않았다. 집중 회귀: `hierarchySearchAcrossScreens`.
