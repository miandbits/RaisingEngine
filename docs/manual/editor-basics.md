# 편집 기본 동작과 버전 관리

## 저장하지 않은 변경 보호

창 닫기·종료 메뉴·프로젝트 열기·새 프로젝트·프로젝트 선택기로 이동할 때 현재 입력 중인 필드를 먼저 반영한다. 편집 서비스가 처리 중이면 결과를 기다린 뒤 저장 여부를 확인한다.

- **저장하고 계속**: 프로젝트 파일 저장이 성공한 뒤 종료하거나 이동한다.
- **저장하지 않고 계속**: 마지막으로 저장한 디스크 파일은 유지하고 현재 초안을 버린다.
- **취소 / Esc**: 작업 창과 초안을 유지한다.

파일 충돌이나 저장 실패, 편집 처리 시간 초과가 있으면 창을 유지하고 오류를 표시한다. Ctrl+S도 속성 입력 중인 값을 먼저 반영한다. 정상적인 창 종료를 보호하며 강제 프로세스 종료나 전원 차단 복구를 제공하는 기능은 아니다.

## 실행 취소와 복사

| 작업 | 메뉴·단축키 |
|---|---|
| 실행 취소 | 편집 → 되돌리기, Ctrl+Z |
| 다시 실행 | 편집 → 다시 실행, Ctrl+Y 또는 Ctrl+Shift+Z |
| 요소와 자식 복사 | 편집 → 요소 복사, Ctrl+C |
| 요소와 자식 붙여넣기 | 편집 → 요소 붙여넣기, Ctrl+V |
| 현재 화면에 복제 | 편집 → 선택 요소 복제, Ctrl+D |
| 한 단계 앞으로 / 뒤로 | 캔버스 도구 막대, Ctrl+] / Ctrl+[ |
| 맨 앞으로 / 맨 뒤로 | 편집 메뉴, Ctrl+Shift+] / Ctrl+Shift+[ |

화면 캔버스나 계층에서 요소를 선택해 복사한다. 그룹을 복사하면 자식과 내부 연결도 같이 복사하고 새 ID를 만든다. 같은 프로젝트의 다른 화면에도 붙여넣을 수 있다. 붙여넣기 전체는 한 번의 편집 트랜잭션이므로 Ctrl+Z 한 번으로 되돌린다. 텍스트 입력란에서는 일반 텍스트 복사·붙여넣기를 사용한다.

프로젝트 사이의 복사는 에셋·행동 참조를 자동으로 이식하지 않으므로 거부한다. 다른 프로젝트로 옮기는 공용 부품 패키징과는 별도 기능이다. 실행 취소 이력은 현재 편집 세션의 이력이며 Git의 영구 이력과 다르다.

## 계층과 레이어

계층 기능은 **보기 → 계층 · 레이어 표시**에서 다시 열 수 있다. 플러그인 작업실에 있었다면 화면 편집으로 돌아가 계층 패널을 표시한다. 전체 배치가 흐트러졌으면 **보기 → 작업 공간 초기화**를 사용한다.

계층에는 요소 이름, 부모·자식, 순서, 종류를 표시한다. **같은 부모 안에서 순서가 클수록 앞에 그린다.** 다른 그룹의 자식 번호끼리는 비교하지 않는다. 그룹을 앞으로 보내면 그 그룹의 자식도 함께 움직인다. 부모를 바꾸는 동작과 그리기 순서를 바꾸는 동작은 구분한다.

그룹으로 드래그하면 부모가 바뀌며, 우클릭 메뉴에서는 복사·붙여넣기·복제·앞뒤 순서를 바꾼다. 부모 그룹의 잠금도 자식 배치에 적용된다. 계층 검색은 기존처럼 다른 화면의 요소까지 찾는다.

## Git과 외부 도구

**보기 → 프로젝트 버전 관리…**에서 현재 프로젝트 폴더의 Git 상태, 스테이징하지 않은 작업 변경, 스테이징 변경, 최근 30개 이력을 조회한다. Git의 변경은 디스크 파일 기준이다. 편집기 초안을 먼저 **프로젝트 저장**해야 Git 비교에 반영된다. Git이 없거나 저장소가 아니면 오류를 표시하고 프로젝트는 수정하지 않는다.

이 창은 조회 기능이다. 커밋·브랜치·병합·푸시·Git 저장소 초기화는 자동 실행하지 않는다. **외부 도구 지정…**에서 Windows 실행 파일을 선택하면, **외부 버전 관리 도구 열기**가 프로젝트 폴더 하나를 인자로 전달한다. 해당 실행 방식이 가능한 Git 또는 다른 버전 관리 GUI를 사용할 수 있다. 인증 정보나 암호는 편집기에 저장하지 않는다.

외부 프로그램에서 파일을 수정한 경우 기존 편집 서비스의 디스크 충돌 검사가 적용된다. 저장 오류가 나면 현재 초안을 유지한 채 차이를 확인한다. 외부 변경을 강제로 덮어쓰는 버튼은 추가하지 않았다.

## 개발자 검증

아래 준비 명령은 공개 테스트 자료를 **새 폴더**에 복사하고 그 사본만 임시 Git 저장소로 초기화한다. 이미 있는 폴더에는 덮어쓰지 않는다.

```powershell
node tests/qt-studio/editor-basics-fixture.mjs .cache/editor-basics-project
$env:RAISING_ENGINE_ROOT = (Get-Location).Path
$env:RAISING_BASICS_PROJECT = (Resolve-Path .cache/editor-basics-project).Path
$env:RAISING_QT_TEST = '1'
$env:QT_QPA_PLATFORM = 'offscreen'
# Set QT_QPA_PLATFORM_PLUGIN_PATH to the matching Qt installation's platforms directory.
dist/qt-studio-editor-basics/qt-studio-test.exe editorBasicsClipboardLayers editorBasicsSaveProtection editorBasicsVersionControl
```

Qt 위젯 시험은 숨겨진 계층 재표시, 그룹의 화면 간 복사, 자식 연결, 실행 취소·재실행, 형제 레이어 순서, 텍스트 클립보드, 다른 프로젝트 붙여넣기 차단, 입력 중 종료·저장·취소, 디스크 충돌 시 종료 차단, 실제 Git 변경 조회를 검사한다. 사용자 프로젝트와 실행 중인 창은 건드리지 않는다.

이번 변경에서는 위 세 시험과 기존 `duplicateElementMenuAndShortcut` 회귀 시험을 통과했다. 실제 Qt 위젯을 오프스크린으로 조작한 검사이며, 계층·저장 확인·버전 관리 화면도 이미지로 확인했다. 한국어·영어·일본어 번역 누락 검사와 저장소 구조 검사도 통과했다. 외부 버전 관리 프로그램 자체의 로그인·커밋·병합 기능은 이번 검사 대상이 아니다.
