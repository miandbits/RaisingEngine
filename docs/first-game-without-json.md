# JSON 없이 첫 육성게임 만들기

Qt 편집기의 프로젝트 관리자에서 `최소 일정 육성` 템플릿으로 새 프로젝트를 만드세요. 원본 샘플은 그대로 보존됩니다. 중앙의 `처음 만드는 게임 · 제작 순서`에서 제목·기간과 기본 플레이 화면을 설정할 수 있습니다.

## 콘텐츠 열기

아래 `콘텐츠` 패널에서 항목을 선택하고 **선택한 콘텐츠 편집…**을 누르세요. Enter와 더블클릭도 가능합니다. 검색은 이름과 파일 경로에 적용됩니다. `콘텐츠 검색 · 사용처 / 삭제…`는 일괄 편집창이 아니라 사용처를 확인하고 불필요한 문서를 정리하는 도구입니다.

## 인물과 활동

인물을 열고 **관계 · 신뢰 / 호감** 탭에서 관계 수치의 표시 이름·설명·최소·초기값·최대를 설정합니다. 숫자도 표 셀을 더블클릭하거나 선택 후 F2로 직접 수정합니다. 새 관계도 추가할 수 있습니다. 기존 ID는 연결을 유지하기 위해 고정되며, 이름을 바꾸는 데 ID 변경은 필요하지 않습니다. 사용 중인 관계 삭제는 어느 문서에서 쓰는지 안내하며 중단합니다.

활동의 기본 속성에서 **실행 조건 편집…**, **능력·자원·관계 효과 편집…**을 누르세요. 간단한 수치 규칙에서 대상 이름을 검색하고, 증감/값 지정 또는 비교 방식과 숫자를 선택한 뒤 **추가/교체**를 누릅니다. 아래 규칙 트리에서 결과를 확인하고 저장하세요. 비용은 활동의 비용 탭에서 설정합니다. 여러 조건은 AND로 추가하거나 트리에서 AND/OR와 하위 항목을 편집합니다.

## 사건과 결말

사건·결말을 편집하면 **사건 · 조건 · 결말 작업실**이 열립니다. 위쪽에서 이름·우선순위·발생/결말 조건을 편집합니다. 사건의 발생 범위는 게임 전체의 **1번째 일정부터** 셉니다. 월 3회라면 2개월 첫 일정은 4번째입니다. 여러 결말이 조건을 만족할 때는 높은 우선순위가 먼저 선택됩니다.

왼쪽에서 대사·선택지·조건 분기·효과·종료 노드를 추가하고, 오른쪽에서 문구와 다음 노드를 고릅니다. 선택지 표에서 행을 선택한 뒤 **선택한 항목의 조건… / 효과…**로 결과를 연결합니다. 가운데 그래프에서 흐름을 확인하세요. 시작 노드를 고르고 연결이 끊기거나 순환하지 않는지 저장 시 진단을 확인합니다.

## 참조를 보존하며 수정하기

대사·선택지 문구·콘텐츠 이름을 바꾸어도 ID를 유지하면 연결은 그대로입니다. 노드 ID를 바꾸려면 **ID 변경 · 연결 갱신**을 사용하세요. 시작 노드, 대본 내 연결, 이 사건의 노드/선택지를 참조하는 프로젝트 시나리오를 함께 갱신합니다. 선택지 ID 변경도 해당 시나리오 참조에 반영됩니다. **선택 노드의 참조 위치…**에서 연결과 문서 경로를 확인할 수 있습니다. 작업실 저장 전에는 초안이며, 취소하면 함께 취소됩니다. 저장 후에는 편집기 실행 취소 한 번으로 함께 되돌립니다.

ID는 영문 소문자로 시작하고 영문 소문자·숫자·하이픈을 사용합니다(예: `first-promise`). 밑줄이나 공백 대신 하이픈을 쓰세요. 한글 문구는 표시 이름과 대사에 넣습니다.

이 기능은 임의 문자열 전체 치환이나 저장 게임 변환이 아닙니다. 과거 플레이 기록·회귀 기준·플레이어 저장 파일은 수정하지 않습니다. 콘텐츠 업데이트 후 기존 저장은 별도의 저장 이전 도구로 검토해야 합니다.

## 검증과 플레이

작업실 저장은 편집기 초안에 적용합니다. 메인 편집기의 **프로젝트 저장**으로 디스크에 저장하고 문제 목록을 확인하세요. **처음부터 플레이**로 실제 활동·사건·결말을 확인한 뒤, 게임 안의 **저장 / 불러오기**로 진행 복원을 시험하세요. 프로젝트 저장과 게임 진행 저장은 서로 다릅니다.

`개발자용 JSON`은 이 제작 흐름에 필요하지 않습니다. 보기만 하면 폼으로 돌아올 수 있지만, 직접 수정하면 충돌을 막기 위해 저장 또는 취소 전까지 폼을 잠그고 안내합니다.
