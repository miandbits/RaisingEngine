# 컷아웃 캐릭터 애니메이션 플러그인 (cutout-animation 1.3.0)

뼈대(본)와 이미지 조각으로 2D 캐릭터를 조립하고 움직이는, 엔진 자체 형식(`raising-cutout-v1`)의 선택 설치형 플러그인입니다.
Spine 파일을 읽지 않으며 Spine 호환 제품이 아닙니다.

## 구성

| 경로 | 역할 | 게임에 포함되는가 |
|---|---|---|
| `core/` | Qt를 쓰지 않는 C++ 평가·재생 코어(검증, 보간, 트랙·전환, 신호, 편집 연산, 템플릿) | 런타임 모듈 안에 포함 |
| `studio/` | Qt 제작 패널 (`cutout-studio.dll`) | 포함 안 됨 |
| `service/` | Studio·MCP가 함께 쓰는 검증·도우미 모듈 (Node) | 포함 안 됨 |
| `schema/` | 리그·컨트롤러 데이터 JSON Schema | — |
| `demo/` | 권리 문제 없는 데모 이미지 조각 생성기 | — |

빌드와 패키징:

```
npm run build:plugin:cutout
```

결과물은 `dist/plugins/cutout-animation-1.3.0.raiseplugin`입니다.
1.1.0은 베지어 보간(곡선)과 그래프 편집기, 시간 확대와 여러 키 선택·복사가 되는 도프시트를 더했습니다. 1.2.0은 스킨(의상·변형 세트)과 표정 세트를 더했습니다. 1.3.0은 IK 제약(팔·다리 두 본 IK, 한 본 조준)을 더했습니다. 이전 버전으로 만든 문서는 그대로 열리고 똑같이 재생됩니다.

## 최소 제작 안내

1. **설치**: 편집기 `플러그인 → 플러그인 관리…`에서 `패키지 설치…`로 `.raiseplugin` 파일을 고릅니다. 그다음 `이 프로젝트에서 사용`을 누르면 `plugins/lock.json`에 버전이 고정됩니다.
2. **작업 공간 열기**: 메뉴 막대 오른쪽의 `화면 편집 | 캐릭터 애니메이션` 탭, `보기 → 작업 공간`, `캐릭터 애니메이션` 도크의 `작업 공간 열기` 또는 Ctrl+Shift+A로 애니메이션 전용 작업 공간으로 바꿉니다.
   - 창 전체가 Spine처럼 바뀝니다: 왼쪽 `계층`·`그리는 순서`·`캐릭터 · 게임 연결`(제목을 눌러 접기), 가운데 도구 줄과 큰 캔버스, 오른쪽 `속성 · 키`·`스킨 · 표정 · IK`·`진단`, 아래 `애니메이션`(클립 | 도프시트·그래프 | 전환)과 `게임 연결` 탭. 맨 위 모드 띠는 늘 보입니다.
   - 칸 사이 경계를 끌어 크기를 바꾸면 이 컴퓨터에 기억됩니다. 아주 넓은 화면에서는 캔버스와 시간 영역만 넓어지고 좌우 패널은 폭을 유지합니다. 버튼 줄이 좁으면 끝의 `»`에 나머지가 들어갑니다.
   - 캔버스·도프시트·그래프에서 Tab(또는 `캔버스 크게`)을 누르면 좌우 패널을 숨겨 캔버스를 넓힙니다. 숫자 칸의 Tab은 그대로 다음 칸으로 이동합니다.
   - 같은 단축키나 `화면 편집` 탭으로 돌아가면 도크 배치가 떠나기 전 그대로 돌아옵니다. 파일·편집(되돌리기·다시 실행)·저장·플레이는 작업 공간에서도 그대로 쓸 수 있고, 작업 공간을 바꾸는 것만으로는 문서가 바뀌지 않습니다. 작업 공간에 있던 채로 프로젝트를 닫았다 다시 열면 그 작업 공간으로 돌아옵니다.
   - 작업 공간을 모르는 이전 편집기에서는 같은 패널이 `캐릭터 애니메이션` 도크 안에 그대로 나옵니다.
3. **새 캐릭터**: 작업 공간 왼쪽 아래 `새 캐릭터`를 누릅니다. 리그(`plugins/cutout-animation/rig/<id>.json`)와 연결(`…/controller/<id>.json`)이 함께 만들어집니다.
4. **조립(파란 띠, 조립 모드)**:
   - `이미지 조각 추가…`로 PNG를 가져옵니다.
   - 트리에서 끌어 놓아 부모를 바꿉니다. 화면상 위치는 유지됩니다.
   - `회전 중심`(P) 도구로 관절 위치를 찍습니다. 자식 본과 조각이 같이 보정됩니다.
   - 위치·회전·크기는 캔버스(V/R/S) 또는 속성 숫자 칸으로 편집합니다.
   - 표시 순서는 위/아래 버튼으로 바꿉니다.
   - 눈 아이콘으로 숨긴 상태는 편집기에서만 적용되고 저장되지 않습니다.
5. **애니메이션(빨간 띠, 애니메이션 모드)**:
   - 클립을 만들고 길이와 반복 여부를 정합니다.
   - 재생 헤드 위치에서 값을 바꾼 뒤 `키`(K)를 누르면 키가 저장됩니다. 자동 키는 기본으로 꺼져 있습니다.
   - 첨부 콤보로 눈·입 이미지를 바꾸면 표정 키가 됩니다.
   - 키는 도프시트에서 이동·삭제하고, 우클릭으로 보간(선형, 계단, 천천히 시작, 천천히 끝, 천천히 시작·끝, 부드럽게, 튕김)을 고릅니다.
     도프시트의 구간 선 모양이 보간을 보여 줍니다: 곧은 선 = 선형, 점선 = 계단, 청록색 곡선 = 베지어.
   - **시간 축**(도프시트·그래프 공통): Ctrl+휠로 커서 위치를 중심으로 확대/축소, Shift+휠·가운데 버튼 드래그·아래 가로 스크롤바로 이동, `맞춤`은 클립 전체 보기입니다. 눈금 간격은 확대에 맞춰 1ms까지 바뀌고, 왼쪽 위에 보이는 범위(ms)가 표시됩니다. 눈금자와 선택 띠는 행을 내려도 위에 남습니다.
     - 몇 픽셀 안에 겹친 키는 숫자가 적힌 **묶음**으로 그립니다. 누를 때마다 묶음 안의 다음 키가 선택되고, 더블클릭하면 키가 구별될 만큼 확대합니다.
     - 재생 헤드: `시간` 칸에 ms를 직접 입력하거나, ◀ ▶ 버튼·쉼표/마침표·←/→ 키로 `간격`(기본 10ms)만큼 옮깁니다. 눈금자 클릭은 10ms 단위, Shift를 누르면 1ms 단위입니다.
     - `[ 구간 시작`·`구간 끝 ]`(또는 눈금자의 초록 표시 끌기)로 미리 보기 반복 구간을 정하면 재생이 그 안에서 반복됩니다. 편집기 전용이라 문서·게임에 저장되지 않습니다(클립마다 기억, `구간 해제`).
   - **키 선택**(도프시트·그래프 공통): 클릭, Ctrl+클릭(토글), Shift+클릭(추가), 빈 곳 드래그(상자 선택), 행 이름 클릭(행 전체), Alt+클릭(같은 시간의 키 모두), Ctrl+A.
     - 고른 키 하나를 끌면 고른 키 전부가 간격을 유지한 채 함께 움직입니다(10ms 단위, Shift 1ms). 다른 키와 겹치거나 클립 밖으로 나가면 거부됩니다. 놓을 때 편집 한 번이라 Ctrl+Z 한 번으로 돌아갑니다.
     - 행 위의 노란 **선택 띠** 양 끝 손잡이를 끌면 시간 간격을 늘이거나 줄입니다(반대쪽 끝 기준, Alt: 재생 헤드 기준). 숫자로는 `간격 배율`(%)과 `만큼 이동`(ms) 칸을 씁니다. 곡선 모양은 그대로 따라갑니다.
     - Delete: 고른 키 삭제 · Ctrl+C(`복사`)·Ctrl+V(`붙여넣기`): 재생 헤드 시간에 붙여넣기. 다른 클립에도 되고, 같은 시간의 키는 덮어씁니다. 한 대상만 복사했다면 지금 고른 본·조각에 붙습니다 · Ctrl+D(`복제`): 고른 키를 재생 헤드 시간에 복제.
     - `포즈 복사`는 고른 본과 그 자식 본(없으면 모든 본)의 지금 자세를, `포즈 붙여넣기`는 그 자세를 재생 헤드 시간의 키로 넣습니다. 여러 클립의 시작·끝 자세를 맞출 때 씁니다.
   - **그래프 편집기**(도프시트 아래, `그래프` 버튼으로 보이기/숨기기): 고른 본·조각의 숫자 트랙(X·Y·회전·크기·투명도)을 채널별 색 곡선으로 보여 줍니다.
     - 빈 곳을 누르면 재생 헤드만 옮깁니다(이벤트는 울리지 않음). 시간 눈금은 도프시트와 같습니다.
     - 키를 위아래로 끌면 값, 좌우로 끌면 시간이 바뀝니다(Alt: 둘 다, Shift: 1ms). 다른 키가 있는 시간으로는 옮겨지지 않습니다.
     - 고른 키의 손잡이를 끌면 그 구간 곡선이 바뀝니다. 놓을 때 한 번만 저장되므로 되돌리기(Ctrl+Z) 한 번이면 원래대로 돌아갑니다.
     - `곡선` 줄의 프리셋 버튼(또는 우클릭)은 고른 키 전부에 한 번의 편집으로 적용됩니다. Ctrl+클릭으로 여러 키, Ctrl+A로 모두 고릅니다.
     - `채널별 맞춤`은 범위가 다른 채널(각도와 크기)을 각자 높이에 맞춰 모양을 비교합니다. 범례를 누르면 채널을 숨깁니다(저장 안 됨).
   - `숨쉬기`·`눈깜빡임` 템플릿은 일반 키로 된 클립을 만듭니다. 숨쉬기는 `천천히 시작·끝` 곡선 키 3개(쉼 → 들숨 → 쉼)입니다.
   - **어니언 스킨**(캔버스 위 `어니언 스킨`, 단축키 O): 앞뒤 시간의 자세를 지금 자세 뒤에 반투명하게 겹쳐 그립니다. 이전은 빨강, 이후는 초록이 기본입니다.
     - `▾` 설정: 앞·뒤 개수(0~10), 방식(`일정 간격` ms 또는 `키 위치만`), 가장 가까운 유령의 불투명도, `멀수록 흐리게`, 이전/이후 색(`원래 색`은 칠하지 않음), `현재 시간도 표시`(저장된 자세를 회색으로: 키로 저장하지 않은 변경과 비교), `선택한 본과 자식만`.
     - `키 위치만`은 고른 본·조각의 앞뒤 키 시간에 그립니다. 고른 대상에 키가 없으면 보이는 모든 트랙의 키를 씁니다.
     - 반복 클립은 끝을 넘어가면 처음으로 이어지고, 한 번 재생 클립은 처음·끝에서 멈춥니다. 게임 연결 탭의 미리 보기(전환·레이어)에는 그리지 않습니다.
     - `궤적`: 고른 본의 원점이 클립 동안 지나는 길을 선으로, 키 시간(그 본과 부모 본의 키)을 점으로 보여 줍니다.
     - 모두 편집기 전용입니다. 켜고 끄거나 설정을 바꿔도 문서는 바뀌지 않고, 설정은 이 컴퓨터의 편집기 환경에만 기억됩니다.
6. **스킨 · 표정**(오른쪽 `스킨 · 표정 · IK` 구역의 `스킨`·`표정` 탭):
   - **스킨**은 의상·변형 세트입니다. 조각(슬롯)마다 같은 첨부 이름에 다른 그림을 넣습니다. 클립은 그림 *이름*만 키로 쓰므로 의상을 바꿔도 새 애니메이션이 필요 없습니다(눈깜빡임이 `closed`를 키로 쓰면 겨울 스킨의 `closed` 그림이 보입니다).
     - `새 스킨`·`복제`·`이름 변경`·`삭제`. 목록에서 고른 스킨이 캔버스에 입혀집니다(미리 보기, 편집기 전용이라 저장되지 않음). `(기본 첨부)` = 스킨 없음.
     - 그림 넣기: 캔버스의 조각 위에 PNG 파일(또는 프로젝트 이미지)을 끌어 놓거나, 조각을 고르고 `그림 지정…`. 그 조각이 지금 보여 주는 첨부 이름(애니메이션 모드에서는 재생 헤드 시간의 이름, 예: 감은 눈)에 들어가고, 위치는 기본 그림 자리에서 시작합니다. `빼기`로 지우면 기본 그림이 보입니다.
     - 스킨 그림이 보이는 조각을 조립 모드에서 옮기면 그 스킨의 배치가 바뀝니다.
   - **표정**은 이름 붙인 얼굴·자세 세트입니다(조각별 그림, 본별 덮을 값).
     - 애니메이션 모드에서 눈·입 그림(첨부 콤보)이나 본을 바꾼 뒤 K를 누르기 전에 `현재 상태로 표정 만들기`를 누르면, 바뀐 부분만 새 표정이 됩니다. 클립 자체의 움직임(숨쉬기 등)은 담기지 않고, 바꾼 내용은 키로 저장되지 않습니다. `다시 담기`는 고른 표정을 덮어씁니다.
     - 목록에서 고른 표정이 캔버스에 겹쳐 보입니다. 아래 표에서 조각별 그림(`—` = 표정에 넣지 않음, `(숨김)`)과 본 값(`rotation=10, y=-3`, 비우면 뺌)을 고칩니다.
     - 표정은 기본 동작(트랙 0) 위, 레이어(트랙 1~15) 아래에 겹칩니다. 그래서 눈깜빡임 레이어는 표정 위에서도 계속 깜빡입니다. 레이어가 키로 쓰는 조각은 레이어 값이 보입니다.
     - 미리 보기 표정이 덮는 채널은 키를 바꿔도 캔버스에서 그대로 보입니다. 속성 칸과 K는 표정을 뺀 값을 씁니다.
     - 애니메이션 모드의 `표정 키`(키 도구 줄)는 고른 표정(없으면 "표정 없음")을 재생 헤드 시간에 키로 넣습니다. 도프시트의 `표정 (리그)` 행에 계단 키로 보입니다. 클립이 표정 키를 가지면 재생 중에는 그 값이 연결·기본 표정보다 우선합니다.
7. **IK**(오른쪽 `스킨 · 표정 · IK` 구역의 `IK` 탭): 손·발·시선 위치를 정하면 팔·다리·머리 회전이 따라오는 제약입니다.
   - **팔·다리 IK**: 아래팔(정강이)처럼 부모가 있는 본을 고르고 `팔·다리 IK`를 누르면 [위팔 → 아래팔] 사슬이 됩니다. 끝점은 아래팔의 첫 자식 본(손·발)의 원점입니다. 손 자리에 대상 본(캔버스의 주황 ✛)이 만들어지고, 지금 굽은 쪽을 그대로 써서 만든 순간 자세가 바뀌지 않습니다.
   - **조준 IK**: 머리·눈·무기 본을 고르고 `조준 IK`를 누르면 그 본의 x축(→)이 대상 본을 향합니다.
   - ✛를 캔버스에서 끌면 팔·다리가 바로 따라옵니다(끄는 동안은 미리 보기, 놓을 때 편집 한 번). 조립 모드에서는 대상 본의 기본 자세가, 애니메이션 모드에서는 대상 본 위치 키가 바뀝니다(자동 키가 꺼져 있으면 K로 저장). `대상 선택`은 ✛를 고릅니다.
   - `혼합`(0~1: 1 = IK가 자세를 정함, 0 = 키로 만든 회전 그대로)과 `굽힘`(팔꿈치·무릎이 굽는 쪽): 조립 모드에서는 IK의 기본값, 애니메이션 모드에서는 재생 헤드 시간의 키가 됩니다. 도프시트에 `IK <id> 혼합`(곡선 가능)·`IK <id> 굽힘`(계단) 행으로 보이고, 혼합 행을 누르면 그래프에 곡선이 나옵니다. `IK 키`는 두 값을 한 번에 키로 넣습니다.
   - `순서`: 작은 값부터 풉니다. 다른 IK가 움직이는 본을 대상·사슬로 쓰는 IK(예: 몸통 IK 뒤의 팔 IK)는 더 큰 순서로 둡니다.
   - `IK 결과를 키로 굽기`(애니메이션 모드): IK가 만든 회전을 재생 헤드 시간의 회전 키로 넣고 혼합을 0으로 키합니다. 그 뒤로는 일반 회전 키로 다듬습니다.
   - IK가 쓰는 본: 사슬을 끊는 부모 바꾸기와 대상을 사슬 아래로 옮기는 것은 거부됩니다. 사슬·대상 본을 지우면 그 IK와 키도 함께 지워집니다(확인 창에 표시). 속성 칸과 K는 IK를 뺀 키 값(회전)을 보여 주고 씁니다. 늘이기(stretch)는 아직 지원하지 않습니다.
8. **게임 연결 탭**:
   - 기본 대기 클립, 상시 레이어(예: 눈깜빡임, 트랙 1), 연결 규칙을 정합니다.
   - 연결 규칙 형식은 "신호 → 클립 → 종료 후 동작"입니다. 예: `actionResult`(outcome=success) → `joy` → `default`.
   - `characterId`를 정하면 대화·초상 신호의 `self=true`로 그 인물만 고를 수 있습니다.
   - `기본 스킨`·`기본 표정`은 새로 배치된 캐릭터의 처음 모습입니다. 연결 규칙의 `스킨`·`표정` 열은 신호가 오면 바꿀 스킨·표정입니다(`클립` = `— (클립 없음)`이면 트랙을 차지하지 않고 모습만 바꿉니다). 예: `portraitChanged`(portraitId=smile, self=true) → 표정 `smile`, `dialogueEnded`(self=true) → `(표정 없음으로)`.
   - 세이브에는 클립과 함께 스킨·표정이 저장되고 불러오면 그대로 돌아옵니다.
9. **화면 배치** (`화면 편집` 작업 공간):
   - 화면 편집의 `+ 요소`에서 `애니메이션 캐릭터`를 추가합니다.
   - 속성 패널에서 연결 문서를 고르고 크기·위치를 맞춥니다. `편집…`을 누르면 애니메이션 작업 공간이 그 연결 문서로 열립니다.
   - 배치한 캐릭터마다 스킨을 고르려면 속성 패널의 플러그인 속성(props) JSON에 `"skin": "<스킨 ID>"`를 넣습니다(예: `{"scale": 1, "skin": "winter"}`). 없으면 연결의 기본 스킨이고, 리그에 없는 ID는 진단에 경고로 나옵니다. 화면 편집 캔버스도 그 스킨으로 그립니다.
10. **플레이·내보내기**: 평소처럼 플레이하거나 Windows/Web으로 내보냅니다. 게임에는 런타임 모듈과 문서·이미지만 들어갑니다.

LLM(MCP)의 작업 경로도 사람과 같습니다.

- 같은 문서를 `apply_project_changes`로 고칩니다(`create`/`replace`).
- 같은 편집 연산과 템플릿은 `plugin_call`(op `edit`, `template`)로 호출합니다.
  곡선은 `setInterp`(`interp`: `step`·`linear`·`bezier`+`curve`·프리셋 이름)와 `setCurve`로 바꾸고, 여러 키는 `batch` 하나로 묶습니다(`docs/contract.md`).
  키 묶음 편집은 도프시트와 같은 연산 `moveKeys`·`scaleKeys`·`deleteKeys`·`copyKeys`/`pasteKeys`·`copyPose`/`pastePose`입니다.
  스킨·표정은 `addSkin`·`setSkinAttachment`·`renameSkin`·`deleteSkin`, `captureExpression`·`addExpression`·`setExpressionSlot`·`setExpressionBone`·`renameExpression`·`deleteExpression`, 표정 키는 `setKey`(`target: "rig"`, `property: "expression"`)입니다.
  IK는 `addIk`(`createTarget: true`로 대상 본 생성)·`setIk`·`renameIk`·`deleteIk`·`bakeIk`, 키는 `setKey`(`target: "ik:<id>"`, `property: "mix"`/`"bendPositive"`)입니다.
- 오래된 버전으로 고치면 `VERSION_CONFLICT`로 거부됩니다.

## 게임 시간과의 분리

- 게임 효과(비용·능력치·RNG)는 명령이 커밋될 때 이미 확정됩니다.
- 플레이어는 명령 하나당 `observe`를 한 번 호출해 신호를 만듭니다.
- 애니메이션 완료 알림은 표현만 바꾸고 게임 명령을 보내지 않습니다.
- 그래서 프레임 속도, 일시정지, 렌더링 속도는 게임 결과를 바꾸지 않습니다.

세이브 정책(`playerPresentation.extensions`):

- 스킨과 표정은 그대로 복원합니다(그 사이 지워진 ID는 연결의 기본값).
- 한 번만 재생되는 동작은 저장된 시간부터 이어서 재생합니다.
- 숨쉬기·눈깜빡임 같은 반복 장식 클립은 0부터 다시 시작합니다.
- 플러그인이 없어도 게임 세이브는 정상으로 불러옵니다.

## 범위

**포함하지 않는 것**

- 메시 변형·웨이트, 물리, IK 늘이기(stretch)·3본 이상 사슬
- Spine 파일 호환
- 공개 마켓·계정·결제
- 클립 이벤트 편집 UI. 데이터와 런타임은 지원합니다.

**플랫폼**

- 검증: Windows(네이티브 플레이어)와 Web(Wasm).
- 미검증: 모바일·콘솔, Electron 플레이어(자리표시자만 표시).

데이터 계약은 [docs/contract.md](docs/contract.md), 엔진 플러그인 계약은 [../../packages/plugin-host/CONTRACT.md](../../packages/plugin-host/CONTRACT.md)에 있습니다.
