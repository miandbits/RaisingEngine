# 컷아웃 캐릭터 애니메이션 플러그인 (cutout-animation 1.17.0)

뼈대(본)와 이미지 조각으로 2D 캐릭터를 조립하고 움직이는, 엔진 자체 형식(`raising-cutout-v1`)의 선택 설치형 플러그인입니다.
Spine 파일을 읽지 않으며 Spine 호환 제품이 아닙니다.

## 구성

| 경로 | 역할 | 게임에 포함되는가 |
|---|---|---|
| `core/` | Qt를 쓰지 않는 C++ 평가·재생 코어(검증, 보간, 트랙·전환, 신호, 편집 연산, 템플릿) | 런타임 모듈 안에 포함 |
| `studio/` | Qt 제작 패널 (`cutout-studio.dll`) | 포함 안 됨 |
| `service/` | Studio·MCP가 함께 쓰는 검증·도우미 모듈 (Node) | 포함 안 됨 |
| `schema/` | 리그·컨트롤러·설정 데이터 JSON Schema | — |
| `demo/` | 권리 문제 없는 데모 이미지 조각 생성기 | — |

빌드와 패키징:

```
npm run build:plugin:cutout
```

결과물은 `dist/plugins/cutout-animation-1.17.0.raiseplugin`입니다.
1.1.0은 베지어 보간(곡선)과 그래프 편집기, 시간 확대와 여러 키 선택·복사가 되는 도프시트를 더했습니다. 1.2.0은 스킨(의상·변형 세트)과 표정 세트를 더했습니다. 1.3.0은 IK 제약(팔·다리 두 본 IK, 한 본 조준)을 더했습니다. 1.4.0은 메시 첨부(그림을 휘게 하는 격자)와 본 웨이트·변형 키, IK 끝점(tip) 지정을 더했습니다. 1.4.1은 조준 IK의 조준 축(aimAxis)을 더해 아래로 늘어진 팔 그림도 대상을 똑바로 가리키게 했습니다. 1.4.2는 캔버스에서 IK 목표·본 손잡이가 겹친 그림보다 먼저 잡히게 하고 Alt+클릭으로 겹친 대상을 차례로 고르게 했습니다. 1.5.0은 본 길이(Spine처럼 원점에서 끝까지 그려지는 본), `본 만들기` 도구, 본 몸통 끌기 회전, `자동 길이`·`본 방향 맞추기`를 더했습니다. 1.6.0은 자유 메시(윤곽을 직접 그리거나 그림 알파에서 자동으로 찾아 만드는 메시, 정점 추가·삭제, 고정 가장자리, 다시 삼각분할)와 빠른 메시 그리기를 더했습니다. 1.7.0은 여러 본 선택(Ctrl/Shift+클릭, 상자 선택, 자식 본·모든 본 선택), 선택 전체 이동·회전·크기(각자 원점 / 선택 중심), 본·이미지 보정, 로컬·부모·월드 축 숫자 칸을 더했습니다(문서 형식은 그대로). 1.8.0은 클립 이벤트 편집(도프시트 `이벤트` 행, 이벤트 정의의 int·float·string 값과 소리, 키별 값 덮어쓰기, 재생 미리 보기 로그)과 그래프 편집기의 값 축 확대·이동·`값 맞춤`을 더했습니다. 1.9.0은 큰 캐릭터(본 200·조각 150·메시 40·키 9000개)를 빠르게 했고(압축 프레임, 편집 후 부분 새로 고침, 한 번만 하는 검증), 내보낼 때 그림을 아틀라스 페이지로 묶습니다(`내보내기` 탭). 1.10.0은 작업 공간을 처음부터 쓸 수 있게 다듬었습니다: 창 크기에 맞춘 자동 배치(어느 도구도 `»` 뒤로 숨지 않음), `작업 공간 글자 크기`, 명령 찾기(Ctrl+K), 처음 안내 줄, 이름 붙은 도구 묶음(문서 형식은 그대로). 1.11.0은 `PSD 가져오기…`를 더했습니다: Photoshop PSD·PSB(또는 PNG 폴더)의 레이어를 본·슬롯·그림으로 바꿔 문서와 똑같이 보이는 캐릭터를 만들고, 다시 가져오면 리그 작업을 지킨 채 그림만 갱신합니다. 1.12.0은 클리핑(다각형 안에서만 보이게 가리기)과 이미지 시퀀스(같은 크기 PNG 여러 장을 키로 넘기는 프레임 애니메이션)를 더했습니다. 1.13.0은 IK 늘이기(닿지 않는 대상까지 본 길이 방향으로 늘이기)와 본 3개 이상의 사슬 IK(꼬리·촉수·머리채), 그리고 머리카락·치마·장식이 움직임을 따라 흔들리는 물리를 더했습니다. 1.14.0은 PSD로 가져온 본이 그 부위 쪽을 향하고 길이를 갖게 해 물리·IK 늘이기가 바로 자연스럽게 움직이게 했고, 물리 탭에서 길이 없는 점 본을 알려 주고 바로 「본 방향 맞추기」를 하게 했으며, 「재생 중 물리」 켜짐/꺼짐을 글자로 보여 주고, 누르지 않은 숫자 칸·목록 위에서 휠을 굴려도 값이 바뀌지 않게(목록이 스크롤됨) 하고, `작업 공간 글자 크기`에 `자동`을 더했습니다. 편집기는 저장하지 않고 닫은 초안의 가져온 그림 파일을 지웁니다(엔진 공통). 1.14.1은 휠 막기가 실제 마우스 휠에서도 동작하게 고쳤습니다(1.14.0은 휠 한 번에 칸이 먼저 포커스를 받아 값이 바뀌었음). 1.15.0은 `PSD 가져오기`가 실제 작업 파일(5000×8000 px, 레이어 500개, 클리핑·혼합 모드·러시아어 이름)을 읽게 했습니다: `배율` 자동(큰 파일은 읽으면서 줄임), 클리핑 레이어를 아래 그림에 합치기, 그룹을 한 그림으로 합치기(`[merge]`, 한도를 넘으면 `자동 합치기`), `효과 레이어 빼기`, 키릴·그리스 문자 이름의 로마자 ID, 빈 레이어 요약. 1.16.0은 변형 제약(본이 다른 본의 위치·회전·크기·기울기를 혼합만큼 따름, 월드·로컬, 절대·상대, IK와 한 순서), 본 상속 방식(위치만·회전/뒤집기 제외·크기 제외 등)과 기울이기(shear, 키 가능)를 더했습니다. 1.17.0은 판정 상자(클릭하면 게임 연결의 `partClicked` 신호로 클립·표정을 트는, 그려지지 않는 다각형)와 기준점(말풍선 같은 UI를 붙일 위치·방향)을 더했습니다. 이전 버전으로 만든 문서는 그대로 열리고 똑같이 재생됩니다(본 1·2개 IK는 이전과 비트 단위로 같은 결과).

## 최소 제작 안내

1. **설치**: 편집기 `플러그인 → 플러그인 관리…`에서 `패키지 설치…`로 `.raiseplugin` 파일을 고릅니다. 그다음 `이 프로젝트에서 사용`을 누르면 `plugins/lock.json`에 버전이 고정됩니다.
2. **작업 공간 열기**: 메뉴 막대 오른쪽의 `화면 편집 | 캐릭터 애니메이션` 탭, `보기 → 작업 공간`, `캐릭터 애니메이션` 도크의 `작업 공간 열기` 또는 Ctrl+Shift+A로 애니메이션 전용 작업 공간으로 바꿉니다.
   - 창 전체가 Spine처럼 바뀝니다: 왼쪽 `계층`·`그리는 순서`·`캐릭터 · 게임 연결`(제목을 눌러 접기), 가운데 도구 줄과 큰 캔버스, 그 아래 `애니메이션`(클립 | 도프시트·그래프 | 전환)과 `게임 연결` 탭, 오른쪽 끝에서 끝까지 `속성 · 키`·`스킨 · 표정 · IK · 메시`·`진단`(진단은 작게 시작). `스킨 · 표정 · IK · 메시`의 각 탭은 버튼 줄을 목록 위아래에 고정해 두므로 1280x720 창부터 울트라와이드까지 스크롤 없이 보입니다(값 입력 칸만 필요하면 스크롤). 맨 위 모드 띠는 늘 보입니다.
   - **처음 배치**(1.10.0): 칸 크기는 창 크기에 비례해 정해지고, 각 칸은 가장 넓은 도구 줄이 다 보이는 폭 아래로 줄지 않습니다. 1280x720부터 1920x1080, 2560x1440, 3840x2160, 5120x1440 울트라와이드, 1440x2560 세로 화면까지(Windows 배율 100·150·200 %) 열자마자 모든 도구가 보이고, 끝의 `»`(넘친 도구)는 1280보다 좁은 창에서만 나옵니다. 넓은 화면에서 좌우 패널은 필요한 폭의 몇 배까지만 넓어지고 나머지는 캔버스와 시간 영역이 씁니다.
   - 칸 사이 경계를 끌어 크기를 바꾸면 그때부터 그 배치가 이 컴퓨터에 기억됩니다. 다시 열 때 너무 좁아 도구가 숨을 칸은 필요한 폭으로 넓혀 복원합니다(1.9.0 이하에서 저장된 배치는 쓰지 않고 자동 배치로 시작). `보기 ▾ › 레이아웃 초기화`는 자동 배치로 되돌립니다.
   - **글자 크기**: `보기 ▾ › 작업 공간 글자 크기`(작게·보통·크게·아주 크게) 또는 작업 공간 안에서 Ctrl+= / Ctrl+-(Ctrl+0 = 보통). 편집기 글꼴 위에 배율을 곱해 글자, 아이콘, 줄 높이, 도프시트 행 높이·눈금자, 그래프 키, 캔버스 손잡이와 잡는 거리를 함께 키웁니다. 이 컴퓨터에만 저장되며, 정하지 않았으면 화면에 맞춰 시작합니다(Windows 배율 100 %인 QHD·울트라와이드는 크게, 4K는 아주 크게). `자동 (화면에 맞춤)`을 고르면 저장한 크기를 지우고 다시 화면에 맞춥니다. `플러그인 → 캐릭터 애니메이션` 메뉴에도 있습니다.
   - **휠과 숫자 칸**: 누르지 않은(포커스 없는) 숫자 칸·목록 상자 위에서 휠을 굴리면 값이 바뀌지 않고 그 영역이 스크롤됩니다. 칸을 눌러 커서가 있을 때만 휠로 값을 올리고 내립니다.
   - **명령 찾기**(Ctrl+K 또는 F1): 작업 공간의 모든 버튼·메뉴 명령·탭을 한국어 이름, 묶음(예: `스킨 삭제`, `메시 정점`) 또는 단축키(예: `K`, `Ctrl+C`)로 찾아 Enter로 실행합니다. 실행은 그 버튼을 누른 것과 같고(편집하는 명령은 편집 한 번), 접힌 구역·다른 탭에 있는 버튼이면 그 탭을 열어 줍니다. 지금 쓸 수 없는 명령(예: 조립 모드의 키 복사)은 흐리게 보입니다.
   - 도구 줄은 이름 붙은 묶음입니다: 캔버스 위 `선택`·`변형`·`본` 도구, 둘째 줄 `선택 ▾`·`변형 옵션`, 계층 아래 `본`, 그리는 순서 아래 `조각`(`이미지 조각 추가…`, 뒤로/앞으로), 시간 영역의 `재생`·`시간`·`키`·`타이밍`(시간 축 확대 포함)·`곡선`, 맨 위 모드 띠 오른쪽 `보기`(어니언 스킨·궤적·화면 맞춤·캔버스 크게·`보기 ▾`). 모든 도구에 마우스를 올리면 설명과 단축키가 나옵니다.
   - 처음 열면 캔버스 위에 안내 줄(명령 찾기, 조립 → 애니메이션 순서, 글자 크기)이 보입니다. `닫기 ✕`로 닫고 `보기 ▾ › 도움말 줄 보이기`로 다시 켭니다(편집기 전용 설정).
   - 캔버스·도프시트·그래프에서 Tab(또는 `캔버스 크게`)을 누르면 좌우 패널을 숨겨 캔버스를 넓힙니다. 숫자 칸의 Tab은 그대로 다음 칸으로 이동합니다.
   - 같은 단축키나 `화면 편집` 탭으로 돌아가면 도크 배치가 떠나기 전 그대로 돌아옵니다. 파일·편집(되돌리기·다시 실행)·저장·플레이는 작업 공간에서도 그대로 쓸 수 있고, 작업 공간을 바꾸는 것만으로는 문서가 바뀌지 않습니다. 작업 공간에 있던 채로 프로젝트를 닫았다 다시 열면 그 작업 공간으로 돌아옵니다.
   - 작업 공간을 모르는 이전 편집기에서는 같은 패널이 `캐릭터 애니메이션` 도크 안에 그대로 나옵니다.
3. **새 캐릭터**: 작업 공간 왼쪽 아래 `새 캐릭터`를 누릅니다. 리그(`plugins/cutout-animation/rig/<id>.json`)와 연결(`…/controller/<id>.json`)이 함께 만들어집니다.
4. **조립(파란 띠, 조립 모드)**:
   - `이미지 조각 추가…`로 PNG를 가져옵니다.
   - 트리에서 끌어 놓아 부모를 바꿉니다. 화면상 위치는 유지됩니다.
   - `회전 중심`(P) 도구로 관절 위치를 찍습니다. 자식 본과 조각이 같이 보정됩니다.
   - 위치·회전·크기는 캔버스(V/R/S) 또는 속성 숫자 칸으로 편집합니다.
   - **본 길이**(1.5.0, Spine식 본): 길이가 있는 본은 원점에서 본의 +x 방향으로 끝까지 가늘어지는 마름모로 그려지고(길이 0이면 지금처럼 점 본), 선택은 노란색, 마우스를 올리면 밝게 보입니다. 이동(V)·회전(R) 도구에서 **본 몸통을 끌면 원점을 중심으로 돌고**, **원점을 끌면 옮겨집니다**(선택한 점 본은 축 눈금이 몸통입니다). 애니메이션 모드에서는 같은 끌기가 회전·위치 키가 됩니다.
     - `본 만들기`(C, 조립 모드): 빈 곳(또는 그림·본 몸통 위)에서 끌면 고른 본(조각을 골랐으면 그 본, 없으면 루트)의 자식 본이 생깁니다. 누른 곳이 원점, 끈 방향과 거리가 회전과 길이이고(부모가 돌거나 커져 있어도 끝이 커서 자리에 옵니다), 클릭만 하면 길이 0 본입니다. Shift를 누르면 화면 각도가 15° 단위로 맞춰집니다. 만든 본이 선택되므로 그 끝에서 다시 끌면 다음 마디가 이어집니다. 본 원점을 누르면 만들지 않고 그 본을 부모로 고릅니다. 한 번 끌기 = 편집 한 번입니다.
     - 속성의 `본 길이` 칸(조립 모드 전용, 키가 아님), `자동 길이`(고른 본, 없으면 모든 본의 길이를 첫 자식 본까지의 거리로), `본 방향 맞추기`(길이 0인 예전 본을 자식 본이나 그림이 뻗은 쪽으로 돌리고 길이를 넣음: 자식·그림·키·표정·조준 축을 함께 보정하므로 애니메이션은 한 픽셀도 바뀌지 않습니다. 가로·세로 크기가 다르게 키된 본(숨쉬기 몸통 등)은 그대로 둡니다)는 계층 아래 줄에 있습니다.
     - 본 색(`color`, 편집기 표시용)은 데이터에 `"#rrggbb"`로 넣으면 그 색으로 그려집니다(게임에는 영향 없음).
   - 캔버스에서 누를 때는 **손잡이가 그림보다 먼저** 잡힙니다(Spine처럼): 메시 정점(정점 편집 중) → IK 대상 ✛(선 어디를 눌러도) → 선택한 본의 원점·축 → 다른 본 원점 → 본 몸통 → 맨 위 그림 조각 순입니다. 손잡이에서 떨어진 곳을 누르면 그림 조각을 고르고 끕니다. 마우스를 올리면 잡힐 대상이 흰 테두리로 보이고 캔버스 아래에 `가리킴: …`으로 나옵니다. 겹친 것 가운데 다른 것을 고르려면 **Alt+클릭**을 되풀이합니다(커서 아래 후보를 차례로 돕니다). 눈 아이콘으로 숨긴 조각은 잡히지 않습니다.
   - **여러 본 선택**(1.7.0): 캔버스·계층·도프시트 행에서 Ctrl 또는 Shift+클릭으로 더하거나 빼고, 이동(V) 도구로 빈 곳을 끌면 상자 안의 본 원점이 모두 골라집니다(Ctrl/Shift = 더하기, 빈 곳 클릭 = 해제, 화면 이동은 가운데·오른쪽 버튼). 캔버스나 계층에 초점이 있을 때 Ctrl+A는 모든 본을 고르고, 계층에 초점이 있을 때 Ctrl+Shift+A는 고른 본의 자식 본까지 더합니다(캔버스에서 Ctrl+Shift+A는 그대로 작업 공간 전환입니다). 같은 명령이 캔버스 위 둘째 줄의 `선택 ▾`에도 있습니다. 고른 것은 캔버스(노란색)·계층·도프시트 행 이름(노란 띠)에 함께 표시됩니다.
     - 고른 본 가운데 하나를 끌면 **모두가 함께** 움직입니다(편집 한 번). 옮기기는 맨 위의 고른 본만 옮기고(고른 자식은 따라감), 회전·크기는 `중심`이 `각자 원점`이면 본마다 자기 원점을 중심으로(이어진 팔은 함께 휨), `선택 중심`이면 고른 본 원점들의 가운데를 중심으로 한 덩어리처럼 돕니다. 고른 본 하나를 클릭만 하면 그 본만 남습니다.
     - `본 보정`·`이미지 보정`(조립 모드): 켜 두면 본을 옮기거나 돌려도 고르지 않은 자식 본 / 그 본에 붙은 그림(모든 스킨)은 화면 자리에 그대로 있습니다(Spine과 같이 기본 자세에만 적용, 애니메이션 모드의 키에는 적용되지 않음). 자식 본에 이미 키가 있으면 그 키는 예전 기본 자세 기준이라는 경고가 진단에 남습니다.
     - 속성 칸은 고른 본 모두에 적용됩니다(편집 한 번). 값이 서로 다르면 `—`가 보이고, 입력한 값이 모두의 값이 됩니다. `상대값 입력`을 켜면 칸이 0이 되고 입력한 값이 본마다 지금 값에 더해집니다. `숫자 축`(로컬 / 부모 / 월드)으로 X·Y·회전을 부모 기준 저장값, 부모 축 기준 px·각도, 캐릭터 화면 좌표·화면 각도로 보고 입력합니다(저장은 언제나 로컬, 크기는 언제나 로컬). 애니메이션 모드의 K는 고른 본·조각을 모두 키로 넣고, `포즈 복사`는 고른 본만(팔 전체는 자식 본까지 선택한 뒤) 복사합니다.
   - 표시 순서는 위/아래 버튼으로 바꿉니다.
   - 눈 아이콘으로 숨긴 상태는 편집기에서만 적용되고 저장되지 않습니다.
5. **애니메이션(빨간 띠, 애니메이션 모드)**:
   - 클립을 만들고 길이와 반복 여부를 정합니다.
   - 재생 헤드 위치에서 값을 바꾼 뒤 `키`(K)를 누르면 키가 저장됩니다. 자동 키는 기본으로 꺼져 있습니다.
   - 첨부 콤보로 눈·입 이미지를 바꾸면 표정 키가 됩니다.
   - 키는 도프시트에서 이동·삭제하고, 우클릭으로 보간(선형, 계단, 천천히 시작, 천천히 끝, 천천히 시작·끝, 부드럽게, 튕김)을 고릅니다.
     도프시트의 구간 선 모양이 보간을 보여 줍니다: 곧은 선 = 선형, 점선 = 계단, 청록색 곡선 = 베지어.
   - **시간 축**(도프시트·그래프 공통): Ctrl+휠로 커서 위치를 중심으로 확대/축소, Shift+휠·가운데 버튼 드래그·아래 가로 스크롤바로 이동, `맞춤`은 클립 전체 보기입니다. 눈금 간격은 확대에 맞춰 1ms까지 바뀌고, 왼쪽 위에 보이는 범위(ms)가 표시됩니다. 눈금자와 선택 띠는 행을 내려도 위에 남습니다.
     - 몇 픽셀 안에 겹친 키는 숫자가 적힌 **묶음**으로 그립니다. 누를 때마다 묶음 안의 다음 키가 선택되고, 더블클릭하면 키가 구별될 만큼 확대합니다.
     - 재생 헤드: `시간` 칸에 ms를 직접 입력하거나, ◀ ▶ 버튼·쉼표/마침표·←/→ 키로 `간격`(기본 10ms)만큼 옮깁니다. 눈금자 클릭은 10ms 단위, Shift를 누르면 1ms 단위입니다.
     - `[ 구간 시작`·`구간 끝 ]`(또는 눈금자의 초록 표시 끌기)로 미리 보기 반복 구간을 정하면 재생이 그 안에서 반복됩니다. 편집기 전용이라 문서·게임에 저장되지 않습니다(클립마다 기억, `구간 해제`).
   - **키 선택**(도프시트·그래프 공통): 클릭, Ctrl+클릭(토글), Shift+클릭(추가), 빈 곳 드래그(상자 선택), 행 이름 클릭(행 전체), Alt+클릭(같은 시간의 키 모두), Ctrl+A.
     - 고른 키 하나를 끌면 고른 키 전부가 간격을 유지한 채 함께 움직입니다(10ms 단위, Shift 1ms). 다른 키와 겹치거나 클립 밖으로 나가면 거부됩니다. 놓을 때 편집 한 번이라 Ctrl+Z 한 번으로 돌아갑니다.
     - 행 위의 노란 **선택 띠** 양 끝 손잡이를 끌면 시간 간격을 늘이거나 줄입니다(반대쪽 끝 기준, Alt: 재생 헤드 기준). 숫자로는 `간격 배율`(%)과 `만큼 이동`(ms) 칸을 씁니다. 곡선 모양은 그대로 따라갑니다.
     - Delete: 고른 키 삭제 · Ctrl+C(`복사`)·Ctrl+V(`붙여넣기`): 재생 헤드 시간에 붙여넣기. 다른 클립에도 되고, 같은 시간의 키는 덮어씁니다. 한 대상만 복사했다면 지금 고른 본·조각에 붙습니다 · Ctrl+D(`복제`): 고른 키를 재생 헤드 시간에 복제.
     - `포즈 복사`는 고른 본과 그 자식 본(없으면 모든 본)의 지금 자세를, `포즈 붙여넣기`는 그 자세를 재생 헤드 시간의 키로 넣습니다. 여러 클립의 시작·끝 자세를 맞출 때 씁니다.
   - **그래프 편집기**(도프시트 아래, `그래프` 버튼으로 보이기/숨기기): 고른 본·조각의 숫자 트랙(X·Y·회전·크기·투명도)을 채널별 색 곡선으로 보여 줍니다.
     - 빈 곳을 누르면 재생 헤드만 옮깁니다(이벤트는 울리지 않음). 시간 눈금은 도프시트와 같습니다.
     - 키를 위아래로 끌면 값, 좌우로 끌면 시간이 바뀝니다(Alt: 둘 다, Shift: 1ms). 다른 키가 있는 시간으로는 옮겨지지 않습니다.
     - 고른 키의 손잡이를 끌면 그 구간 곡선이 바뀝니다. 놓을 때 한 번만 저장되므로 되돌리기(Ctrl+Z) 한 번이면 원래대로 돌아갑니다.
     - `곡선` 줄의 프리셋 버튼(또는 우클릭)은 고른 키 전부에 한 번의 편집으로 적용됩니다. Ctrl+클릭으로 여러 키, Ctrl+A로 모두 고릅니다.
     - `채널별 맞춤`은 범위가 다른 채널(각도와 크기)을 각자 높이에 맞춰 모양을 비교합니다. 범례를 누르면 채널을 숨깁니다(저장 안 됨).
     - **값 축**: Ctrl+Shift+휠 또는 Alt+휠로 커서 위치의 값을 중심으로 세로 확대/축소, 가운데 버튼 드래그로 시간·값을 함께 이동합니다. 시간 축(도프시트와 공통)은 그대로이고, 확대한 채로 키·손잡이를 끌 수 있으며 편집·되돌리기 뒤에도 보던 범위가 유지됩니다. `값 맞춤`은 보이는 채널이 모두 들어오게 되돌립니다(편집기 전용).
   - **클립 이벤트**(발소리·효과음·타격 표시 등, 표시 전용): 도프시트 맨 아래 `이벤트` 행에 분홍 깃발과 이름으로 보입니다.
     - `이벤트 키`(키 도구 줄, `이벤트` 페이지) 또는 `이벤트` 행 오른쪽 클릭 `여기에 이벤트 추가` · 빈 곳 더블클릭: `스킨 · 표정 · IK · 메시 · 이벤트` 구역의 `이벤트` 페이지에서 고른 이벤트를 그 시간에 넣습니다. 정의가 없으면 이름을 묻습니다.
     - 깃발을 끌면 이동(같은 이름이 있는 시간으로는 거부), Delete로 삭제, 더블클릭(또는 `키 편집…`)으로 이름과 그 키만의 int·float·string 값을 바꿉니다. 다른 키와 함께 골라 함께 옮기고 복사·붙여넣기도 됩니다.
     - `이벤트` 페이지: `새 이벤트`·`이름 변경`(모든 클립의 키도 함께)·`삭제`(키가 있으면 묻고 함께 삭제), 기본 값 int·float·string과 `소리`(프로젝트 오디오 에셋)·`음량`·`좌우`. 정의가 하나라도 있으면 키는 정의된 이름만 씁니다.
     - `미리 보기 로그`: ▶ 재생(반복하면 한 바퀴에 한 번씩)과 `게임 연결` 미리 보기에서 일어난 이벤트를 값과 함께 보여 줍니다. 재생 헤드를 끌거나 시간을 입력하는 것(스크럽)은 이벤트를 일으키지 않습니다. 소리는 편집기에서 재생하지 않습니다.
     - 게임에서는 플레이어가 소리를 재생하고(소리가 켜져 있을 때) 이벤트 값은 자동화 보고서에 남습니다. 게임 연결 규칙은 이벤트에 반응할 수 없습니다(게임 규칙은 애니메이션 시간과 무관).
   - `숨쉬기`·`눈깜빡임` 템플릿은 일반 키로 된 클립을 만듭니다. 숨쉬기는 `천천히 시작·끝` 곡선 키 3개(쉼 → 들숨 → 쉼)입니다.
   - **어니언 스킨**(모드 띠 오른쪽 `보기` 묶음의 `어니언 스킨`, 단축키 O): 앞뒤 시간의 자세를 지금 자세 뒤에 반투명하게 겹쳐 그립니다. 이전은 빨강, 이후는 초록이 기본입니다.
     - `▾` 설정: 앞·뒤 개수(0~10), 방식(`일정 간격` ms 또는 `키 위치만`), 가장 가까운 유령의 불투명도, `멀수록 흐리게`, 이전/이후 색(`원래 색`은 칠하지 않음), `현재 시간도 표시`(저장된 자세를 회색으로: 키로 저장하지 않은 변경과 비교), `선택한 본과 자식만`.
     - `키 위치만`은 고른 본·조각의 앞뒤 키 시간에 그립니다. 고른 대상에 키가 없으면 보이는 모든 트랙의 키를 씁니다.
     - 반복 클립은 끝을 넘어가면 처음으로 이어지고, 한 번 재생 클립은 처음·끝에서 멈춥니다. 게임 연결 탭의 미리 보기(전환·레이어)에는 그리지 않습니다.
     - `궤적`: 고른 본의 원점이 클립 동안 지나는 길을 선으로, 키 시간(그 본과 부모 본의 키)을 점으로 보여 줍니다.
     - 모두 편집기 전용입니다. 켜고 끄거나 설정을 바꿔도 문서는 바뀌지 않고, 설정은 이 컴퓨터의 편집기 환경에만 기억됩니다.
6. **스킨 · 표정**(오른쪽 `스킨 · 표정 · IK · 메시` 구역의 `스킨`·`표정` 탭):
   - **스킨**은 의상·변형 세트입니다. 조각(슬롯)마다 같은 첨부 이름에 다른 그림을 넣습니다. 클립은 그림 *이름*만 키로 쓰므로 의상을 바꿔도 새 애니메이션이 필요 없습니다(눈깜빡임이 `closed`를 키로 쓰면 겨울 스킨의 `closed` 그림이 보입니다).
     - `새 스킨`·`복제`·`이름 변경`·`삭제`. 목록에서 고른 스킨이 캔버스에 입혀집니다(미리 보기, 편집기 전용이라 저장되지 않음). `(기본 첨부)` = 스킨 없음.
     - 그림 넣기: 캔버스의 조각 위에 PNG 파일(또는 프로젝트 이미지)을 끌어 놓거나, 조각(트리·캔버스·스킨 목록)을 고르고 `그림 지정…`. 그 조각이 지금 보여 주는 첨부 이름(애니메이션 모드에서는 재생 헤드 시간의 이름, 예: 감은 눈)에 들어가고, 위치는 기본 그림 자리에서 시작합니다. `빼기`로 지우면 기본 그림이 보입니다.
     - `그림 지정…` 창(`스킨 그림 지정 — <스킨>`): `조각`은 있는 조각 중에서만 고르고(고른 조각, 본을 골랐으면 그 본의 첫 조각으로 시작), `첨부 이름`은 그 조각의 이름 목록에서 고르거나 새 이름을 입력합니다. 이미지 목록(썸네일, `PNG 가져오기…`)에서 그림을 고르면 오른쪽에 결과가 미리 보이고, 그림을 골라도 조각·이름은 바뀌지 않습니다. 확인 한 번 = 편집 한 번(Ctrl+Z로 되돌림).
     - `이미지 조각 추가…`에서 그림을 고르면 `조각 ID`가 비어 있거나 자동으로 채운 값일 때만 그림 이름으로 채워집니다. 고른 조각으로 미리 채워졌거나 직접 입력한 ID와 `첨부 이름`은 그대로입니다.
     - 스킨 그림이 보이는 조각을 조립 모드에서 옮기면 그 스킨의 배치가 바뀝니다.
   - **표정**은 이름 붙인 얼굴·자세 세트입니다(조각별 그림, 본별 덮을 값).
     - 애니메이션 모드에서 눈·입 그림(첨부 콤보)이나 본을 바꾼 뒤 K를 누르기 전에 `현재 상태로 표정 만들기`를 누르면, 바뀐 부분만 새 표정이 됩니다. 클립 자체의 움직임(숨쉬기 등)은 담기지 않고, 바꾼 내용은 키로 저장되지 않습니다. `다시 담기`는 고른 표정을 덮어씁니다.
     - 목록에서 고른 표정이 캔버스에 겹쳐 보입니다. 아래 표에서 조각별 그림(`—` = 표정에 넣지 않음, `(숨김)`)과 본 값(`rotation=10, y=-3`, 비우면 뺌)을 고칩니다.
     - 표정은 기본 동작(트랙 0) 위, 레이어(트랙 1~15) 아래에 겹칩니다. 그래서 눈깜빡임 레이어는 표정 위에서도 계속 깜빡입니다. 레이어가 키로 쓰는 조각은 레이어 값이 보입니다.
     - 미리 보기 표정이 덮는 채널은 키를 바꿔도 캔버스에서 그대로 보입니다. 속성 칸과 K는 표정을 뺀 값을 씁니다.
     - 애니메이션 모드의 `표정 키`(키 도구 줄)는 고른 표정(없으면 "표정 없음")을 재생 헤드 시간에 키로 넣습니다. 도프시트의 `표정 (리그)` 행에 계단 키로 보입니다. 클립이 표정 키를 가지면 재생 중에는 그 값이 연결·기본 표정보다 우선합니다.
7. **IK**(오른쪽 `스킨 · 표정 · IK · 메시` 구역의 `IK` 탭): 손·발·시선 위치를 정하면 팔·다리·머리 회전이 따라오는 제약입니다.
   - **팔·다리 IK**: 아래팔(정강이)처럼 부모가 있는 본을 고르고 `팔·다리 IK`를 누르면 [위팔 → 아래팔] 사슬이 됩니다. 끝점은 아래팔에 길이가 있으면 **아래팔의 끝**(1.5.0), 없으면 아래팔의 첫 자식 본(손·발)의 원점이고, 후자는 만들 때 그 본이 IK의 `tip`(끝점)으로 저장되어 나중에 아래팔에 다른 자식 본(소매·무기)을 더해도 바뀌지 않습니다. 이미 IK가 있는 아래팔에 길이를 넣으면(속성 칸·`자동 길이`·`본 방향 맞추기`) 쓰던 자식 본이 `tip`으로 고정되어 팔이 움직이지 않습니다. 손 자리에 대상 본(캔버스의 주황 ✛)이 만들어지고, 지금 굽은 쪽을 그대로 써서 만든 순간 자세가 바뀌지 않습니다.
   - **조준 IK**: 머리·눈·무기·팔 본을 고르고 `조준 IK`를 누르면 그 본의 **조준 축**이 대상 본을 향합니다. 조준 축은 본이 실제로 뻗은 방향에서 시작합니다: 길이가 있는 본이면 본 방향(+x, 조준 축 없음 · 대상은 본 끝에), 자식 본이 있으면 그쪽, 없으면 그 본에 붙은 그림이 뻗은 쪽(회전 0인 채 아래로 늘어진 팔 그림이면 90° = 아래). 대상 본(✛)은 그 축 끝에 만들어지므로 만들 때 팔이 움직이지 않습니다.
     - `조준 축(°)`(0 = 오른쪽 →, 90 = 아래 ↓)을 직접 고치거나, 대상을 옮겨 둔 채 `현재 방향으로 맞추기`를 누르면 지금 본이 대상 쪽을 보는 각도가 축이 됩니다(IK를 켜도 본이 돌지 않음). 캔버스에는 조준 축이 주황색 화살표로 보입니다.
     - 팔·다리 IK(두 본)는 본 위치(팔꿈치·손목)로 풀기 때문에 조준 축을 쓰지 않습니다. 그림이 팔을 따라 놓이게 하려면 손목 본을 그림 끝에 두세요.
   - ✛를 캔버스에서 끌면 팔·다리가 바로 따라옵니다(끄는 동안은 미리 보기, 놓을 때 편집 한 번). 조립 모드에서는 대상 본의 기본 자세가, 애니메이션 모드에서는 대상 본 위치 키가 바뀝니다(자동 키가 꺼져 있으면 K로 저장). `대상 선택`은 ✛를 고릅니다.
   - `혼합`(0~1: 1 = IK가 자세를 정함, 0 = 키로 만든 회전 그대로)과 `굽힘`(팔꿈치·무릎이 굽는 쪽): 조립 모드에서는 IK의 기본값, 애니메이션 모드에서는 재생 헤드 시간의 키가 됩니다. 도프시트에 `IK <id> 혼합`(곡선 가능)·`IK <id> 굽힘`(계단) 행으로 보이고, 혼합 행을 누르면 그래프에 곡선이 나옵니다. `IK 키`는 두 값을 한 번에 키로 넣습니다.
   - `순서`: 작은 값부터 풉니다. 다른 IK가 움직이는 본을 대상·사슬로 쓰는 IK(예: 몸통 IK 뒤의 팔 IK)는 더 큰 순서로 둡니다.
   - `IK 결과를 키로 굽기`(애니메이션 모드): IK가 만든 회전을 재생 헤드 시간의 회전 키로 넣고 혼합을 0으로 키합니다. 그 뒤로는 일반 회전 키로 다듬습니다.
   - IK가 쓰는 본: 사슬을 끊는 부모 바꾸기와 대상을 사슬 아래로 옮기는 것은 거부됩니다. 사슬·대상 본을 지우면 그 IK와 키도 함께 지워집니다(확인 창에 표시). 속성 칸과 K는 IK를 뺀 키 값(회전)을 보여 주고 씁니다. 늘이기(stretch)는 아직 지원하지 않습니다.
8. **메시**(오른쪽 구역의 `메시` 탭): 그림을 격자로 나눠 본을 따라 휘게 하거나(팔꿈치·허리·옷자락) 키로 모양을 바꿉니다(볼 부풀리기·머리카락 흔들림).
   - 조립 모드에서 조각을 고르고 `세로`·`가로` 칸 수를 정한 뒤 `메시로 변환`을 누릅니다. 모양은 그대로이고, `투명 칸 빼기`를 켜면 그림이 없는 칸은 빠집니다. `이미지로 되돌리기`는 보통 그림으로 되돌립니다(그 메시의 변형 키도 지워짐).
   - **윤곽 그리기**(1.6.0): 조각을 고르고 `윤곽 그리기`를 누른 뒤 캔버스에서 그림 둘레를 차례로 클릭합니다. 첫 점을 다시 누르거나 더블클릭·Enter로 닫으면 그 안을 삼각형으로 나눈 메시가 됩니다(오목한 모양도 됨, 스스로 교차하는 윤곽은 이유와 함께 거부). Backspace는 마지막 점을, Esc는 그리기를 취소합니다. `안쪽 간격`을 정하면 안쪽에 그 간격(그림 px)으로 정점을 채워 더 부드럽게 휩니다.
   - **자동 윤곽**(1.6.0): `알파 기준`(이보다 불투명한 픽셀이 그림)·`윤곽 디테일`(1에 가까울수록 점이 많음)을 정하고 `자동 윤곽`을 누르면 가장 큰 불투명 덩어리를 따라 윤곽을 찾아 메시로 만듭니다. `자동 윤곽 미리보기`를 켜면 만들 윤곽이 캔버스에 분홍 점선으로 보입니다.
   - `정점 편집`: 캔버스에서 정점을 클릭(Shift+클릭 추가)하거나 빈 곳을 끌어 상자로 고르고, 정점을 끌어 옮깁니다. 조립 모드에서는 메시 모양이 바뀌고 그림은 제자리에 있습니다. 주황 선은 윤곽, 하늘색 선은 고정 가장자리입니다.
   - 정점 편집 중(조립 모드)에는 웨이트 줄 대신 모양 도구가 나옵니다(1.6.0): `정점 추가`(메시 안을 클릭하면 안쪽 정점, 윤곽 가까이를 클릭하면 윤곽 정점), `가장자리 추가`(정점에서 정점으로 끌어 그 선을 고정: 다시 나눠도 남아 메시가 그 선을 따라 접힘), `정점 삭제`(Delete), `가장자리 삭제`(고른 두 정점 사이 고정 풀기), `다시 삼각분할`(정점을 많이 옮겨 삼각형이 뒤집혔을 때). 새 정점의 웨이트·변형 키는 주변 정점 값을 섞어 받으므로 그림과 애니메이션이 튀지 않습니다. 모든 동작이 편집 한 번이고 Ctrl+Z로 되돌립니다.
   - **웨이트**: `자동 웨이트에 쓸 본` 목록에서 본(예: 위팔·아래팔)을 체크하고 `자동 웨이트`를 누르면 정점마다 가까운 본 1~4개가 부드럽게 나뉘어 정해집니다(체크가 없으면 조각의 본과 그 부모·자식). 웨이트를 줘도 기본 자세 모양은 바뀌지 않고, 애니메이션 모드에서 본을 움직이면 메시가 휘어집니다. IK로 푼 자세도 그대로 따라갑니다.
   - `웨이트 칠하기`: `칠할 본`·`웨이트`(목표값)·`세기`·`붓 크기`를 정하고 캔버스를 끌어 칠합니다. 고른 본의 웨이트가 색으로 보입니다(파랑 0 → 빨강 1). 한 번 끌기가 편집 한 번입니다. `웨이트 해제`는 웨이트를 지웁니다.
   - **변형 키**(애니메이션 모드): `정점 편집`을 켜고 정점을 끌면 이 시간의 메시 모양이 바뀌고, K(또는 `변형 키`)로 키가 됩니다(자동 키가 켜져 있으면 바로). 도프시트에 `<조각> 변형 (<첨부>)` 행으로 보이고 곡선 보간도 됩니다. `변형 키 삭제`는 재생 헤드 시간의 키를 지웁니다.
   - 스킨에도 메시를 둘 수 있습니다(미리 보기 스킨이 그 그림을 가진 조각은 그 스킨의 메시가 바뀝니다). 메시를 쓰는 게임은 `plugin-mesh-v1`을 지원하는 플레이어(이번 빌드의 Windows·Web 플레이어)로만 내보내집니다.
9. **게임 연결 탭**:
   - 기본 대기 클립, 상시 레이어(예: 눈깜빡임, 트랙 1), 연결 규칙을 정합니다.
   - 연결 규칙 형식은 "신호 → 클립 → 종료 후 동작"입니다. 예: `actionResult`(outcome=success) → `joy` → `default`.
   - `characterId`를 정하면 대화·초상 신호의 `self=true`로 그 인물만 고를 수 있습니다.
   - `기본 스킨`·`기본 표정`은 새로 배치된 캐릭터의 처음 모습입니다. 연결 규칙의 `스킨`·`표정` 열은 신호가 오면 바꿀 스킨·표정입니다(`클립` = `— (클립 없음)`이면 트랙을 차지하지 않고 모습만 바꿉니다). 예: `portraitChanged`(portraitId=smile, self=true) → 표정 `smile`, `dialogueEnded`(self=true) → `(표정 없음으로)`.
   - 세이브에는 클립과 함께 스킨·표정이 저장되고 불러오면 그대로 돌아옵니다.
10. **화면 배치** (`화면 편집` 작업 공간):
   - 화면 편집의 `+ 요소`에서 `애니메이션 캐릭터`를 추가합니다.
   - 속성 패널에서 연결 문서를 고르고 크기·위치를 맞춥니다. `편집…`을 누르면 애니메이션 작업 공간이 그 연결 문서로 열립니다.
   - 배치한 캐릭터마다 스킨을 고르려면 속성 패널의 플러그인 속성(props) JSON에 `"skin": "<스킨 ID>"`를 넣습니다(예: `{"scale": 1, "skin": "winter"}`). 없으면 연결의 기본 스킨이고, 리그에 없는 ID는 진단에 경고로 나옵니다. 화면 편집 캔버스도 그 스킨으로 그립니다.
11. **플레이·내보내기**: 평소처럼 플레이하거나 Windows/Web으로 내보냅니다. 게임에는 런타임 모듈과 문서·이미지만 들어갑니다.

LLM(MCP)의 작업 경로도 사람과 같습니다.

- 같은 문서를 `apply_project_changes`로 고칩니다(`create`/`replace`).
- 같은 편집 연산과 템플릿은 `plugin_call`(op `edit`, `template`)로 호출합니다.
  곡선은 `setInterp`(`interp`: `step`·`linear`·`bezier`+`curve`·프리셋 이름)와 `setCurve`로 바꾸고, 여러 키는 `batch` 하나로 묶습니다(`docs/contract.md`).
  키 묶음 편집은 도프시트와 같은 연산 `moveKeys`·`scaleKeys`·`deleteKeys`·`copyKeys`/`pasteKeys`·`copyPose`/`pastePose`입니다.
  스킨·표정은 `addSkin`·`setSkinAttachment`·`renameSkin`·`deleteSkin`, `captureExpression`·`addExpression`·`setExpressionSlot`·`setExpressionBone`·`renameExpression`·`deleteExpression`, 표정 키는 `setKey`(`target: "rig"`, `property: "expression"`)입니다.
  IK는 `addIk`(`createTarget: true`로 대상 본 생성, `tip`)·`setIk`·`renameIk`·`deleteIk`·`bakeIk`, 키는 `setKey`(`target: "ik:<id>"`, `property: "mix"`/`"bendPositive"`)입니다.
  메시는 `convertToMesh`(`rows`·`cols`·`cells`)·`convertToRegion`·`setMeshVertices`·`autoWeights`/`bindMesh`·`setWeights`·`unbindMesh`, 자유 메시는 `createMeshFromOutline`(`hull`·`points?`·`spacing?`·`edges?`)·`autoOutline`(서비스에서는 `imagePath`에 PNG 절대 경로를 주면 알파를 읽어 `mask`를 채움)·`addMeshVertex`(`position`)·`removeMeshVertex`·`addMeshEdge`/`removeMeshEdge`(`edge`)·`retriangulate`, 변형 키는 `setKey`(`target: "slot:<id>"`, `property: "deform"`, `attachment`, `offsets`)입니다.
  본 길이는 `addBone`/`setBone`의 `length`·`color`, `fitBoneLengths`(`bones?`)·`orientBones`(`bones?`, `fitLength?`)입니다. `본 만들기` 도구는 `addBone`(`x`·`y`·`rotation`·`length`, 부모 공간 값) 한 번입니다.
  클립 이벤트는 `addEventDef`·`setEventDef`·`renameEventDef`·`deleteEventDef`(`force`), 키는 `setEventKey`(`newName`, `int`·`float`·`string` 덮어쓰기, null = 정의 값)·`moveEventKey`·`deleteEventKey`이고, 여러 키 명령(`moveKeys`·`deleteKeys`·`copyKeys`…)에는 `{target: "event", property: <이름>, timeMs}`로 넣습니다.
- 오래된 버전으로 고치면 `VERSION_CONFLICT`로 거부됩니다.

## PSD 가져오기 (1.11.0, 큰 작업 파일 1.15.0)

그림 담당이 레이어로 나눠 그린 PSD를 그대로 캐릭터로 만듭니다(Spine의 PSD 스크립트와 같은 역할, 외부 프로그램 없음).

1. `캐릭터 · 게임 연결` 아래 `PSD 가져오기…`(또는 `플러그인 → 캐릭터 애니메이션 → PSD 가져오기…`, 명령 찾기 `PSD`)를 누르고 `.psd`/`.psb` 파일을 고릅니다. PNG 폴더는 그 안의 PNG 하나나 `layout.json`을 고르면 됩니다.
2. 미리 보기 창에서 레이어 트리(앞쪽 레이어가 위)를 보고 가져올 레이어의 체크를 고릅니다. 열마다 그 레이어가 될 본·슬롯·첨부(● = 처음 보이는 그림)와 상태(추가·그림 교체·같음·유지)가 나오고, 아래 `주의`에 지원하지 않는 효과가 나옵니다. `가져올 곳`(새 캐릭터 / 고른 캐릭터 갱신), `캐릭터 ID`, `원점`(기본: 아래 가운데), `배율`(기본 `자동`), `투명 여백 잘라내기`, `본 방향·길이 자동`, `효과 레이어 빼기`, 그룹의 `한 그림으로` 칸을 바꾼 뒤 `미리 보기 갱신`으로 다시 계산해 볼 수 있습니다.
3. `가져오기` = 편집 한 번: 그림(내용 해시 이름의 PNG 에셋), 리그, 게임 연결이 함께 생기고 Ctrl+Z 한 번으로 모두 되돌아갑니다. 조립 모드의 기본 자세는 PSD와 픽셀까지 같습니다.

**레이어 이름 규칙** (그림 담당용):

| PSD에서 | 캐릭터에서 |
|---|---|
| 그룹(폴더) `head` | 본 `head`(그룹 안의 그룹 = 자식 본). 본 원점 = 그룹 그림 영역의 가운데. 본은 그 부위 쪽을 향하고 길이를 가집니다(아래 1.14.0) |
| 그룹 안의 작은 레이어 `[pivot]`(또는 `[bone]`, `#pivot`) | 그 그룹 본의 회전 중심(관절 자리). 그림으로는 들어오지 않음. 맨 위 단계에 두면 캐릭터 원점 |
| 레이어 `arm` | 슬롯 `arm` + 같은 이름의 그림(같은 이름 레이어가 둘이면 `arm-2`, 다른 그룹의 같은 이름은 `right-arm`) |
| `eyes/open`, `eyes/closed` (또는 `eyes@open`) | 한 슬롯 `eyes`의 바꿔 끼우는 그림 `open`·`closed` |
| 그룹 `mouth [slot]` | 그 안의 레이어가 모두 슬롯 `mouth`의 그림(`smile`, `open` …) |
| 숨긴 레이어 | 숨긴 그림(첨부): 표정·눈 깜빡임 키로 바꿔 보입니다. 슬롯에 보이는 레이어가 없으면 그 슬롯은 처음에 비어 있음 |
| `[ignore]`가 붙은 레이어·그룹 | 가져오지 않음(메모, 밑그림) |
| 레이어 순서 | 그리는 순서 |
| 불투명도 | 슬롯 투명도(그룹 불투명도는 곱해서) |
| 클리핑 마스크(아래 레이어에 잘린 그림자·빛 레이어) | 아래 그림(기준 레이어)에 합쳐 한 그림이 됨. 곱하기·스크린·오버레이·선형 닷지·밝게·어둡게·소프트 라이트를 계산해 넣음(1.15.0) |
| 그룹 `hair [merge]`(또는 미리 보기의 `한 그림으로` 체크) | 그 안의 보이는 레이어를 혼합 모드·클리핑까지 합성한 그림 하나, 슬롯 `hair` 하나(본은 만들지 않음). `mouth/smile [merge]`처럼 나누면 바꿔 끼우는 그림(1.15.0) |

- ID는 이름의 영문·숫자에서 만듭니다(소문자, 공백은 `-`). 러시아어·우크라이나어(키릴 문자)와 그리스어 이름은 로마자로 바꿉니다(`рука левая` → `ruka-levaya`, `тень` → `ten`). Photoshop 기본 이름 `Layer 12 Copy 3`은 `layer-12-copy-3`. 한글·한자만 있는 이름은 `part-1`, `bone-1`처럼 번호가 붙으니, 나중에 키·표정에서 쓰려면 영문 이름을 권합니다.
- 8비트 RGB PSD만 읽습니다. 16·32비트, CMYK, 인덱스, 회색조는 이유와 바꾸는 방법(예: `이미지 › 모드 › 8비트/채널`)을 알려 주고 멈춥니다. 레이어 마스크는 적용되지 않는다고 `주의`에 나오니 병합(적용)한 뒤 다시 가져오세요.
- **큰 작업 파일 (1.15.0)**: 5000×8000 px, 레이어 500개짜리 PSD도 그대로 고르면 됩니다.
  - `배율` `자동`(기본): 캔버스 긴 변이 2048 px 이하이고 그림이 64메가픽셀 이하가 되는 가장 큰 배율(1, 0.75, 0.5, 0.375, 0.25, 0.125)을 골라 옆에 보여 줍니다(작은 PSD는 1). 1보다 작은 배율은 그림을 **읽으면서 줄입니다**(면적 평균, 가장자리 알파가 깨끗함, 어두운 테두리 없음). 그래서 큰 파일도 메모리를 조금만 쓰고, 그림 해상도는 리그 크기와 같습니다. 파일은 512 MiB까지 읽습니다.
  - 새 캐릭터의 미리 보기는 빠르게 알파만 읽습니다: 잘라낸 크기·위치·본·슬롯 배치는 실제와 같고, 색·클리핑 합성·PNG 만들기는 `가져오기` 때 합니다(다시 가져오기 미리 보기는 바뀐 그림을 찾으려고 색까지 읽습니다).
  - 클리핑 레이어는 아래 그림에 합칩니다(숨긴 클리핑 레이어는 빼고). 기본 자세는 PSD 합성 그림과 거의 같습니다(소프트 라이트는 Photoshop 곡선과 몇 단계 다를 수 있음).
  - 클리핑되지 않은 곱하기·선형 닷지·스크린 레이어(그림자·빛 덧칠)는 리그가 표준으로만 그리므로 `주의`에 한 줄로(개수와 종류) 나옵니다. `효과 레이어 빼기`(`effects: "skip"`)를 켜면 가져오지 않고, 살리려면 그 그룹을 한 그림으로 합치세요.
  - 본 256·슬롯 256·첨부 1024개를 넘으면 미리 보기가 멈추지 않고 넘은 개수를 빨갛게 보여 주며 `가져오기`가 꺼집니다. `자동 합치기`는 그림이 가장 많은 맨 아래 그룹부터(숨긴 표정 그림이 있는 그룹은 마지막에) 한도 안에 들 때까지 `한 그림으로`를 체크합니다. 체크는 직접 풀거나 더할 수 있고(행 오른쪽 클릭 `한 그림으로 합치기`도 같음), 합친 그룹은 본 없이 그 부모 본의 그림 하나가 됩니다.
  - 비어 있는(0×0이거나 완전히 투명한) 레이어와 그림 없는 그룹은 조용히 건너뛰고 `주의`에 한 줄로만 알려 줍니다.
- **다시 가져오기**: 그 PSD에서 가져온 캐릭터를 고른 채 같은 파일을 고르면 `「…」 갱신`이 기본입니다. 본·키·스킨·표정·IK와 손으로 옮긴 그림 위치는 그대로 두고, 바뀐 그림만 같은 자리에 바꿔 끼우며(그림이 PSD에서 옮겨진 만큼 기준점을 보정), 새 레이어는 새 슬롯·그림으로 더합니다. PSD에서 사라진 그림은 지우지 않고 알려 줍니다. 메시로 바꾼 그림은 크기·위치가 같을 때만 바꿉니다.
- **본 방향·길이 (1.14.0)**: 새 본은 자식 본이 하나면 그 자식 쪽, 아니면 그룹 그림의 가운데 쪽(원점이 그림 가운데면 위쪽)을 향하고, 길이는 자식까지 거리 또는 그림이 닿는 끝까지입니다(축과 4° 이내면 축에 맞춤). 그림은 반대로 돌려 붙이므로 기본 자세는 PSD와 똑같고, 머리카락·치마 물리와 IK 늘이기가 바로 자연스럽게 움직입니다. 체크를 끄면(`boneDirection: "none"`) 1.11.0처럼 모든 본이 오른쪽(+x)을 향하고 길이가 없습니다. 루트 본과 다시 가져올 때 이미 있는 본은 바꾸지 않습니다.
- PNG 폴더: `layout.json` `{"width", "height", "layers": [{"file": "body.png", "x": 22, "y": 40, "name": "eyes/open", "visible": false, "group": "body/head"}]}`(앞에 적은 것이 뒤에 그려짐). 없으면 PNG를 모두 (0,0)에 이름 순서로(앞 번호 `01-`는 순서에만 쓰임), 하위 폴더 = 그룹.
- LLM·MCP: `plugin_import`(plugin `cutout-animation`, op `importLayers`, payload `{file, id | rig, origin?, trim?, scale? (숫자 또는 "auto"), exclude?, merge?, effects?, boneDirection?}`, `dryRun`으로 미리 보기), 읽기 전용 미리 보기는 `plugin_call` op `importLayers`. 규칙과 결과 형식은 `docs/contract.md` "Layer import".

## 클리핑 · 시퀀스 (1.12.0)

**클리핑**(가면 속 얼굴, 창문 너머 풍경, 주머니에 들어가는 손처럼 일부만 보여야 할 때):

1. 조립 모드에서 가릴 조각을 고르고 오른쪽 `클리핑` 페이지의 `클리핑 만들기`를 누릅니다.
2. 캔버스를 차례로 클릭해 보일 영역을 그립니다(오목해도 됨). 첫 점을 다시 누르거나 더블클릭·Enter로 닫으면 그 조각 바로 아래에 클리핑 조각 `<조각>-clip`이 생기고, 그 조각은 다각형 안에서만 보입니다. Esc = 취소, Backspace = 마지막 점 지우기.
3. `끝 조각`에서 위쪽 조각을 고르면 클리핑 조각 위부터 그 조각까지(그리는 순서) 모두 잘립니다. `모양 다시 그리기`로 다각형을 새로 그리고, `클리핑 삭제`로 지웁니다.
- 다각형은 클리핑 조각의 본을 따라 움직입니다(본을 키로 움직이면 가리는 영역도 움직임). 캔버스의 분홍 점선이 영역이고(`윤곽 보기`로 끄고 켬), 계층에서 클리핑 조각의 눈을 끄면 편집하는 동안만 자르지 않고 보여 줍니다.
- 게임에서도 똑같이 잘립니다: 플레이어는 잘린 조각을 메시로 그리므로 메시를 그리는 플레이어면 됩니다. 클리핑 안에 또 클리핑은 쓰지 않습니다(안쪽은 무시).

**시퀀스**(불꽃, 물결, 입 모양처럼 그림을 차례로 바꾸는 프레임 애니메이션):

1. 조립 모드에서 조각을 고르고 `시퀀스` 페이지의 `PNG로 시퀀스…`로 같은 크기의 PNG를 여러 장 고릅니다. 파일 이름 순서(숫자는 숫자 순서: `fire2`가 `fire10`보다 앞)로 프레임이 됩니다. 조각을 고르지 않고 본을 고른 채 누르면 그 본에 새 조각이 생깁니다.
2. 프레임 목록에서 `▲`·`▼`로 순서를 바꾸고 `빼기`·`프레임 추가…`로 고칩니다. `기본 프레임`은 키가 없을 때 보이는 프레임입니다. `▶ 미리보기`는 아래 재생 방식·간격으로 페이지에서 돌려 봅니다(문서는 바뀌지 않음).
3. 애니메이션 모드에서 재생 헤드를 두고 `재생 방식`(멈춤·한 번·반복·왕복·거꾸로 한 번·거꾸로 반복·거꾸로 왕복), `시작 프레임`, `프레임 간격`(ms)을 정해 `시퀀스 키`를 누르면 그 시간부터 프레임이 바뀝니다. 도프시트에 `<조각> 시퀀스` 행이 생겨 다른 키처럼 옮기고 복사합니다.
- 프레임 크기가 다르면 넣지 않고 알려 줍니다. 내보낼 때 아틀라스를 켜 두면 모든 프레임이 페이지에 들어갑니다.
- LLM·MCP: `addClipping`(`slot`·`before`·`vertices`(본 공간) 또는 `worldVertices`(리그 좌표)·`end`)·`setClipping`·`setSequence`(`frames`·`setupIndex`, `frames: null` = 해제), 키는 `setKey`(`property: "sequence"`, `mode`·`index`·`delay`)입니다. 규칙은 `docs/contract.md` "Clipping"·"Image sequences".

## 사슬 IK · 늘이기 · 물리 (1.13.0)

**사슬 IK**(꼬리, 촉수, 늘어뜨린 머리채, 여러 마디 팔):

1. 계층이나 캔버스에서 이어진 본을 여러 개 고릅니다(Ctrl/Shift+클릭, 또는 맨 위 본을 고르고 `자식 본까지 선택`). 부모 → 자식으로 한 줄이어야 하고 고른 순서는 상관없습니다.
2. `IK` 페이지의 `사슬 IK`를 누르면 그 본들이 사슬이 되고 끝점에 대상 본(✛)이 생깁니다(만들 때 아무것도 움직이지 않음). 본 2개면 팔·다리 IK, 3개 이상이면 FABRIK으로 풉니다(최대 32회 반복, 끝점이 대상에서 0.01 px 안이면 멈춤). 정보 줄에 지금 자세의 반복 횟수와 끝점 오차가 나옵니다.
- 끝점은 마지막 본의 길이 끝(길이가 있을 때), 아니면 첫 자식 본입니다(`tip`으로 고정 가능). 사슬은 애니메이션 자세가 굽은 쪽으로 굽고, 일직선일 때만 `굽힘` 방향을 씁니다.

**늘이기**: `IK` 페이지의 `늘이기`를 켜면 대상이 닿지 않는 곳에 있을 때 사슬을 본 길이 방향으로 늘여 닿게 합니다(조준 IK는 그 본, 사슬은 첫 본의 크기 X). `줄이기`(조준 IK만)는 가까운 대상에 맞춰 줄이고, `균일`은 두께도 같이 바꿉니다. 사슬의 모든 본에 길이가 있어야 하고(없으면 진단 경고, 늘이지 않음), 조준 IK는 조준 축이 0(본 길이 방향)일 때만 늘입니다. 키가 아니라 IK 설정이며 혼합(mix)만큼 늘어납니다.

**물리**(머리카락, 치마, 리본·귀걸이 같은 장식):

1. 흔들릴 본을 고르고(여러 개면 본마다 하나씩 만듦) `물리` 페이지에서 프리셋(`머리카락`·`치마`·`장식 흔들림`)을 고른 뒤 `물리 추가`를 누릅니다. 캔버스의 청록 용수철 표시(~)가 물리 본입니다. 머리카락처럼 여러 마디면 마디마다 물리를 두면 끝으로 갈수록 크게 흔들립니다.
2. 아래 값을 고칩니다: `회전 흔들림`·`가로/세로 흔들림`·`늘어남`(채널, 0..1), `관성`(부모가 움직일 때 제자리에 남으려는 정도), `복원력`(되돌아오는 힘), `감쇠`(1/60초마다 남는 속도), `질량`, `바람`·`중력`(px/s²), `전달 한계`(이보다 빠른 움직임은 더 세게 밀지 않음), `순간 이동`(이보다 멀리 한 번에 뛰면 날아가지 않고 다시 정착), `단계`(고정 시뮬레이션 Hz), `다시 정착`(0번 트랙 클립이 시작될 때). `프리셋 적용`은 흔들림 값만 바꿉니다.
3. 애니메이션 모드에서 ▶ 재생하면 흔들립니다. 재생 헤드를 끌어 움직이는 동안(스크럽)은 계산하지 않고 클립 자세만 보입니다. 재생 중에는 캔버스에 점선이 애니메이션만의 자리에서 흔들린 자리까지 이어집니다. `● 재생 중 물리: 켜짐` / `○ … 꺼짐`(기본 켜짐)으로 끄고 켜며, `바람`·`중력`은 미리 보기에만 더해집니다(저장 안 됨). `다시 놓기`는 지금 자세에서 다시 정착시킵니다.
   - 흔들림은 본의 +x 방향(길이 방향)을 기준으로 계산합니다. 길이 없는 점 본(오른쪽을 향함)에 물리를 붙이면 아래로 늘어진 머리카락이 중력에 옆으로 기울고, 오른쪽 바람에는 거의 반응하지 않습니다. 이때 물리 탭에 안내와 `본 방향 맞추기` 버튼이 나오니 눌러 본을 그 부위 쪽으로 돌리세요(조립 모드에서 편집 한 번, 그림·애니메이션은 그대로). 1.14.0부터 PSD로 가져온 본은 처음부터 부위 쪽을 향합니다.
4. `혼합`은 키가 됩니다: 애니메이션 모드에서 바꾸고 K(또는 `혼합 키`)를 누르면 도프시트에 `물리 <id> 혼합` 행이 생깁니다(0 = 그 구간은 흔들리지 않음).
- 게임에서도 같은 결과입니다: 물리는 화면 프레임과 상관없이 고정 단계로 계산되므로 30·60·144 Hz나 들쭉날쭉한 프레임에서도 같은 시간이면 같은 자세입니다(Windows·Web 플레이어 동일). 물리 상태는 저장되지 않고, 불러오면 정착한 상태에서 시작합니다.
- LLM·MCP: `addIk`(`bones`에 본 3개 이상, `stretch`·`compress`·`uniform`)·`setIk`, `addPhysics`(`bone` 또는 `bones`, `preset`: `hair`·`skirt`·`accessory`, 값)·`setPhysics`(`null` = 기본값)·`renamePhysics`·`deletePhysics`, 혼합 키는 `setKey`(`target: "physics:<id>"`, `property: "mix"`)입니다. 규칙은 `docs/contract.md` "IK chains and stretch"·"Physics".

## 변형 제약 · 상속 · 기울이기 (1.16.0)

**기울이기**(shear): 본 속성의 `기울이기 X°`·`기울이기 Y°`. X는 본의 x축(길이 방향)을 회전보다 더 돌리고, Y는 y축을 더 돌려 그림을 비스듬히 밉니다(천 펄럭임, 찌그러지는 탄성 표현). 조립 모드에서는 기본값, 애니메이션 모드에서는 키가 되며(자동 키·K), 그래프 편집기에 `기울이기 X/Y` 곡선이 나옵니다. 기울인 본에 K를 누르면 기울이기도 함께 키가 됩니다(쓰지 않는 본은 예전처럼 다섯 채널만).

**상속**: 본 속성의 `상속` 목록(조립 모드 전용, 키 아님)으로 부모에게서 무엇을 물려받을지 고릅니다. 원점 위치는 언제나 부모를 따릅니다.

| 상속 | 쓰임 |
|---|---|
| 일반 (모두 상속) | 기본. 부모의 회전·크기·뒤집기를 모두 따름 |
| 위치만 | 부모가 돌거나 커져도 화면 방향·크기 그대로(눈동자 하이라이트, 늘 위를 향하는 머리카락 장식) |
| 회전·뒤집기 제외 | 부모의 크기만 따르고 회전은 따르지 않음 |
| 크기 제외 | 부모의 회전(뒤집기 포함)은 따르고 크기는 그대로(늘어나는 팔 끝의 손이 찌그러지지 않게) |
| 크기·뒤집기 제외 | 부모의 회전만 따르고 크기·좌우 뒤집기는 따르지 않음 |

상속을 바꾼 본도 부모 바꾸기, 본 보정, 회전 중심 옮기기, 월드·부모 축 숫자 칸, IK가 그 방식대로 계산합니다(바꾸는 순간 화면 자세가 달라질 수 있으니 필요하면 `본 보정`을 켠 채 부모를 조정하세요).

**변형 제약**(한 본이 다른 본을 따라 움직이기: 소품을 손에 쥐기, 그림자·반사, 여러 장식이 한 본을 따라 돌기):

1. 따라 움직일 본들을 고르고 **마지막에 대상 본**을 Ctrl+클릭한 뒤 `변형 제약` 페이지의 `제약 추가`를 누릅니다(본 하나만 고르면 대상 본 ID를 묻습니다). 지금 자세는 그대로 두도록 오프셋이 자동으로 정해지고, 그 뒤 대상이 움직이는 만큼 따라옵니다. 캔버스에 분홍 점선(제약된 본 → 대상의 ◇)이 보입니다.
2. 혼합으로 무엇을 따를지 정합니다: `회전 혼합`·`위치 X/Y 혼합`(기본 1), `크기 X/Y 혼합`·`기울이기 혼합`(기본 0 = 제 크기·모양 유지). 오프셋(회전°, 위치, 크기, 기울이기°)은 대상 값에 더해집니다. 오프셋을 모두 0으로 두면 대상에 딱 붙습니다.
3. `로컬 값으로`를 켜면 화면(월드) 자세 대신 부모 기준 값(x·y·회전·크기·기울이기)을 맞추고, `상대`를 켜면 대상 쪽으로 옮기는 대신 대상의 값을 더합니다(대상이 돈 만큼 같이 돌기). 바꿀 때 지금 자세가 유지되도록 오프셋이 다시 맞춰집니다.
4. `순서`: IK와 변형 제약은 작은 순서부터 함께 풉니다(같으면 IK 먼저, 물리는 그 뒤). 다른 제약이 움직이는 본을 대상으로 쓰면 순서를 더 크게 두세요(아니면 진단 경고).
5. 애니메이션 모드에서 혼합을 바꾸고 K(또는 `혼합 키`)를 누르면 도프시트에 `변형 <id> 회전 혼합` 같은 행이 생깁니다(0 = 그 구간은 따라가지 않음). `대상 선택`·`본 선택`, `이름 변경`(키도 함께), `삭제`(키도 함께)가 있습니다. 대상 본을 지우려면 제약도 함께 지워야 하고, 제약된 본을 지우면 목록에서만 빠집니다.
- 게임에서도 같은 결과입니다: 계산은 Windows·Web 플레이어가 같은 코어로 하며 프레임 간격과 상관없습니다. 이 기능을 쓰지 않은 이전 문서는 비트 단위로 똑같이 재생됩니다.
- LLM·MCP: `setBone`의 `shearX`·`shearY`·`inherit`, 기울이기 키 `setKey`(`property: "shearX"|"shearY"`), `addTransform`(`bones`, `target`, 혼합·오프셋, `local`·`relative`, `order`, `keepPose`)·`setTransform`(`null` = 기본값)·`renameTransform`·`deleteTransform`, 혼합 키 `setKey`(`target: "transform:<id>"`, `property: "mixRotate"` 등)입니다. 규칙은 `docs/contract.md` "Shear, inherit and transform constraints".

## 판정 상자 · 기준점 (1.17.0)

**판정 상자**는 게임 화면에 그려지지 않는 클릭 영역입니다. 플레이어에서 그 위를 클릭하면 캐릭터가 반응합니다(머리를 쓰다듬으면 웃기, 팔을 누르면 흔들기).

1. 조립 모드에서 조각(▣)을 고르고 `판정` 페이지의 `판정 상자`를 누릅니다. 그 그림의 불투명한 윤곽을 따라(메시 페이지의 `알파 기준`·`세밀도` 사용) 상자가 생기고, 조각 바로 위에 `<조각>-box` 조각이 생깁니다. 그림이 없으면 사각형, 본을 골랐으면 그 본에 사각형입니다. 캔버스에 반투명 연두 점선으로 보입니다(테두리를 클릭해 고름).
2. 모양 고치기: `정점 편집`을 켜면 메시처럼 점을 클릭·Shift+클릭·상자로 고르고 끌어 옮깁니다. `점 추가`를 켜고 변 가까이를 클릭하면 점이 생기고, Delete(또는 `점 삭제`)로 지웁니다(3개는 남음). 상자는 본·웨이트·IK·물리를 따라 그림과 함께 움직입니다.
3. `게임 연결` 탭에서 `연결 추가` → 게임 신호 `partClicked · 판정 상자 클릭`, 조건 `box=box`(상자 첨부 이름; 칸에 이 리그의 상자 이름이 제안됨) 또는 `slot=face-box` → 클립·표정·스킨. 이 탭에서 캔버스의 상자를 클릭하면 미리 보기 캐릭터에 같은 신호가 가서 연결을 바로 시험할 수 있습니다.
- 겹친 상자는 위에 그려지는(그리는 순서가 뒤인) 상자가 이깁니다. 숨긴 조각(표정·키로 null)의 상자는 클릭되지 않습니다.
- **게임 규칙과 무관**: 클릭은 그 캐릭터 요소 안에서만 처리되는 화면 신호입니다. 게임 명령·난수·저장된 게임 상태를 바꾸지 않고(연출 상태만 바뀜), 클릭은 그 아래 화면 요소에도 그대로 전달됩니다. Windows·Web 플레이어가 같은 코어로 판정합니다.

**기준점**은 말풍선·효과 아이콘 같은 UI를 캐릭터의 한 부분(입, 머리 위)에 붙일 자리입니다. `기준점`을 누르고 캔버스를 클릭하면 고른 본(조각이면 그 본)에 `<본>-point` 조각이 생깁니다. 보라 십자를 끌어 옮기고, 방향 선 끝의 둥근 손잡이를 끌어 방향을 돌립니다. 플레이어는 지금 자세의 기준점 위치·방향을 요소 좌표로 알려 줍니다(확장 호스트의 `points`).

- `보기 ▾`의 `판정 상자 보이기`·`기준점 보이기`로 캔버스 표시를 켜고 끕니다(편집기 전용).
- PSD 가져오기: 레이어 이름에 `[box]`를 붙이면(`head [box]`) 그림 대신 그 픽셀 윤곽의 판정 상자(조각 `head-box`, 상자 이름 `head`)가, `[point]`를 붙이면(`mouth [point]`) 픽셀 가운데에 기준점(조각 `mouth-point`)이 생깁니다. 본 위치에는 영향이 없고, 다시 가져오면 모양·위치가 갱신됩니다.
- 판정 상자·기준점은 아틀라스에 들어가지 않고 PSD 다시 가져오기에서 그림으로 바뀌지 않습니다.
- LLM·MCP: `addBoundingBox`(`slot`, `from` 조각 + `imagePath`/`mask`, 또는 `vertices`·`worldVertices`)·`setBoundingBox`·`addPoint`(`worldX`·`worldY`·`worldRotation`)·`setPoint`, 런타임 `points`·`boxes`·`hitTest`. 규칙은 `docs/contract.md` "Bounding boxes and points".

## 게임 시간과의 분리

- 게임 효과(비용·능력치·RNG)는 명령이 커밋될 때 이미 확정됩니다.
- 플레이어는 명령 하나당 `observe`를 한 번 호출해 신호를 만듭니다.
- 애니메이션 완료 알림은 표현만 바꾸고 게임 명령을 보내지 않습니다.
- 그래서 프레임 속도, 일시정지, 렌더링 속도는 게임 결과를 바꾸지 않습니다.

세이브 정책(`playerPresentation.extensions`):

- 스킨과 표정은 그대로 복원합니다(그 사이 지워진 ID는 연결의 기본값).
- 한 번만 재생되는 동작은 저장된 시간부터 이어서 재생합니다.
- 숨쉬기·눈깜빡임 같은 반복 장식 클립은 0부터 다시 시작합니다.
- 플러그인이 없어도 게임 세이브는 정상으로 불러옵니다.
