# 견습생의 사계절 — 12개월 확장 샘플

첫해 4월 입학부터 다음 해 3월까지 **12개월·36기간**을 진행합니다. 외부 아트·네트워크 다운로드 없이 텍스트로 플레이합니다. 기존 2개월 샘플은 그대로 남아 있습니다.

Raising Studio의 **12개월 새 프로젝트**에서 빈 폴더로 복사하거나, Player의 **12개월 샘플**로 바로 플레이하세요. 프로젝트 생성 후에는 원본과 독립적인 JSON 파일을 GUI·MCP에서 함께 편집합니다.

## 콘텐츠와 선택

| 콘텐츠 | 수 |
| --- | --- |
| 능력·자원·상태 | 7 |
| 활동 | 7 |
| 사건 정의 | 19 |
| 엔딩 | 5 |
| 고정 시나리오 | 5 |

상순·중순·하순에 활동을 하나씩 수행합니다. 1개월차 말에 기사·학자·장인 과정 또는 자유로운 생활을 선택합니다. 3·9개월차에는 전공 수치가 충분하면 일반 월말 사건보다 우선순위가 높은 발표 사건이 발동합니다. 6개월차 축제 지원에는 소지금 10이 들고 평판 5·신뢰 3을 얻습니다. 10개월차 대사는 축제 지원 여부에 따라 분기합니다. 마지막 기간의 졸업식은 졸업 플래그와 평판을 적용한 다음 엔딩을 판정합니다.

일반 월말 사건과 전공 발표·졸업식은 같은 기간에 경쟁합니다. 한 경로에서 모든 사건을 보는 것은 아니며, 각 시나리오에서는 월말 사건 총 12개를 경험합니다. 정적 도달 가능성과 특정 고정 경로의 관찰 결과를 구분합니다.

## 독립 기대값과 재현

시나리오 seed는 42입니다. 기사·학자·장인 경로는 매월 `[전공 활동, work, rest]`를 선택하고 축제를 지원합니다. 이웃은 `[work, rest, socialize]`, 여행자는 `[expedition, work, rest]`이며 두 경로는 축제를 구경합니다.

| 경로 / 엔딩 | 최종 주 능력 | 소지금 | 평판 | 체력 | 스트레스 |
| --- | --- | --- | --- | --- | --- |
| knight-year / 마을의 수호 기사 | 검술 106 | 134 | 15 | 100 | 0 |
| scholar-year / 새로운 기록을 쓰는 학자 | 학문 106 | 146 | 15 | 100 | 0 |
| artisan-year / 자신의 공방을 연 장인 | 제작 106 | 158 | 15 | 100 | 0 |
| neighbor-year / 마을을 잇는 이웃 | 검술 0 | 192 | 40 | 95 | 0 |
| wanderer-year / 다음 길을 찾는 여행자 | 검술 36~84 | 204~300 | 0 | 100 | 0 |

전공 수치는 `12×8 + 발표 2×5 = 106`, 소지금은 `60 + 12×(12−전공 비용) − 축제 10`, 평판은 `발표 2×3 + 축제 5 + 졸업 4 = 15`입니다. 이웃의 소지금은 `60 + 12×(12−1) = 192`, 평판은 `12×3+졸업 4=40`입니다. 체력·스트레스는 각 효과마다 범위를 제한하므로 단순 합계와 다를 수 있습니다.

여행자 기대값의 범위는 난수와 독립적으로 계산했습니다. 성공 횟수 S에 대해 검술은 `36+4S`, 소지금은 `204+8S`입니다. 테스트에서는 seed 42의 전체 상태·난수 상태·전이 기록이 반복 실행 및 매 명령 저장·복원 후 같고 성공과 실패가 모두 나타나는지 추가 검사합니다.

```powershell
npm run validate -- examples/academy-year
npm run scenarios -- examples/academy-year --roundtrip
node --test tests/release/year.test.mjs
```

다섯 경로는 각각 159개 코어 명령, assertion 6개를 통과합니다. 매 명령 저장·복원 검사는 경로별 초기 상태를 포함해 160번, 합계 800번입니다. 시작은 1년 4월, periodIndex 27은 2년 1월, 마지막 periodIndex 35는 2년 3월입니다.

`scripts/create-year-sample.mjs`는 이 샘플을 작성한 소스이며 실행 결과로 기대값을 생성하지 않습니다. 재실행하면 샘플 파일을 덮어쓰므로 사용자 프로젝트에 실행하지 마세요. 설치판 통합 테스트는 복사본의 검술 성장량을 8에서 9로, 기대값을 106에서 118로 함께 바꾸고 GUI·MCP·미리보기·Player의 결과 일치를 검사합니다.
