# 별빛 길드의 세 달

9단계 상용 제작 파일럿. Qt 편집기의 기존 프로젝트 재사용과 제작 도구만으로 만든 3개월 × 3일정 게임이다. 기본 시스템과 이미지는 `direction-lab`에서 재사용했다.

저장소 루트의 `start-commercial-pilot.cmd`로 연다. 집에서 생활·상품·관계·파티 준비·연출로 이동하고, 상단 일정에서 월별 활동을 배정한다. 상세 제작/검증 기록과 공략은 `docs/commercial-pilot.md`에 있다.

- **별빛 길드의 동료**: 유나에게 꽃 선물, 공부로 능력 16 이상 준비, 의뢰 수락·장비 설정 후 숲의 두 웨이브 전투 승리, 의뢰 보상 수령. 최종 능력 20·신뢰 15 이상.
- **마을에 남은 약속**: 꽃을 선물한 뒤 전투 목표를 달성하지 않고 세 달 종료.
- **다시 시작하는 계절**: 나머지 경우의 기본 엔딩.

상용 완제품이 아닌 제작 가능성 검증용 파일럿이다. 배포용 미술·사운드·번역·콘텐츠와 에셋 권리 검토는 별도다.

목표 경로는 `playtests/routes/`에 등록한다. 편집기의 **디자인 → 목표 경로 기록 · 회귀 검사**에서 확인하며 프로젝트 저장 때 자동 검사한다. 사용법은 `docs/goal-route-regression.md`를 참고한다. 탐험 버튼이 잠기면 아래 표시된 검술/평판 조건과 현재 값을 확인한다.

자동 탐색 기능으로 관계 사건 도달 경로 `auto-friendship`도 Qt 편집기에서 등록했다. 기존 세 엔딩과 함께 검사하며, 새 목표 탐색/실패 경로 대체 등록은 `docs/goal-route-search.md`를 참고한다.
