# 잔설 아래 막내손자 — 시각 완성도 검토판

남궁가에서 천대받는 시한부 막내 남궁설이 두 달 동안 살아남을 길을 찾는 짧은 육성게임입니다. `last-grandson`의 규칙과 두 엔딩을 보존한 별도 샘플입니다. 겨울 저택·약방 삽화, 캐릭터, 일정 설명, 재사용 저장 UI와 잔잔한 합성 배경음을 추가했습니다. 다른 게임의 에셋은 사용하지 않습니다.

## 열기와 제작

프로젝트 선택기의 **새 프로젝트 → 기존 프로젝트 복제**로 이 폴더를 `projects/` 아래에 복제해 사용하세요. 호환되는 **cutout-animation 1.13.0** 패키지를 편집기의 플러그인 관리에서 먼저 설치해야 합니다. 프로젝트의 잠금 파일·리그·컨트롤러는 함께 복제되며, 실행 모듈은 사용자 플러그인 저장소에서 제공됩니다. 소스는 `plugins/cutout-animation`에 있습니다.

화면은 타이틀·일정·대화·엔딩 네 개입니다. `공용 저장·불러오기` 부품을 수정하면 연결된 화면에 반영됩니다. 일정 위젯의 **선택한 활동 설명 표시**를 켜면 선택 중인 활동의 비용·효과 설명을 읽을 수 있습니다. 화면은 1280×720 기준으로 fit 배치됩니다.

캐릭터 위젯의 애니메이션 작업실에서 `seol` 초상과 `seol-sd` 활동 캐릭터를 선택해 편집할 수 있습니다. 활동 결과가 나오면 일정표·설명·상태 카드는 숨겨지고 SD 동작과 이번 활동의 능력치·자원 증감이 표시됩니다. 수련은 책 읽기 2프레임, 심부름은 걷기 2프레임, 운기조식은 명상 자세의 숨쉬기입니다. 팔다리를 분리한 전신 연기는 아닙니다.

`seol-sd`는 일정 화면에 계속 배치하여 활동 신호를 받습니다. 선택 중에는 명상 대기, 활동 후에는 연결된 동작을 반복합니다. 일정을 한 번 확정하면 동작 → 비용·효과 순서의 숫자 변화 → 다음 활동으로 자동 진행합니다. 사건 대사와 선택지에서 멈추고, 이를 읽고 선택하면 남은 일정이 이어집니다. 한 달이 끝나면 다음 달 일정을 정합니다.

**프로젝트 설정 → 활동 결과 연출**에서 동작 시작 대기(800ms), 한 항목 변화(800ms), 마지막 유지(1000ms)를 조절할 수 있습니다. **기본 · 달력 → 월 일정 연속 진행**이 자동 진행 설정입니다. 연출은 실제 계산이 끝난 수치의 표시만 바꾸며, 별도의 일별 판정을 만들거나 효과를 중복 적용하지 않습니다. 숫자가 변하는 도중 저장해도 같은 표시 위치에서 이어집니다. SD 반복 동작 자체는 기존 플러그인 정책대로 불러올 때 처음부터 재생합니다.

프로젝트 저장은 제작 내용을 저장합니다. 실제 플레이의 **기록 / 이어가기** 또는 **F5 / F9**는 게임 진행을 저장·복원합니다.

일정 실행 중 하단에 **일시정지 / 계속 재생**, **배속 ×1 / ×4**, **이번 활동 연출 건너뛰기**가 나타납니다. 일시정지는 숫자와 SD를 함께 멈추고, 배속은 다음 활동과 저장·불러오기에도 유지됩니다. 건너뛰기는 현재 활동 연출만 완료하며 결과나 난수를 바꾸지 않습니다. 대사·선택지에서는 조작 바가 사라지고 반드시 입력을 기다립니다. 일시정지 상태로 저장하면 다시 열어도 정지 상태이므로 계속 재생을 눌러야 합니다.

## 활동과 엔딩

| 활동 | 비용 | 효과 |
|---|---|---|
| 서고의 비급 수련 | 약값 6, 기력 10 | 내공 +12, 한독 +5 |
| 약방 심부름 | 기력 10 | 약값 +12, 한독 +8 |
| 운기조식 | 없음 | 기력 +25, 한독 −15 |

두 달 동안 매달 세 활동을 정합니다. 첫 활동 뒤 약방 노인과의 약속을 선택합니다. 생존 엔딩은 마지막에 **내공 30 이상·기력 20 이상·노인의 신뢰 1 이상**을 요구합니다. 조건을 충족하지 못하면 이별 엔딩입니다. 수치 증감은 각 능력의 범위 안에서 제한됩니다.

검증한 경로(스포일러):

- **생존:** 첫 달 수련 → 운기조식 → 수련, 노인의 제안 수락. 둘째 달 수련 → 운기조식 → 심부름.
- **이별:** 두 달 모두 운기조식, 노인의 제안 거절.

## 검증과 범위

`node --test tests/native-player/short-polish.test.mjs`로 두 엔딩, 중간 저장·복원, 프로그램 재실행, SD 클립·프레임 전환·일정표 비표시, 해상도와 음악 토글을 검사합니다. 네이티브 플레이어와 웹 런타임 빌드, 설치된 플러그인이 필요합니다. 기본 플레이어는 `dist/native-player`이며 `RAISING_NATIVE_PLAYER_RUNTIME`으로 지정할 수 있습니다. `node scripts/test-qt-studio.mjs shortPolishAuthoring`은 실제 Qt 위젯에서 복제·일정 설정·클립 길이 변경·저장·재열기를 검사합니다.

반복 클립은 불러올 때 처음부터 재생하며, 단발 클립은 저장된 재생 위치를 복원합니다. 원본 프로젝트의 저장 파일을 이 별도 샘플로 이식하는 검증은 이번 범위에 포함하지 않습니다.

상용 출시본으로 인증한 게임은 아닙니다. 현재는 짧은 시각·제작 흐름 검토판이며, 일러스트 디테일 보정·전신 분절 애니메이션·최종 사운드 제작·장편 콘텐츠·현지화·배포 품질 검증은 남아 있습니다. 데이터 배치는 공통 JSON 계약으로 작성하고 편집기에서 조정·검증했습니다. 모든 배치를 GUI에서 처음부터 제작했다고 주장하지 않습니다. 자세한 기록은 `docs/short-game-polish.md`, 에셋 출처와 프롬프트는 [assets/PROVENANCE.md](assets/PROVENANCE.md)에 있습니다.

## 회상과 엔딩 도감

화면의 **설이의 추억과 결말** 버튼에서 약방 노인의 제안과 두 결말을 확인합니다. 이야기를 끝까지 보면 해금되며, 당시 대사·선택·최종 능력치를 다시 볼 수 있습니다. 새 게임이나 과거 저장 불러오기로 도감은 지워지지 않습니다. 다른 선택의 대사는 별도 기록으로 남습니다.

Qt **프로젝트 설정 → 회상 · 엔딩 도감**에서 항목과 힌트·썸네일·순서를 바꿉니다. 이 샘플의 도감 항목은 실제 Qt 편집기로 제작·저장했습니다. 현재 도감은 Windows 네이티브 플레이어에서 지원합니다. 미지원 웹 내보내기는 명시적으로 거부합니다. 도감을 제거한 기존 샘플 구성은 종전 웹 기능을 유지합니다.

최신 빌드를 지정한 검증: `RAISING_NATIVE_PLAYER_RUNTIME=dist/native-player-gallery node --test tests/native-player/gallery.test.mjs` (PowerShell에서는 먼저 `$env:RAISING_NATIVE_PLAYER_RUNTIME='dist/native-player-gallery'` 설정). 범위와 저장 규칙은 [도감 문서](../../docs/gallery-and-recollection.md)를 참고하세요.
