# 도시·상점·관계 표본

집에서 일정·도시·상점으로 이동하고, 물품 구매·선물·관계 사건을 연결하는 표본.

Qt 프로젝트 선택기에서 이 템플릿을 선택해 설치 폴더 밖의 새 프로젝트로 복사하세요. 원본 예제를 직접 수정할 필요가 없습니다.

- [첫 게임 제작 안내](../../docs/first-game.md)
- [Windows·Web 지원표](../../docs/platform-support.md)
- [샘플·에셋 배포 경계](../../docs/public-assets.md)

개발 환경에서 데이터 검증:

```powershell
npm run validate -- examples/academy-journey
```

검증 통과는 모든 엔딩 도달·모든 플랫폼 지원을 뜻하지 않습니다. 실제 플레이와 저장·복원, 목표 경로 회귀를 함께 확인하세요.
