# 여섯 유형 제작 시험

Qt의 **디자인 → 완결 샘플 제작…**으로 생성한 일반 프로젝트입니다. 각 폴더를 열어 화면·규칙·활동·인물을 수정하고 플레이할 수 있습니다.

- `schedule`: 두 기간 훈련.
- `free`: 제작 행동과 시간 진행, 취소·행동력.
- `relationship`: 두 번 대화해 관계 목표 달성.
- `adventure`: 탐험·전투 승리·귀환.
- `roster`: 두 인물에게 훈련과 휴식을 따로 배정.
- `pet`: 먹이 주기와 훈련.

한 달 두 기간 뒤 목표 또는 대체 엔딩으로 끝납니다. 사용법과 검증 증거: `docs/genre-authoring-assurance.md`.
